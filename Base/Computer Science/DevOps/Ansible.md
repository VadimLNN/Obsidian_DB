# Ansible

Ansible — agentless-инструмент управления конфигурациями: управляющий узел подключается к целевым хостам по SSH и приводит их к описанному состоянию.

## Что нужно знать

- ad hoc-команды;
- inventory в INI/YAML;
- playbook и его структура;
- модули (`apt`, `copy`, `template`, `file`, `service`, `user`, `git`);
- variables и приоритеты переменных;
- facts;
- handlers;
- `when`, `loop`;
- шаблоны Jinja2;
- подключение по SSH-ключам;
- Ansible Vault.

### Идемпотентность

Повторный запуск playbook не должен менять систему, если она уже находится в нужном состоянии.

### Roles

Роли разбивают конфигурацию на переиспользуемые модули с предсказуемой структурой: например, отдельные роли для Nginx, PostgreSQL и мониторинга.
