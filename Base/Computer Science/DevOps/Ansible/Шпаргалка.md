# Шпаргалка

[[Base/Computer Science/DevOps/Ansible/Ansible|Карта тем]] · [[Base/Computer Science/DevOps/Ansible/Playbooks/Playbooks|Playbooks]] · [[Base/Computer Science/DevOps/Ansible/Playbooks/Модули|Модули]] · [[Base/Computer Science/DevOps/Ansible/Playbooks/Отладка и проверка|Отладка и проверка]]

| Команда | Назначение |
|---|---|
| `ansible --version` | Версия Ansible |
| `ansible-inventory -i inventory.yml --graph` | Дерево хостов и групп |
| `ansible all -m ansible.builtin.ping` | Проверка управляемых Linux-хостов |
| `ansible web -a 'hostname'` | Ad-hoc команда |
| `ansible-playbook site.yml` | Запуск playbook |
| `ansible-playbook site.yml --syntax-check` | Проверка синтаксиса |
| `ansible-playbook site.yml --check --diff` | Проверка предполагаемых изменений |
| `ansible-playbook site.yml --limit app01` | Ограничить целевые хосты |
| `ansible-playbook site.yml --tags web` | Выбранные задачи по тегам |
| `ansible-playbook site.yml -K` | Запрос пароля sudo/become |
| `ansible-playbook site.yml -vvv` | Подробный debug вывод |
| `ansible-doc ansible.builtin.copy` | Справка по модулю |
| `ansible-galaxy role init roles/myrole` | Создать роль |
| `ansible-galaxy collection list` | Посмотреть коллекции |
| `ansible-vault create secrets.yml` | Создать зашифрованный файл |
| `ansible-config dump --only-changed` | Активные переопределения настроек |
| `ansible-lint site.yml` | Проверка стиля/практик, если установлен ansible-lint |

## Другие команды из конспекта

| Команда | Назначение |
|---|---|
| `ansible-inventory -i inventory.ini --list` | Inventory в структурированном виде |
| `ansible-inventory -i inventory.ini --host app01` | Переменные хоста |
| `ansible-playbook -i inventory.ini site.yml` | Запуск с явным inventory |
| `ansible-doc -l` | Список модулей |
| `ansible-doc -s ansible.builtin.command` | Краткая справка |
| `ansible-galaxy role search nginx` | Поиск ролей |
| `ansible-galaxy collection install -r requirements.yml` | Установка коллекций проекта |

## Ключевые слова playbook

| Ключевые слова | Назначение |
|---|---|
| `name`, `hosts`, `tasks` | Имя, целевые хосты, список задач |
| `become`, `gather_facts` | Повышение привилегий, сбор facts |
| `vars`, `vars_files`, `register`, `set_fact` | Переменные и результаты задач |
| `when`, `loop`, `loop_control` | Условия и циклы |
| `notify`, `handlers` | Реакция на изменения |
| `roles`, `tags`, `serial` | Подключение ролей, выбор задач, пакеты хостов |
| `failed_when`, `changed_when` | Критерии ошибки и изменения |
| `block`, `rescue`, `always` | Группировка задач и обработка ошибок |
| `no_log` | Скрытие чувствительных результатов задачи |

## Частые модули

`ping`, `command`, `shell`, `package`, `apt`, `dnf`, `service`, `systemd_service`, `copy`, `template`, `file`, `user`, `git`, `debug`, `assert` — модули коллекции `ansible.builtin`. Для Windows — `ansible.windows.win_ping` и `ansible.windows.win_service`. Назначение и примеры: [[Base/Computer Science/DevOps/Ansible/Playbooks/Модули|Модули]].

Команды и ключевые слова взяты из конспекта. Без `-i` используется настроенный inventory. `--check` имеет ограничения; `--diff` показывает различия. Подробности: [[Base/Computer Science/DevOps/Ansible/Playbooks/Отладка и проверка|Отладка и проверка]].
