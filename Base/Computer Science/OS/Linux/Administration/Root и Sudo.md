# Root и Sudo

[[OS/Linux/Linux|Карта Linux]] · Источник: Terminal Tools Курс

## Права root и группа sudo

Возможность выполнять команды с привилегиями суперпользователя (через `sudo`) определяется членством пользователя в группе **sudo**.

> [!info] Arch Linux
> Обычно используют группу `wheel`, но членство само по себе не даёт `sudo`: нужна разрешающая политика. При уже настроенном административном доступе:
>
> ```bash
> sudo usermod -aG wheel username
> sudo visudo
> ```
>
> В `sudoers` разрешающая строка для группы выглядит так:
>
> ```text
> %wheel ALL=(ALL:ALL) ALL
> ```
>
> Она разрешает участникам выполнять любые команды от любого пользователя/группы. Войдите заново и проверьте `sudo -l`, сохраняя рабочую административную сессию. Если `sudo` ещё не установлен/не настроен, первоначальные `pacman -Syu sudo`, `usermod` и `visudo` выполняются из имеющейся root-сессии. Удаление из группы: `sudo gpasswd -d username wheel`. Источники: [ArchWiki: Sudo](https://wiki.archlinux.org/title/Sudo_), [sudoers(5)](https://man.archlinux.org/man/sudoers.5.en).

### Проверка групп пользователя

```bash
groups                  # группы текущего пользователя
groups username         # группы указанного пользователя
```

### Сравнение пользователей

- Пользователь `itguy` состоит в группе `sudo` → может выполнять команды с `sudo`

- Пользователь `smileygirl` не состоит в группе `sudo` → при попытке использования `sudo` получает отказ


_Ошибка при отсутствии прав:_

> user is not in the sudoers file.  This incident will be reported.

## Добавление и удаление пользователя из группы sudo

### Добавление в группу sudo

```bash
sudo usermod -a -G sudo username
```

- `-a` (append) — добавить к существующим группам (без этого ключа пользователь будет удалён из всех других дополнительных групп)

- `-G` — указать список дополнительных групп

- `sudo` — название группы (регистр важен)


### Удаление из группы sudo

```bash
sudo deluser username sudo
```

- Первое `sudo` — запуск команды с правами root

- `deluser` — команда для удаления пользователя из группы

- Второе `sudo` — название группы, из которой удаляем


### Проверка после изменений

```bash
groups smileygirl
```

Вывод должен показывать наличие или отсутствие группы `sudo`.



## Файл `/etc/sudoers` — конфигурация прав sudo

Файл `/etc/sudoers` содержит правила, определяющие, кто и какие команды может выполнять с `sudo`.

### Просмотр файла

```bash
sudo cat /etc/sudoers
```

### Синтаксис

> user      ALL=(ALL:ALL) ALL
> %group    ALL=(ALL:ALL) ALL

|Поле|Значение|
|---|---|
|`user` / `%group`|Пользователь или группа (группа с префиксом `%`)|
|`ALL` (первое)|Хосты, с которых разрешено выполнение|
|`(ALL:ALL)`|Пользователь и группа, от имени которых можно выполнять команды|
|`ALL` (последнее)|Список разрешённых команд|

### Примеры строк в `sudoers`

> root    ALL=(ALL:ALL) ALL
> %admin  ALL=(ALL:ALL) ALL
> %sudo   ALL=(ALL:ALL) ALL

Именно строка **`%sudo`** даёт всем членам группы `sudo` права на выполнение любых команд от имени root.

### Важные предостережения

- Изменения в `/etc/sudoers` применяются **мгновенно** после сохранения

- Ошибка в файле может лишить всех пользователей (включая себя) прав `sudo`

- Для безопасного редактирования используется команда:


```bash
sudo visudo
```

**`visudo`** проверяет синтаксис перед сохранением и предотвращает критические ошибки.

## Итог

В этом уроке рассмотрены:

|Тема|Команды / Файлы|
|---|---|
|Права root|Группа `sudo`, файл `/etc/sudoers`|
|Добавление в группу|`sudo usermod -a -G sudo username`|
|Удаление из группы|`sudo deluser username sudo`|
|Просмотр групп|`groups` или `groups username`|
|Файл конфигурации sudo|`/etc/sudoers` (редактировать через `sudo visudo`)|
|Удаление пользователя|`sudo userdel username`|
|Удаление с домашним каталогом|`sudo userdel -r username`|

**Ключевые понятия:**

- **Группа sudo** — даёт пользователю право выполнять команды от имени root

- **`/etc/sudoers`** — файл, определяющий права sudo; редактируется через `visudo`

- **`usermod -a -G`** — безопасный способ добавить пользователя в дополнительные группы

- **`userdel -r`** — удаляет пользователя вместе с его данными (домашним каталогом, почтой)


**Важное предостережение:** при редактировании `/etc/sudoers` используйте `visudo` — это предотвращает синтаксические ошибки, которые могут сделать невозможным использование `sudo` для всех пользователей.
