## Базовая безопасность сервера

В roadmap есть отдельная практическая задача: первоначально настроить сервер.

Нужно уметь:

1. создать пользователя;
2. настроить sudo;
3. настроить SSH по ключам;
4. отключить вход по паролю;
5. отключить root login;
6. установить базовый firewall.

В roadmap упоминаются:

```text
ufw
iptables
```

### Навыки и практика

На тестовой VM выполнить первичную настройку.

#### Задача

- [ ] Создать отдельного пользователя.
- [ ] Настроить `sudo`.
- [ ] Настроить SSH по ключу.
- [ ] Проверить, что вход по ключу работает.
- [ ] Отключить password authentication.
- [ ] Отключить root login по SSH.
- [ ] Включить firewall.
- [ ] Открыть только необходимые порты.
- [ ] Проверить логи SSH.

Не копируй blindly команды hardening из интернета. Для каждого параметра понимай, что именно он меняет.
