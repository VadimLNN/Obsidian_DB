## Troubleshooting — алгоритм DevOps

Когда что-то не работает, не переустанавливай всё подряд.

Иди сверху вниз.

### Процесс существует?

```bash
systemctl status app
ps aux | grep app
```

### Что говорят логи?

```bash
journalctl -u app -n 100
```

### Порт слушается?

```bash
ss -tulpn
```

### Работает локально?

```bash
curl -v http://127.0.0.1:8080
```

### Работает через Nginx?

```bash
curl -v http://127.0.0.1
```

### Что с DNS?

```bash
dig example.com
```

### Что с маршрутом?

```bash
ip route
ping HOST
traceroute HOST
```

### Что с ресурсами?

```bash
top
free -h
df -h
df -i
```

### Что изменилось недавно?

```bash
git diff
git log
journalctl --since "30 minutes ago"
```
