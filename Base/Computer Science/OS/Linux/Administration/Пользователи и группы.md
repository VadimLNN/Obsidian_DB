# Пользователи и группы

[[OS/Linux/Linux|Карта Linux]] · Источник: Terminal Tools Курс

## Итог: пользователи и сессии

В этом уроке рассмотрены:

|Команда|Назначение|
|---|---|
|`whoami`|Имя текущего пользователя|
|`groups`|Список групп текущего пользователя|
|`id`|UID, GID, группы с идентификаторами|
|`su username`|Переключение на другого пользователя|
|`sudo su`|Переключение на root|
|`exit`|Выход из текущей сессии|
|`sudo command`|Выполнение команды с правами root|
|`users`|Список активных пользователей|
|`who`|Детальная информация о сессиях|
|`w`|Расширенная информация о сессиях и активности|

**Ключевые понятия:**

- **UID** — числовой идентификатор пользователя

- **GID** — числовой идентификатор группы

- **Основная группа** — создаётся автоматически при создании пользователя

- **Дополнительные группы** — назначаются отдельно

- **Принцип минимальных прав** — работа с минимально необходимыми привилегиями

- **Символ приглашения** — `$` (обычный пользователь), `#` (root)


## Создание пользователей — `useradd`

Команда `useradd` — основной инструмент для создания пользователей в Linux. Она присутствует во всех дистрибутивах и является низкоуровневой утилитой.

### Базовый синтаксис

```bash
sudo useradd username
```

### Основные ключи `useradd`

|Ключ|Описание|
|---|---|
|`-m`|Создать домашний каталог для пользователя (обычно `/home/username`)|
|`-d <путь>`|Указать путь к домашнему каталогу (используется вместе с `-m` или вместо него)|
|`-g <группа>`|Задать **основную** (primary) группу пользователя|
|`-G <группы>`|Задать **дополнительные** (secondary) группы (список через запятую без пробелов)|
|`-s <оболочка>`|Указать командную оболочку (например, `/bin/bash`)|
|`-u <UID>`|Задать числовой идентификатор пользователя вручную|
|`-p <хэш>`|Указать хэш пароля (не рекомендуется — пароль остаётся в истории команд)|
|`-D`|Показать настройки по умолчанию для создания пользователей|



## Файлы хранения информации о пользователях

В Linux информация о пользователях и группах хранится в текстовых файлах в директории `/etc/`.

### `/etc/passwd` — информация об учётных записях

```bash
cat /etc/passwd
```

Формат строки (разделитель — двоеточие `:`):

|Поле|Описание|
|---|---|
|1|Логин пользователя|
|2|`x` — признак того, что хэш пароля хранится в `/etc/shadow` (исторически здесь был хэш)|
|3|**UID** (User ID) — числовой идентификатор пользователя|
|4|**GID** (Group ID) — идентификатор основной группы|
|5|GECOS — дополнительная информация (имя, телефон, и т.д.)|
|6|Путь к домашнему каталогу|
|7|Командная оболочка (shell)|

> [!warning] Требует проверки
> Вывод `/etc/shadow` содержит секретные хэши; не публикуйте его в переписке, логах или конспектах. Хэширование не является обратимым шифрованием.

### `/etc/shadow` — хэши паролей

```bash
sudo cat /etc/shadow
```

- Доступен **только для root**

- Содержит хэши паролей (зашифрованные строки), информацию о сроке действия пароля и другие параметры безопасности


### `/etc/group` — информация о группах

```bash
cat /etc/group
```

Содержит названия групп, GID и список пользователей, входящих в группу.


## Итог: создание пользователей

В этом уроке рассмотрены:

|Команда|Назначение|
|---|---|
|`sudo useradd username`|Создание пользователя (базовый вариант)|
|`sudo useradd -m username`|Создание пользователя с домашним каталогом|
|`sudo useradd -d <путь> -s <shell> username`|Создание с указанием домашнего каталога и оболочки|
|`sudo adduser username`|Интерактивное создание пользователя (Ubuntu/Debian)|
|`sudo passwd username`|Установка/смена пароля пользователя|
|`cat /etc/passwd`|Просмотр информации об учётных записях|
|`sudo cat /etc/shadow`|Просмотр хэшей паролей (только root)|
|`cat /etc/group`|Просмотр информации о группах|

**Ключевые понятия:**

- **UID** — числовой идентификатор пользователя

- **GID** — идентификатор основной группы

- **Системные пользователи (демоны)** — UID 1–999, не имеют возможности входа

- **Обычные пользователи** — UID от 1000 и выше

- Пароли хранятся в зашифрованном виде в `/etc/shadow`

- **`adduser`** — удобная обёртка над `useradd`, но может отсутствовать в некоторых дистрибутивах



## Изменение домашнего каталога

### Изменение пути — `-d` (home directory)

```bash
sudo usermod -d /new/home/path username
```

- Изменяет запись о домашнем каталоге в файле `/etc/passwd`

- **Не создаёт** новую папку автоматически


### Изменение пути с созданием папки — `-m` (move)

```bash
sudo usermod -m -d /new/home/path username
```

- Ключ `-m` (move) перемещает содержимое старого домашнего каталога в новый

- Новый каталог создаётся автоматически



## Изменение командной оболочки — `-s` (shell)

Командная оболочка (shell) определяет среду, в которой пользователь работает после входа.

### Синтаксис

```bash
sudo usermod -s /path/to/shell username
```

> [!warning] Требует проверки
> Ниже в исходнике две команды `usermod` склеены в одну строку. Не выполняйте её целиком: это два отдельных действия для двух пользователей. Формулировка и строка сохранены для сверки.

### Пример: смена оболочки на `/bin/bash`

`**sudo usermod -s /bin/bash officemanager sudo usermod -s /bin/bash smileygirl**`

### Распространённые оболочки

| Оболочка            | Описание                                                                      |
| ------------------- | ----------------------------------------------------------------------------- |
| `/bin/bash`         | Bourne Again Shell — наиболее распространённая, богатая функциональностью     |
| `/bin/sh`           | Bourne Shell — более простая, может быть ссылкой на bash в совместимом режиме |
| `/bin/zsh`          | Z Shell — расширенная альтернатива bash                                       |
| `/usr/sbin/nologin` | Запрещает вход (используется для системных пользователей)                     |
| `/bin/false`        | Немедленно завершает сессию (также запрещает вход)                            |


> [!warning] Требует проверки
> `usermod -G` без `-a` заменяет дополнительные группы. Дата `2025-12-31` в примере уже прошла: её применение отключит учётную запись. После смены UID/GID проверьте владельцев файлов вне домашнего каталога; автоматическое исправление там не гарантируется. См. [usermod(8)](https://man.archlinux.org/man/usermod.8.en).

## Другие полезные ключи `usermod`

|Ключ|Описание|Пример|
|---|---|---|
|`-g <группа>`|Изменить **основную** группу|`sudo usermod -g developers username`|
|`-G <группы>`|Задать **дополнительные** группы (список через запятую)|`sudo usermod -G sudo,www-data username`|
|`-a -G <группы>`|Добавить в дополнительные группы (без удаления существующих)|`sudo usermod -a -G docker username`|
|`-u <UID>`|Изменить UID пользователя|`sudo usermod -u 2000 username`|
|`-l <новый_логин>`|Изменить логин пользователя|`sudo usermod -l newname oldname`|
|`-e <YYYY-MM-DD>`|Установить дату истечения учётной записи|`sudo usermod -e 2025-12-31 username`|

## Прямое редактирование файлов пользователей (не рекомендуется)

Технически информацию о пользователях можно изменять, редактируя файлы:

- `/etc/passwd` — основная информация

- `/etc/shadow` — хэши паролей

- `/etc/group` — информация о группах


**Почему этого лучше не делать:**

- Нет проверок на корректность формата

- Ошибка может привести к невозможности входа в систему

- Можно случайно удалить или повредить системные учётные записи

- Специализированные команды (`usermod`, `useradd`, `passwd`) выполняют необходимые проверки и обеспечивают целостность данных



> [!warning] Требует проверки
> `usermod -L` блокирует пароль, а не все способы входа: например, доступ по SSH-ключу может сохраниться. UID системной учётной записи сам по себе также не запрещает вход. Для отключения учётной записи нужно отдельно учитывать способы аутентификации и текущие сессии. См. [usermod(8)](https://man.archlinux.org/man/usermod.8.en).

## Итог: изменение пользователей

В этом уроке рассмотрены основные возможности команды `usermod` для изменения параметров существующих пользователей:

|Действие|Команда|
|---|---|
|Блокировка пользователя|`sudo usermod -L username`|
|Разблокировка|`sudo usermod -U username`|
|Изменить домашний каталог|`sudo usermod -d /path username`|
|Изменить домашний каталог с перемещением содержимого|`sudo usermod -m -d /path username`|
|Изменить оболочку|`sudo usermod -s /bin/bash username`|
|Изменить основную группу|`sudo usermod -g groupname username`|
|Добавить в дополнительные группы|`sudo usermod -a -G group1,group2 username`|
|Изменить логин|`sudo usermod -l newname oldname`|
|Установить срок действия учётной записи|`sudo usermod -e 2025-12-31 username`|

**Ключевые понятия:**

- Блокировка добавляет символ `!` в начало хэша пароля в `/etc/shadow`

- Команды `useradd` и `usermod` используют одинаковый набор ключей

- Прямое редактирование файлов `/etc/passwd`, `/etc/shadow`, `/etc/group` возможно, но опасно и не рекомендуется

- При добавлении в дополнительные группы обязателен ключ `-a`, иначе существующие членства будут удалены

## Удаление пользователей — `userdel`

Команда **`userdel`** (user delete) удаляет учётную запись пользователя.

### Базовый синтаксис

```bash
sudo userdel username
```

- Удаляет запись из `/etc/passwd`, `/etc/shadow`, `/etc/group`

- **Не удаляет** домашний каталог и почтовый ящик пользователя


> [!warning] Требует проверки
> `userdel -r` удаляет домашние данные и почту. Сначала проверьте пользователя и резервную копию. Файлы пользователя вне домашнего каталога могут остаться; не назначайте его UID новой учётной записи без проверки.

### Удаление с домашним каталогом — `-r`

```bash
sudo userdel -r username
```

Ключ `-r` (remove) удаляет:

- Домашний каталог пользователя

- Почтовый ящик (обычно `/var/mail/username`)

## Сравнение ключей `usermod` и `userdel`

|Команда|Ключ|Назначение|
|---|---|---|
|`usermod -a -G`|`-a -G`|Добавить пользователя в дополнительные группы|
|`deluser user group`|—|Удалить пользователя из группы|
|`userdel`|—|Удалить пользователя (каталог остаётся)|
|`userdel -r`|`-r`|Удалить пользователя вместе с домашним каталогом|

## Добавление пользователя в дополнительные группы

### Синтаксис

```bash
sudo usermod -a -G groupname username
```

- `-a` (append) — добавить к существующим дополнительным группам (без этого ключа пользователь будет удалён из всех других дополнительных групп)

- `-G` (groups) — указать список дополнительных групп (можно указать несколько через запятую без пробелов)


## Удаление пользователей из группы — `deluser` или `gpasswd`

### С помощью `deluser`

```bash
sudo deluser username groupname
```

_Пример:_

```bash
sudo deluser salesguy remoteworkers
```

### С помощью `gpasswd`

```bash
sudo gpasswd -d username groupname
```

_Пример:_

```bash
sudo gpasswd -d salesguy remoteworkers
```

Ключ **`-d`** (delete) удаляет пользователя из указанной группы.

## Удаление групп — `groupdel`

Команда **`groupdel`** (group delete) удаляет существующую группу.

### Синтаксис

```bash
sudo groupdel groupname
```

### Важные ограничения

- Нельзя удалить группу, если она является **основной (primary)** для какого-либо пользователя

- Перед удалением группы необходимо либо удалить пользователей, у которых эта группа является основной, либо сменить им основную группу



## Другие команды для работы с группами

| Команда                        | Назначение                                                 |
| ------------------------------ | ---------------------------------------------------------- |
| `groupmod -n newname oldname`  | Переименовать группу                                       |
| `groupmod -g newGID groupname` | Изменить GID группы                                        |
| `gpasswd groupname`            | Установить пароль для группы                               |
| `gpasswd -A user groupname`    | Назначить администратора группы                            |
| `newgrp groupname`             | Временно переключить основную группу текущего пользователя |



## Итог: группы

В этом уроке рассмотрены основные операции с группами в Linux:

|Действие|Команда|
|---|---|
|Создать группу|`sudo groupadd groupname`|
|Добавить пользователя в группу|`sudo usermod -a -G groupname username`|
|Удалить пользователя из группы|`sudo deluser username groupname` или `sudo gpasswd -d username groupname`|
|Удалить группу|`sudo groupdel groupname`|
|Просмотреть все группы|`cat /etc/group`|
|Просмотреть группы пользователя|`groups username`|

**Ключевые понятия:**

- **GID** — числовой идентификатор группы

- **Основная группа (primary group)** — группа, указанная в `/etc/passwd` в поле GID. У каждого пользователя есть ровно одна основная группа

- **Дополнительные группы (secondary groups)** — группы, в которые пользователь добавлен через `/etc/group`

- При добавлении в дополнительные группы всегда используйте `-a`, чтобы не потерять существующие членства

- Группу нельзя удалить, если она является основной для какого-либо пользователя

## Дополнения и особенности системы

> [!info] Arch Linux
> Используйте `useradd`, `usermod`, `userdel`, `groupadd`, `groupdel` и `gpasswd`. Не рассчитывайте на Debian-обёртки `adduser`/`deluser` или группы `sudo`/`www-data`. Для обычной учётной записи без административных прав, при установленном Fish:
>
> ```bash
> sudo useradd -m -s /usr/bin/fish username
> sudo passwd username
> sudo gpasswd -d username groupname
> ```
>
> Перед назначением shell проверьте `command -v fish` и `/etc/shells`. Основная группа зависит от настроек `useradd` и `USERGROUPS_ENAB`; нельзя считать её создание безусловным для всех систем. После изменения групп войдите заново: уже запущенные процессы сохраняют прежний набор групп. Источники: [Users and groups](https://wiki.archlinux.org/title/Users_and_groups), [usermod(8)](https://man.archlinux.org/man/usermod.8.en). Для административных прав см. [[OS/Linux/Administration/Root и Sudo]].
