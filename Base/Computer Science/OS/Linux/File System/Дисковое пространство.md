## Утилита `df` — информация о дисковом пространстве

Команда `df` (disk free) отображает информацию об использовании дискового пространства всех смонтированных файловых систем.

### Базовое использование

```bash
df
```

### Полезные ключи

|Ключ|Описание|
|---|---|
|`-h`|Human-readable — размеры в КБ, МБ, ГБ|
|`-T`|Показывает тип файловой системы|
|`-i`|Показывает использование inodes (количество файлов)|

### Примеры

```bash
df -h                     # удобочитаемый вывод всех файловых систем
df -hT                    # добавить тип файловой системы
df -h /                   # информация только о корневой файловой системе
df -i                     # информация об использовании inodes
```

### Интерпретация вывода

Команда `df -h /` показывает:

- **Size** — общий размер раздела

- **Used** — занятое место

- **Available** — свободное место

- **Use%** — процент занятого места


Команда `df -i` показывает:

- **IUsed** — количество использованных inodes

- **IFree** — количество свободных inodes

- **IUse%** — процент использованных inodes


_Важно:_ в Linux невозможно создать новый файл, если закончились либо свободное место в мегабайтах, либо свободные inodes (квота на количество файлов).

### Определение точки монтирования устройства

При подключении внешнего носителя (флешки, CD-ROM, образа диска) он автоматически монтируется в `/media/<username>/<метка_устройства>`. Это можно увидеть в выводе `df -h`.



## Утилита `du` — оценка размера директорий и файлов

Команда `du` (disk usage) показывает, сколько места занимают файлы и директории.

### Базовое использование

```bash
du ~                      # размер домашней директории (с разбивкой по подпапкам)
```

### Полезные ключи

|Ключ|Описание|
|---|---|
|`-h`|Human-readable — размеры в КБ, МБ, ГБ|
|`-s`|Summary — только общий итог (без разбивки)|
|`-c`|Total — добавить строку с общим итогом в конце|
|`--exclude="шаблон"`|Исключить файлы, соответствующие шаблону|

### Примеры

```bash
du -sh ~                  # общий размер домашней директории
du -h --max-depth=1 ~     # размер файлов и папок первого уровня вложенности
du -ch *.txt              # размер всех .txt файлов с итогом
du -sh --exclude="*.txt"  # размер всех файлов, кроме .txt
```

## Дополнительные примеры df из урока о дисках


### Базовое использование

```bash
df -h                # human-readable (ГБ, МБ, КБ)
df -hT               # добавить тип файловой системы
df -hT /             # информация только о корневом разделе
```

### Фильтрация по типу файловой системы

```bash
df -hT -t ext4       # показать только разделы с ext4
```

### Информация об inodes

```bash
df -i                # использование inodes
df -ih               # с human-readable
```


## Дополнительные параметры и примеры du


### Полезные ключи

|Ключ|Описание|
|---|---|
|`-d N`|max depth — глубина вложенности|

### Примеры

```bash
du -sh ~             # размер домашней директории
du -h --max-depth=1  # размер файлов и папок первого уровня
du -ch *.txt         # размер всех .txt файлов с итогом
```

## Дополнения и особенности системы

> [!info] Arch Linux
> Путь `/media/<username>/...` в исходнике относится к конкретной конфигурации автомонтирования. В Arch с UDisks обычно используется `/run/media/$USER/`; проверяйте фактическую точку через `df -h` или `findmnt`. Подробнее: [[OS/Linux/File System/Структура каталогов Linux]].
