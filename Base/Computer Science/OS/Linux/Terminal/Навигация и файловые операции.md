# Навигация и файловые операции

[[OS/Linux/Linux|Карта Linux]] · Источник: Terminal Tools Курс

## Итог: навигация

В этом уроке рассмотрены базовые команды для навигации по файловой системе Linux:

|Команда|Назначение|
|---|---|
|`pwd`|Показать текущую директорию|
|`cd`|Сменить директорию (абсолютные и относительные пути, `..`, `~`, `-`)|
|`ls`|Просмотреть содержимое директории (ключи `-a`, `-l`, их комбинации)|
|`ll`|Псевдоним для `ls -al` (подробный список всех файлов)|

Эти команды являются основой для работы с файловой системой в терминале Linux. Понимание абсолютных и относительных путей, а также умение использовать ключи команды `ls` необходимо для дальнейшего изучения более сложных операций с файлами и директориями.


## Список изученных команд

|Команда|Назначение|Ключи/особенности|
|---|---|---|
|`mkdir`|Создание папок|`-p` — создание вложенной структуры|
|`touch`|Создание пустого файла или обновление даты файла|—|
|`echo > file`|Создание файла с содержимым|перезаписывает существующий|
|`> file`|Создание пустого файла|аналог `touch`|
|`cat > file`|Создание файла с многострочным вводом|завершение — `Ctrl + D`|
|`tree`|Просмотр структуры папок (требуется установка)|`sudo apt install tree`|

> [!warning] Требует проверки
> Строка «`> file` — аналог `touch`» опасна: в Bash перенаправление обнуляет существующий файл, а `touch` сохраняет его содержимое. Не используйте этот пример для проверки существования файла. См. [bash(1), REDIRECTION](https://man.archlinux.org/man/bash.1.en).


**Дополнительные важные понятия:**

- Регистрозависимость имён в Linux
- Использование `sudo` для операций в защищённых директориях
- Отличие абсолютных путей (начинаются с `/`) от относительных
- Расширения файлов не определяют тип содержимого


## Итог: копирование, перемещение и удаление

В этом уроке рассмотрены основные операции с файлами и папками:

|Команда|Назначение|Ключи|
|---|---|---|
|`cp`|Копирование файлов и папок|`-r` (для папок)|
|`mv`|Перемещение и переименование|—|
|`rm`|Удаление файлов и папок|`-r` (для папок), `-f` (принудительно)|

**Важные особенности:**

- В **Linux** переименование выполняется командой **`mv`**

- Шаблон **`*`** (звёздочка) используется для групповых операций с файлами

- Удаление через **`rm`** происходит безвозвратно, без перемещения в корзину

- Регистр букв в именах имеет значение (`folder1` ≠ `Folder1`)

- Будьте осторожны с командой **`rm -rf`** — это мощный инструмент, который при неосторожном использовании может привести к потере данных

## Дополнения и особенности системы

> [!info] Arch Linux
> Для примера `sudo apt install tree` эквивалент установки с обновлением системы — `sudo pacman -Syu tree`. `ll` — настраиваемый псевдоним/функция, его наличие и флаги не гарантированы; явная команда из курса — `ls -al`. См. [[OS/Linux/Terminal/Основы терминала и Shell]].

> [!info] Fish
> Шаблоны обрабатывает оболочка. При отсутствии совпадений `*.txt` Fish обычно выдаёт ошибку и не запускает команду. В `find -name "*.txt"` кавычки передают шаблон самому `find`. См. [Fish для пользователей Bash](https://fishshell.com/docs/current/fish_for_bash_users.html#wildcards-globs).

## Базовая работа в терминале

### Навигация и файлы

#### `cd`

Перейти в директорию.

```bash
cd /etc
cd ~
cd ..
```

#### `mkdir`

Создать директорию.

```bash
mkdir project
mkdir -p project/config
```

#### `touch`

Создать пустой файл.

```bash
touch app.log
```

#### `rm`

Удалить файл.

```bash
rm file.txt
```

#### `rm -rf`

Удалить директорию рекурсивно.

```bash
rm -rf directory
```

Использовать аккуратно: команда удаляет данные без корзины.

## Работа с файлами и файловой системой

Roadmap рекомендует углубиться в:

```text
find
locate
tree
ln
stat
file
```

### `tree`

Показать структуру каталогов деревом.

```bash
tree
```

### `stat`

Подробная информация о файле.

```bash
stat file.txt
```

### `file`

Определить тип файла.

```bash
file archive.tar.gz
```

## Терминал, файловая система и базовые команды

### Нужно понимать

- абсолютный и относительный путь;
- домашняя директория `~`;
- текущая директория `.`;
- родительская директория `..`;
- скрытые файлы;
- [[Inodes и ссылки|inode]] в общих чертах;
- hard link и symbolic link;
- стандартную структуру Linux:
    - `/etc`
    - `/var`
    - `/home`
    - `/tmp`
    - `/usr`
    - `/opt`
    - `/proc`
    - `/sys`
    - `/dev`
