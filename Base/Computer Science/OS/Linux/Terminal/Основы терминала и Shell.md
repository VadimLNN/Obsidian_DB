# Основы терминала и Shell

[[OS/Linux/Linux|Карта Linux]] · Источник: Terminal Tools Курс

> [!info] Дополнение к структуре курса
> Терминал обеспечивает текстовый ввод и вывод, а shell разбирает команды и запускает программы. Командная строка состоит из имени команды, параметров и аргументов. Встроенные команды выполняет сама оболочка; внешние программы ищутся по `PATH`. См. [терминологию Fish](https://fishshell.com/docs/current/language.html#terminology).

## Приёмы работы из курса

В этом уроке рассмотрены приёмы, повышающие эффективность работы в терминале:

1. **Очистка экрана** — `clear`, `Ctrl + L`, `reset`
2. **Редактирование строки** — `Ctrl + U` (удалить слева), `Ctrl + K` (удалить справа)
3. **Справочная система** — `whatis`, `help`, `--help`, `man`, `info`
4. **Поиск команд** — двойной `Tab`, `apropos`
5. **История команд** — `history`, `!номер`, `!!`, `!-N`, `Ctrl + R`, `history -c`, скрытие команд с помощью пробела

Эти приёмы позволяют быстрее находить нужную информацию, меньше печатать и эффективнее управлять сессией в терминале.

## Дополнения и особенности системы


> [!info] Arch Linux
> Оригинальные команды `apt` относятся к Ubuntu/Debian. В Arch используется `pacman`:
>
> ```bash
> sudo pacman -Syu              # обновить базы и всю систему
> sudo pacman -Syu tree         # обновить систему и установить tree
> pacman -Ss tree              # поиск пакетов
> pacman -Qi tree              # сведения об установленном пакете
> ```
>
> `pacman -S пакет` устанавливает пакет по имеющейся базе; `-Syu пакет` совмещает установку с полным обновлением. Не используйте `pacman -Sy пакет`: частичные обновления Arch не поддерживает. Имена пакетов и наличие утилит нужно проверять, а не переносить автоматически из `apt`. Источники: [pacman(8)](https://man.archlinux.org/man/pacman.8.en), [System maintenance](https://wiki.archlinux.org/title/System_maintenance#Partial_upgrades_are_unsupported).
