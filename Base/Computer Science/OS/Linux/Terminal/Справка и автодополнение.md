# Справка и автодополнение

[[OS/Linux/Linux|Карта Linux]] · Источник: Terminal Tools Курс

## Автодополнение и информация

|Сочетание клавиш|Действие|
|---|---|
|**Tab**|Автодополнение команды или имени файла/каталога|
|**Ctrl + I**|Аналогично **Tab** (автодополнение)|
|**~** затем **Tab Tab**|Показать список всех пользователей системы|
|**Alt + ?**|Показать список файлов и каталогов в текущем пути (справка)|
|**Alt + ***|Вставить имена всех файлов и каталогов в текущем пути как аргументы|

## Дополнения и особенности системы

> [!info] Дополнение к структуре курса
> Упомянутые в [[OS/Linux/Terminal/Основы терминала и Shell]] средства справки можно вызывать отдельно:
>
> ```bash
> whatis ls
> apropos archive
> ls --help
> man ls
> info coreutils
> help cd
> ```
>
> `help cd` здесь — встроенная справка Bash; остальные команды обращаются к установленной документации. См. [bash(1)](https://man.archlinux.org/man/bash.1.en).

> [!info] Arch Linux
> Для `man`, `whatis` и `apropos` может потребоваться пакет `man-db`; документация системных интерфейсов поставляется также в [man-pages](https://archlinux.org/packages/core/any/man-pages/), GNU Info — в [texinfo](https://archlinux.org/packages/core/x86_64/texinfo/). Наличие команды не гарантирует наличие документации ко всем программам. См. [man-db](https://archlinux.org/packages/core/x86_64/man-db/) и [[OS/Linux/Terminal/Основы терминала и Shell]].

> [!info] Fish
> `help` открывает документацию Fish; для встроенной команды удобно `set --help`. `Tab` показывает меню вариантов с описаниями. Bash/Readline-комбинации из исходной таблицы не являются универсальными для Fish. См. [справку и автодополнение Fish](https://fishshell.com/docs/current/interactive.html#help).
