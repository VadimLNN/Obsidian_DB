# Шпаргалка

[[OS/Linux/Linux|Карта Linux]]

Краткая навигационная выжимка из курса с отдельно отмеченными дополнениями. Имена файлов, пользователей и групп в примерах заменяйте своими. Опасные упражнения с разметкой и форматированием дисков оставлены в подробных заметках с предупреждениями.

## Навигация и файлы

Подробно: [[OS/Linux/Terminal/Навигация и файловые операции]], [[OS/Linux/File System/Структура каталогов Linux]].

| Команда | Назначение и полезные флаги | Пример |
|---|---|---|
| `pwd`, `cd` | Текущий каталог; переход: `..`, `~`, `-` | `cd /etc` |
| `ls` | Список: `-a` — скрытые, `-l` — подробно | `ls -al` |
| `mkdir` | Создание каталогов; `-p` — вложенные | `mkdir -p project/config` |
| `touch` | Создать пустой файл или обновить время | `touch notes.txt` |
| `cp` | Копировать; `-r` — каталог | `cp -r project backup` |
| `mv` | Переместить или переименовать | `mv old.txt new.txt` |
| `rm` | Удалить без корзины; `-r` — каталог | `rm old.txt` |
| `tree` | Показать дерево каталогов | `tree project` |

## Просмотр и поиск

Подробно: [[OS/Linux/Terminal/Просмотр файлов]], [[OS/Linux/Terminal/Поиск и обработка текста]].

| Команда | Назначение и полезные флаги | Пример |
|---|---|---|
| `cat` | Вывести или соединить файлы | `cat part1.txt part2.txt` |
| `less` | Постранично; `-N` — номера строк, `-i` — поиск без регистра | `less -N app.log` |
| `head`, `tail` | Начало/конец; `-n` — строки, `-c` — байты | `tail -n 20 app.log` |
| `find` | По имени: `-name`, `-iname`; глубина: `-maxdepth`; размер: `-size` | `find . -iname "*.txt"` |
| `grep` | Поиск: `-i`, `-n`; исключить: `-v`; только совпадение: `-o`; рекурсивно: `-r` | `grep -in error app.log` |
| `sort`, `uniq` | Сортировать; убрать соседние повторы | `sort names.txt \| uniq` |
| `wc` | Подсчёт; `-l` — строки | `wc -l app.log` |

## Потоки и выполнение команд

Подробно: [[OS/Linux/Terminal/Потоки и перенаправления]], [[OS/Linux/Terminal/Конвейеры и операторы]].

| Оператор | Значение | Пример |
|---|---|---|
| `>` / `>>` | Перезаписать / дописать stdout | `echo text >> notes.txt` |
| `2>` / `2>>` | Перезаписать / дописать stderr | `ls /root 2> errors.log` |
| `2>&1` | Направить stderr туда, куда сейчас направлен stdout | `ls /root > result.log 2>&1` |
| `<` | stdin из файла | `wc -l < notes.txt` |
| `\|` | stdout в stdin следующей команды | `cat app.log \| grep error` |
| `&&` | Следующая команда при успехе | `head notes.txt && echo Done` |
| `\|\|` | Следующая команда при ошибке | `head notes.txt \|\| echo Error` |
| `;` | Последовательно независимо от результата | `echo First; echo Second` |

`>` обнуляет существующий файл. Это не эквивалент `touch`.

## История, справка и редакторы

Подробно: [[OS/Linux/Terminal/История команд и горячие клавиши]], [[OS/Linux/Terminal/Справка и автодополнение]], [[OS/Linux/Terminal/Nano]], [[OS/Linux/Terminal/Vim]].

| Инструмент | Быстрые действия |
|---|---|
| Bash | `history`, `Ctrl+R`, `!!`; `help cd` |
| Справка | `man ls`, `ls --help`, `apropos archive` |
| Nano | `Ctrl+O` — запись, `Ctrl+X` — выход, `Ctrl+W` — поиск |
| Vim | `i` — вставка, `Esc` — нормальный режим, `:wq` — сохранить и выйти, `:q!` — отбросить изменения |

> [!info] Fish
> `history search текст`, `Ctrl+R`, ↑ и автоподсказки заменяют Bash-подстановки `!!` и `!номер`. `set -gx APP_ENV dev` экспортирует переменную; `echo $status` показывает код последней команды. Подробнее: [[OS/Linux/Terminal/Bash и Fish]].

## Архивы

Подробно: [[OS/Linux/Terminal/Архивирование и сжатие]].

| Команда | Назначение |
|---|---|
| `tar -czf backup.tar.gz folder/` | Создать архив gzip: `-c` создать, `-z` сжать, `-f` имя |
| `tar -tf backup.tar.gz` | Просмотреть содержимое: `-t` список |
| `tar -xzf backup.tar.gz` | Извлечь: `-x` распаковать |
| `zip -r backup.zip folder/` | ZIP с каталогом рекурсивно |
| `unzip backup.zip -d restored/` | Извлечь в указанный каталог |

## Диски и ссылки

Подробно: [[OS/Linux/File System/Дисковое пространство]], [[OS/Linux/File System/Диски и разделы]], [[OS/Linux/File System/Файловые системы и монтирование]], [[OS/Linux/File System/Inodes и ссылки]].

| Команда | Назначение |
|---|---|
| `df -hT` | Место и тип смонтированных файловых систем |
| `df -i /` | Использование inode |
| `du -sh folder/` | Суммарное место, занимаемое каталогом |
| `du -h --max-depth=1` | Размеры на первом уровне вложенности |
| `lsblk -f` | Устройства, файловые системы и UUID |
| `mount` | Список смонтированных файловых систем |
| `ls -li` | Inode и число жёстких ссылок |
| `ln source hardlink` | Жёсткая ссылка |
| `ln -s source symlink` | Символическая ссылка |

## Пользователи и права

Подробно: [[OS/Linux/Administration/Пользователи и группы]], [[OS/Linux/Administration/Root и Sudo]], [[OS/Linux/Administration/Права доступа]], [[OS/Linux/Administration/Владельцы файлов]], [[OS/Linux/Administration/Специальные права и umask]].

| Команда | Назначение |
|---|---|
| `whoami`, `id`, `groups` | Пользователь, UID/GID, группы |
| `sudo useradd -m username` | Создать пользователя с домашним каталогом |
| `sudo passwd username` | Задать пароль |
| `sudo usermod -aG groupname username` | Добавить в существующую группу, сохранив остальные |
| `sudo gpasswd -d username groupname` | Удалить из группы |
| `chmod 600 private.txt` | Чтение и запись только владельцу |
| `sudo chown username:groupname file` | Назначить владельца и группу |
| `umask` | Посмотреть маску создания файлов |

## Пакеты и логи

> [!info] Arch Linux
> `sudo pacman -Syu` — полное обновление; `sudo pacman -Syu tree` — обновление и установка пакета. Не используйте частичное обновление `-Sy пакет`. Для `sudo` обычно настраивают `wheel` через `visudo`, а не копируют группу `sudo` из Ubuntu. См. [[OS/Linux/Terminal/Основы терминала и Shell]] и [[OS/Linux/Administration/Root и Sudo]].
>
> `journalctl -b` — текущая загрузка; `journalctl -u sshd -n 100 --no-pager` — последние записи службы; `journalctl -u sshd -f` — новые записи. См. [[OS/Linux/Terminal/Поиск и обработка текста]].
