**JSX ([[JavaScript]] [[XML]])** — это расширение синтаксиса [[JavaScript]], которое позволяет разработчикам описывать структуру пользовательского интерфейса с помощью кода, визуально напоминающего [[HTML]]. Это основной способ определения того, что должен отображать компонент в React.

## Cамые важные аспекты темы JSX:

### 1. Природа и транспиляция

- **Это не HTML:** Несмотря на внешнее сходство, JSX не является [[HTML]]; это расширение [[JavaScript]].

- **Транспиляция:** Браузеры не могут исполнять JSX напрямую. Перед выполнением код должен быть преобразован в обычный JavaScript с помощью таких инструментов, как **Babel**.

- **Работа «под капотом»:** JSX компилируется в вызовы функции **`React.createElement()`**. Эта функция принимает тип элемента, объект со свойствами ([[Компоненты и Props#2. Props (Свойства)|props]]) и дочерние элементы (children).

### 2. Ключевые правила синтаксиса

- **Регистр имен:** Имена стандартных [[HTML-тег]]ов всегда пишутся со строчной буквы (например, `div`, `span`). Имена компонентов React **обязательно должны начинаться с заглавной буквы** (например, `<Alert />`), чтобы библиотека могла отличить их от обычных тегов.

- **Атрибуты ([[Компоненты и Props#2. Props (Свойства)|Props]]):** JSX использует **[[camelCase]]** для именования атрибутов вместо традиционных имен [[HTML]]. Например, вместо `class` используется `className`, а вместо `for` — `htmlFor`, так как `class` и `for` являются зарезервированными словами в [[JavaScript]].

- **Единственный корневой элемент:** Компонент должен возвращать только один корневой элемент. Если нужно вернуть несколько элементов без создания лишнего `div` в [[DOM]], используются **фрагменты** (`<>...</>` или `<React.Fragment>...</React.Fragment>`).

### 3. Встраивание логики и данных

- **Фигурные скобки `{}`:** Любое выражение [[JavaScript]] можно встроить непосредственно в JSX, обернув его в фигурные скобки. Это позволяет выводить значения переменных или результаты вычислений.

- **Условный рендеринг:** Поскольку конструкции `if-else` не работают внутри JSX, используются **тернарные операторы** (`условие ? истина : ложь`) или логическое сокращение `&&`.

- **Рендеринг списков:** Для отображения массивов данных используется метод **`.map()`**, который возвращает массив JSX-элементов. При этом каждому элементу списка необходимо передать уникальный атрибут **`key`**, чтобы React мог эффективно обновлять [[DOM]] при изменениях.

### 4. JSX и TypeScript

- В проектах с [[TypeScript]] файлы, содержащие JSX, должны иметь расширение **`.tsx`**. Это позволяет компилятору корректно обрабатывать синтаксис и обеспечивать типобезопасность свойств компонентов.

**Преимущество JSX** заключается в его декларативности: разработчик просто описывает желаемый результат, а React берет на себя синхронизацию интерфейса с данными.
