**Компоненты** и **Props** (свойства) являются фундаментальными строительными блоками любого [[React]]-приложения, позволяя разделять пользовательский интерфейс на независимые, переиспользуемые части.

### 1. Компоненты: основы

Компонент в React можно представить как запечатанную единицу функциональности, которая описывает, как должна выглядеть часть интерфейса.

- **Природа компонента:** По сути, это [[JavaScript]]-функция или класс, которые принимают входные данные и возвращают элементы [[React]] (обычно через [[JSX]]), описывающие экран.
- **Правило именования:** Имена компонентов **обязательно должны начинаться с заглавной буквы** (например, `<Alert />`). Если имя начинается со строчной буквы, React будет рассматривать его как обычный HTML-тег (например, `<div>`), что приведет к ошибке рендеринга.
- **Два типа компонентов:**
    - **Функциональные компоненты:** Обычные функции, возвращающие [[JSX]]. На сегодняшний день они являются доминирующими, так как требуют меньше кода и позволяют легче переиспользовать логику.
    - **Классовые компоненты:** Основаны на классах ES6, расширяющих `React.Component`, и обязательно содержат метод `render()`.

### 2. Props (Свойства)

**Props** (сокращение от _properties_) — это механизм передачи данных от родительского компонента к дочернему. Они делают компоненты гибкими и настраиваемыми.

- **Передача и получение:** В [[JSX]] свойства передаются как атрибуты: `<Welcome name="Alice" />`. Внутри функционального компонента они доступны как объект, передаваемый в качестве первого аргумента.
- **Неизменяемость (Read-only):** Это важнейшее правило: **компонент никогда не должен изменять свои props**. С точки зрения компонента, свойства являются входными данными, доступными только для чтения.
- **Однонаправленный поток данных:** Данные в [[React]] всегда передаются только в одном направлении — «сверху вниз», от родителя к потомку. Чтобы передать данные «вверх», родитель передает дочернему компоненту функцию через props, которую тот вызывает при необходимости.

### 3. Специальное свойство children

Существует зарезервированное свойство **`children`**. Оно используется для передачи контента, который помещается между открывающим и закрывающим тегами компонента:

```
<Alert>
  Это сообщение передается через свойство children
</Alert>
```

Внутри компонента `props.children` позволит отрендерить это содержимое в нужном месте.

### 4. Взаимодействие с TypeScript

При использовании [[TypeScript]] props становятся еще мощнее, так как их можно [[Типизация Props и State|строго типизировать]] с помощью интерфейсов или типов. Это позволяет:

- **Ловить ошибки на этапе разработки**, если вы забыли передать обязательное свойство или передали данные неверного типа.
- Использовать автодополнение (IntelliSense), которое подсказывает, какие свойства ожидает компонент.

### 5. Проблема "Prop Drilling"

При проектировании больших приложений вы можете столкнуться с ситуацией, когда данные нужно передать глубоко вложенному компоненту через множество промежуточных уровней, которым эти данные не нужны. Этот процесс называется **"[[Prop Drilling|prop drilling]]"** (прокидывание пропсов) и считается недостатком использования только свойств для управления глобальным состоянием. В таких случаях рекомендуется использовать более продвинутые инструменты, такие как **[[React Context]]** или **[[Redux]]**.
