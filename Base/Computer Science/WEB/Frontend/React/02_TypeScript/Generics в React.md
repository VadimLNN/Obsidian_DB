**Generics (универсальные типы)** в React — это мощный инструмент [[TypeScript]], который позволяет создавать компоненты, функции и хуки, способные работать с различными типами данных, сохраняя при этом строгую типизацию.

## Ключевые аспекты использования Generics в React-разработке.

### 1. Универсальные компоненты (Generic Components)

Компонент становится универсальным, когда его типы пропсов зависят от передаваемых данных. Типовой параметр обычно указывается в угловых скобках перед определением функции.

- **Пример использования:** Вы можете создать один компонент `GenericSelect` или `Checklist`, который будет одинаково корректно работать со списками книг, фильмов или сотрудников, подстраиваясь под структуру их объектов.
- **Гибкость:** Это позволяет избегать дублирования кода и «нормализации» данных только ради рендеринга. Вместо того чтобы заставлять все объекты иметь поля `id` и `title`, вы можете передать компоненту инструкции, какие ключи использовать.

### 2. Оператор `keyof` в связке с Generics

Оператор **`keyof`** генерирует тип из ключей объекта. В универсальных компонентах он незаменим для обеспечения безопасности:

- Если компонент принимает массив объектов и имя ключа, который нужно отобразить (например, `primaryKey`), [[TypeScript]] проверит, что этот ключ действительно существует в переданном типе данных.
- Это предотвращает ошибки опечаток и использование несуществующих свойств еще на этапе написания кода.

### 3. Generics в хуках React

Многие встроенные хуки [[React]] используют универсальные типы для определения структуры данных, с которыми они работают:

- **`useState<T>`:** Если начальное значение `null` или тип должен быть сложным (например, объединение строк), тип указывается явно: `useState<string | null>(null)`.
- **`useReducer<Reducer<State, Action>>`:** Позволяет строго типизировать состояние и все возможные действия в редукторе.
- **`useMemo<T>` и `useCallback<T>`:** Используются для явного указания типа возвращаемого значения или функции, когда автоматический вывод типов не дает нужного результата.

### 4. Продвинутые техники

- **Type Predicates (Предикаты типа):** При работе с универсальными типами часто требуется «сузить» тип переменной во время выполнения. Функции с оператором `is` (например, `value is string`) помогают TypeScript понять, с каким конкретным типом из объединения он имеет дело внутри блока `if`.
- **Ограничение Generic-типов:** Вы можете ограничить универсальный тип, используя ключевое слово `extends`. Например, `<T extends Base>` гарантирует, что любой переданный тип будет содержать как минимум обязательные поля, описанные в `Base` (например, `id`).
- **Наследование пропсов [[HTML]]:** С помощью `ComponentPropsWithoutRef<'ul'>` можно расширить пропсы универсального компонента всеми стандартными атрибутами HTML-элемента, что полезно для паттерна **[[Props Spreading]]**.

**Главное преимущество** использования Generics — это создание **типобезопасных переиспользуемых абстракций**. Компонент не просто принимает «любые» данные (как в случае с `any`), а «запоминает» их структуру, обеспечивая автодополнение и проверку ошибок во всех дочерних элементах.
