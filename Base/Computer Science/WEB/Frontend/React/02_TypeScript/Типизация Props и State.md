**Типизация Props и State** в [[React]] с использованием [[TypeScript]] позволяет создавать более надежный код, обеспечивая проверку типов на этапе разработки и улучшая взаимодействие с редактором кода через автодополнение (IntelliSense).

## Типизация Props (Свойств)

[[Компоненты и Props#2. Props (Свойства)|Props]] определяют «контракт» между родительским и дочерним компонентами.

• **Способы определения типов:** Для описания структуры объекта свойств чаще всего используются **псевдонимы типов (type) или интерфейсы (***interface****). Выбор между ними часто зависит от личных предпочтений, хотя псевдонимы типов считаются более гибкими для сложных структур.

• **Обязательные и необязательные свойства:** Чтобы пометить свойство как необязательное, после его имени ставится символ **?**. Если обязательное свойство не передано, [[TypeScript]] выдаст ошибку.

• **Специальный тип** **React.ReactNode****: Используется для типизации свойства `children`, так как оно может содержать не только строки, но и [[JSX]]-элементы, массивы или другие компоненты.

• **Применение:** Тип назначается компоненту при деструктуризации параметров: `export function MyComponent({ name }: Props) { ... }`.

## Типизация State (Состояния)

[[Состояние (State)|Состояние]] определяет внутреннюю логику и отображение компонента.

• **Вывод типов (Inference):** [[TypeScript]] умеет автоматически определять тип состояния на основе **начального значения**, переданного в `useState`. Например, `useState("")` автоматически сделает состояние строковым.

• **Явное указание через [[Generics в React|Generic]]:** Если начальное значение не позволяет точно определить тип (например, оно равно `null`) или тип должен быть сложным (Union), используется универсальный аргумент: `useState<Type>()`.

• **Объединения (Unions):** Позволяют ограничить состояние конкретным набором значений, например `useState<'Good' | 'Bad'>('Good')`.

• **Сложные объекты:** Для хука [[useReducer]] часто создаются отдельные типы для самого объекта состояния (`State`) и для всех возможных действий (`Action`), которые объединяются в Union-тип.

## Продвинутые техники типизации

Для создания по-настоящему гибких и переиспользуемых компонентов используются следующие инструменты:

1. **Generics (Универсальные типы):** Позволяют компоненту работать с различными типами данных, сохраняя при этом строгую типизацию. Это особенно полезно для списков и таблиц.

2. **Оператор** **[[Keyof и Indexed Types|keyof]]**: Генерирует тип, состоящий из ключей другого типа. Это гарантирует, что передаваемая в пропсы строка действительно является именем одного из свойств объекта данных.

3. **Type Predicates (Предикаты типа):** Функции вида `value is Type`, которые помогают [[TypeScript]] «сузить» (narrow) тип переменной в блоках `if`, чтобы безопасно обращаться к её свойствам.

4. **ComponentPropsWithoutRef**: Позволяет типу пропсов компонента наследовать все стандартные атрибуты [[HTML]]-элемента (например, `ul` или `button`), что удобно для паттерна **[[Props Spreading]]**.

Использование типизации позволяет обнаруживать ошибки (например, обращение к несуществующему свойству или передачу `null` в обязательное поле) еще до запуска приложения в браузере.
