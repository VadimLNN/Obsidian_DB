**useFetch** — это **пользовательский хук ([[Custom Hooks]])**, предназначенный для **извлечения логики сетевых запросов** из компонентов в отдельную переиспользуемую функцию. Он позволяет повторно использовать логику получения данных без дублирования кода, что делает компоненты более простыми и понятными.

## 1. Параметры и структура `useFetch`

```
function useFetch(url) {
  const [data, setData] = useState(null);
  
  useEffect(() => {
    fetch(url)
      .then(res => res.json())
      .then(setData);
  }, [url]); // Перезапуск при изменении URL
  
  return data;
}
```

Хук обычно принимает один аргумент:

1. **URL:** строковый адрес [[API]], к которому выполняется запрос.
2. **Возвращаемое значение:** данные, полученные в результате запроса (иногда также возвращаются состояния `isLoading` и `error`).

## 2. Управление жизненным циклом через зависимости

Поведение `useFetch` определяется массивом зависимостей внутреннего `useEffect`:

• **Массив** **url:** запрос будет выполняться повторно каждый раз, когда изменяется адрес ресурса.

• **Пустой массив** **[]****: если URL статичен, запрос выполнится только один раз при монтировании компонента.

## 3. Функция очистки (Cleanup) в `useFetch`

Для предотвращения утечек памяти и ошибок при размонтировании компонента (например, попытки обновить состояние уже удаленного компонента) внутри `useFetch` рекомендуется использовать **флаг отмены**.

• **Пример:** создание переменной `cancel`, которая становится `true` при размонтировании, блокируя вызов `setData`.

## 4. Правила использования

Как и любой хук, `useFetch` должен следовать общим правилам [[React]]:

• **Префикс** **use**: название обязательно должно начинаться с `use`, чтобы инструменты линтинга могли проверить соблюдение правил хуков.

• **Вызов стандартных хуков:** функция считается хуком только если она внутри вызывает `useState`, `useEffect` или другие хуки.

## 5. Работа с асинхронным кодом

Поскольку функция внутри `useEffect` не может быть `async`, в `useFetch` асинхронная работа реализуется либо через **цепочку** **.then()**, либо через **объявление асинхронной функции внутри** и её немедленный вызов.

## 6. Типичный пример использования

Компонент просто вызывает хук и получает готовые данные для отрисовки:

```
function Profile({ userId }) {
  const user = useFetch(`https://api.example.com/users/${userId}`);
  
  if (!user) return <div>Загрузка...</div>;
  return <h1>{user.name}</h1>;
}
```

Важные нюансы из источников:

• **Инкапсуляция:** Хук скрывает сложность работы с `fetch` и `json()`, предоставляя компоненту чистый интерфейс.

• **Типизация:** В проектах с [[TypeScript]] рекомендуется строго типизировать возвращаемые данные через **[[Generics в React|Generics]]**, чтобы избежать использования типа `any`.

• **Альтернативы:** В современных приложениях 2025-2026 гг. ручное создание `useFetch` часто заменяется мощными библиотеками вроде **TanStack Query (React Query)**, которые автоматически обрабатывают кэширование и фоновое обновление данных.
