Хук **`useMemo`** — это инструмент производительности в [[React]], который позволяет сохранять (мемоизировать) результат вычислений между рендерингами. Он полезен для предотвращения повторных ресурсозатратных вычислений при каждом обновлении компонента, если входные данные не изменились.

### 1. Параметры и синтаксис `useMemo`

```
const memoizedValue = useMemo(() => {
  // Выполнение ресурсозатратных вычислений
  return expensiveCalculation(a, b);
}, [a, b]); // Массив зависимостей
```

Хук принимает два аргумента:

1. **Функция вычисления:** должна быть «чистой», принимать зависимости и возвращать значение, которое необходимо мемоизировать.
2. **Массив зависимостей:** список значений, при изменении которых React заново вызовет функцию вычисления для получения нового результата.

### 2. Как это работает

- При первом рендеринге `useMemo` вызывает функцию и возвращает её результат.
- При последующих рендерингах React сравнивает текущие значения зависимостей с предыдущими. Если они идентичны, хук возвращает **уже вычисленное ранее значение**, не запуская функцию повторно.
- Если хотя бы одна зависимость изменилась, функция запускается снова, и React запоминает новый результат.

### 3. Использование с TypeScript

TypeScript обычно автоматически выводит тип возвращаемого значения, но при необходимости его можно указать явно через универсальный аргумент (generic):

```
const result = useMemo<number>(() => computeSomething(), []);
```

### 4. Когда использовать (и когда не стоит)

- **Дорогостоящие расчеты:** Идеально подходит для обработки больших массивов данных, сложных математических операций или преобразований объектов.
- **Стабильность ссылок:** Используется для сохранения ссылки на объект или массив, чтобы предотвратить лишние рендеринги дочерних компонентов, которые зависят от этих данных через `React.memo`.
- **Предостережение:** Не следует оборачивать в `useMemo` абсолютно все вычисления. Это увеличивает сложность кода и потребление памяти. Оптимизацию следует проводить только после измерения реальных проблем с производительностью.

### Важные нюансы из источников:

- **Риск "замирания" данных (Stale Values):** Если вы укажете пустой массив зависимостей `[]`, значение будет вычислено только один раз при монтировании. Если расчет зависит от переменных (`props` или `state`), которые не указаны в массиве, результат всегда будет содержать их устаревшие (начальные) значения.
- **Семантическая гарантия:** [[React]] рассматривает мемоизацию как подсказку, а не как 100% гарантию. В будущем библиотека может решить очистить кэш `useMemo` для освобождения ресурсов, поэтому код должен корректно работать, даже если расчет будет запущен повторно.
- **Чистота функций:** Внутри функции `useMemo` нельзя использовать побочные эффекты (запросы к [[API]], изменение [[DOM]]) — для этого предназначен `useEffect`.
