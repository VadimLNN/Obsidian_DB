Хук **`useState`** — это базовая функция в [[React]], которая позволяет добавлять [[Состояние (State)|состояние (state)]] в функциональные компоненты. Состояние представляет собой информацию о текущей ситуации в компоненте (например, данные формы, статус загрузки или видимость элементов), которая может меняться со временем.

### 1. Синтаксис и возвращаемое значение

```
const [state, setState] = useState(initialValue);
```

Хук принимает один аргумент:

1. **Начальное значение (initialValue):** значение, которое будет использоваться при первом рендеринге. Если значение не передано, оно будет `undefined`.

`useState` возвращает **кортеж (массив)** из двух элементов:

- **Текущее значение состояния:** переменная, хранящая данные.
- **Функция-сеттер:** функция для обновления этого значения. По общепринятой практике её называют так же, как переменную состояния, но с префиксом `set`.

### 2. Механизм обновления и рендеринга

- **Триггер обновлений:** Вызов функции обновления (например, `setScore(score + 1)`) заставляет React **повторно отрендерить** компонент, чтобы отразить изменения в интерфейсе.
- **Асинхронность и пакетная обработка (Batching):** Обновление состояния не происходит мгновенно. React собирает изменения в пакеты и применяет их перед следующим циклом рендеринга для оптимизации производительности.
- **Иммутабельность:** Состояние нельзя изменять напрямую (например, `state = newValue`). Для корректной работы React всегда необходимо использовать функцию-сеттер.

### 3. Использование с TypeScript

[[TypeScript]] обычно автоматически **выводит тип** состояния на основе начального значения. Однако в сложных случаях тип можно указать явно с помощью универсального аргумента (**[[Generics в React|generic]]**):

```
// Явное указание типа (может быть строкой или null)
const [email, setEmail] = useState<string | null>(null);
```

Это необходимо, когда начальное значение (например, `null`) не позволяет компилятору точно определить, какие данные будут храниться в переменной в будущем.

### 4. Правила использования

Как и все хуки, `useState` должен подчиняться строгим правилам:

- **Только на верхнем уровне:** Хук нельзя вызывать внутри условий, циклов или вложенных функций.
- **Только в функциональных компонентах:** Он не работает в классовых компонентах.

### 5. Когда выбирать `useState`

Этот хук идеально подходит для управления **простыми значениями** (примитивами), которые независимы друг от друга. Если логика состояния становится сложной (например, объект с множеством связанных свойств или когда новое состояние зависит от предыдущего), рекомендуется рассмотреть альтернативу — хук **`useReducer`**.

### Пример реализации:

```
import { useState } from 'react';

export function Counter() {
  // Инициализация состояния нулем
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Текущий счет: {count}
    </button>
  );
}
```
