Это встроенный механизм [[React]], который позволяет делиться состоянием между компонентами без ручного [[Prop Drilling|прокидывания пропсов]]. Однако обновления контекста заставляют всех потребителей перерендериваться, поэтому он лучше подходит для редко меняющихся данных.

• **Как это работает:** Сначала создается контекст через `createContext`. Затем используется компонент-провайдер (`Provider`), который оборачивает часть дерева компонентов и предоставляет им значение. Потребители получают доступ к этим данным через хук `useContext`.

• **Типичные случаи использования:** Данные об авторизации пользователя, темы оформления (темная/светлая), языковые настройки или флаги функций.

• **Ограничение:** Важно помнить, что **обновление контекста вызывает повторный рендеринг всех его потребителей**, поэтому в него не рекомендуют помещать часто меняющиеся значения.
