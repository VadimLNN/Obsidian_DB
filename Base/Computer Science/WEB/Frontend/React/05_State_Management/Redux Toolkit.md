Это официальный современный набор инструментов, созданный для **упрощения работы с [[Redux]] и уменьшения количества шаблонного кода (boilerplate)**.

• **Основные инструменты:**

- `configureStore`: Упрощает создание хранилища, автоматически настраивая инструменты разработчика и стандартное промежуточное ПО.
-  `createSlice:`Позволяет объединить логику действий (actions) и редукторов в одном месте, называемом "слайсом" (срезом).

• **Иммутабельность:** RTK использует внутри библиотеку **Immer**, которая позволяет писать код так, будто вы напрямую меняете [[Состояние (State)|состояние]] (мутируете его), но на самом деле она превращает эти действия в безопасные неизменяемые обновления.

• **RTK Query:** Специальный инструмент в составе RTK для упрощения загрузки, кэширования и управления данными с сервера.
