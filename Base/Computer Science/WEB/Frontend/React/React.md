## Модуль 1: Основы и рендеринг

• **[[Декларативный подход и Virtual DOM]]:** Разберитесь, как React эффективно обновляет интерфейс через механизм сверки (reconciliation).
• **[[JSX]]:** Изучите синтаксис JavaScript XML, правила вложенности и типичные ошибки (например, необходимость заглавной буквы в названии компонента).
• **[[Компоненты и Props]]:** Поймите концепцию компонентов как строительных блоков и научитесь передавать данные через свойства (props).
• **[[Состояние (State)]]:** Изучите хук `useState` и правила изменения состояния (иммутабельность).

## Модуль 2: React + TypeScript

• **[[Типизация Props и State]]:** Научитесь создавать интерфейсы и типы для входных данных и состояний компонентов.
• **[[Generics в React]]:** Изучите использование обобщений для создания переиспользуемых компонентов (например, универсальных списков или таблиц).
• **[[Keyof и Indexed Types]]:** Продвинутые техники типизации для работы со свойствами объектов в компонентах.

## Модуль 3: Хуки и логика (Hooks)

• [[Хуки (Hooks)]]: Что это и зачем.
• **[[useEffect]]:** Управление побочными эффектами (сетевые запросы, подписки) и очистка ресурсов.
• **[[useReducer]]:** Управление сложным состоянием, когда изменения зависят от предыдущих значений.
• **[[useRef]]:** Доступ к [[DOM]]-узлам и хранение изменяемых значений без перерендера.
• **[[useMemo]] и [[useCallback]] (Оптимизация):** Мемоизация вычислений и функций для предотвращения лишних отрисовок.
• **[[Custom Hooks]]:** Извлечение логики в переиспользуемые хуки (например, [[useFetch]]).

## Модуль 4: Экосистема (Routing, Forms, Styling)

• **[[Routing (React Router)]]:** Навигация, параметры маршрутов, вложенные роуты и ленивая загрузка (lazy loading).
• **[[Формы]]:** Контролируемые и неконтролируемые поля, использование библиотек вроде **React Hook Form** для валидации и производительности.
• **[[Стилизация]]:** Сравните подходы: CSS Modules, Tailwind CSS и CSS-in-JS (Emotion).

## Модуль 5: Управление состоянием и Данные

• **[[React Context]]:** Обмен данными между глубоко вложенными компонентами без "прокидывания" пропсов ([[Prop Drilling|prop drilling]]).
• **[[Redux Toolkit]]:** Централизованное управление состоянием через хранилище (store), действия (actions) и редукторы (reducers).
• **[[TanStack Query (React Query)]]:** Управление серверным состоянием, кэширование и оптимистичные обновления.

## Модуль 6: Продвинутые паттерны и Архитектура

• **[[Паттерны проектирования]]:** Compound Components (составные компоненты), Render Props, Slots и Higher-Order Components (HOC).
• **[[Feature-Based Folder Structure]]:** Организация файлов не по типу (components/hooks), а по функциональным фичам (features/auth, features/dashboard).
• **[[Разделение состояний]]:** Четкое ментальное разделение на UI state, App state и Server state.

## Модуль 7: Современные тренды и Тестирование

• **[[Testing|Тестирование]]:** Unit-тесты с использованием **Jest** и **React Testing Library** (фокус на взаимодействии пользователя, а не на реализации).
• **[[React Server Components (RSC)]]:** Перенос части рендеринга на сервер для улучшения производительности.
• **[[AI в разработке ("Vibe Coding")]]:** Использование AI-ассистентов (Cursor, Copilot) для генерации шаблонов и тестов, сохраняя критическое мышление и контроль над архитектурой.
