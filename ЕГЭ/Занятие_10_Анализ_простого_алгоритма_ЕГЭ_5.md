# Занятие 10. Анализ простого алгоритма

**ЕГЭ по информатике — задание №5**

Цель занятия: научиться быстро разбирать алгоритмы, которые:

- переводят число в двоичную систему;
- изменяют двоичную запись;
- дописывают или заменяют биты;
- считают единицы и нули;
- получают новое число `R`;
- требуют найти минимальное или максимальное исходное число `N`.

Для курса на **60+** это задание стоит считать обязательным.

---

# 1. Что обычно происходит в задании №5

Дано натуральное число:

```text
N
```

Над ним выполняется алгоритм.

Например:

```text
1. Строится двоичная запись числа N.
2. Если N чётное, справа дописывается 10.
3. Если N нечётное, справа дописывается 01.
4. Полученная запись переводится обратно в десятичную систему.
```

Полученное число обозначают:

```text
R
```

После этого спрашивают, например:

```text
найдите минимальное N, при котором R > 100
```

или:

```text
найдите максимальное N, при котором R < 300
```

---

# 2. Двоичная запись числа

В Python:

```python
bin(13)
```

даёт:

```text
0b1101
```

Обычно `0b` нам не нужно:

```python
s = bin(13)[2:]
```

Получим:

```text
1101
```

---

# 3. Перевод обратно в десятичную систему

```python
int("1101", 2)
```

получаем:

```text
13
```

То есть универсальная схема:

```python
s = bin(N)[2:]
# изменяем строку s
R = int(s, 2)
```

---

# 4. Дописывание справа

Если к двоичной записи дописать:

```text
0
```

значение числа увеличится в:

```text
2 раза
```

Например:

```text
101₂ = 5
1010₂ = 10
```

Если дописать два бита:

```text
00
```

число увеличивается в:

```text
4 раза
```

Но если дописываем:

```text
01
10
11
```

к умножению добавляется значение этих битов.

Например:

```text
N = 13
1101₂
```

дописали:

```text
10
```

получили:

```text
110110₂
```

В десятичной:

```text
13 · 4 + 2 = 54
```

# 5. Чётность числа

Для натурального числа:

```python
N % 2 == 0
```

— число чётное.

```python
N % 2 == 1
```

— нечётное.

Также последний бит двоичной записи показывает чётность:

```text
...0 → чётное
...1 → нечётное
```

```python
s.count("1")
```

```text

```

# 7. Чётность количества единиц

Проверка:

```python
s.count("1") % 2
```

Если результат:

```text
0
```

количество единиц чётное.

Если:

```text
1
```

нечётное.

---

# 8. Дописывание бита чётности

Алгоритм:

```text
если единиц чётное количество → дописать 0
если нечётное → дописать 1
```

На Python:

```python
s += str(s.count("1") % 2)
```

Это короткий и удобный приём.

---

# 9. Если действие выполняется два раза

Очень важно:

> после первого дописывания строка уже изменилась.

Например:

```python
for _ in range(2):
    s += str(s.count("1") % 2)
```

На второй итерации количество единиц считается уже **в новой строке**.

---

# 10. Самый надёжный способ решать №5

Не пытаться каждый раз выводить сложную формулу.

На ЕГЭ удобно написать перебор:

```python
for N in range(1, 1000):
    s = bin(N)[2:]

    # алгоритм из условия

    R = int(s, 2)

    if R > 100:
        print(N, R)
        break
```

Если нужен:

```text
минимальный N
```

то перебираем числа по возрастанию и используем:

```python
break
```

# 13. Семь алгоритмов для тренировки

В задачах ниже часто используются следующие алгоритмы.

## Алгоритм A

```text
1. Строится двоичная запись N.
2. Если N чётное, справа дописывается 10.
3. Если N нечётное, справа дописывается 01.
4. Получается число R.
```

Python:

```python
s = bin(N)[2:]

if N % 2 == 0:
    s += "10"
else:
    s += "01"

R = int(s, 2)
```

---

## Алгоритм B

```text
1. Строится двоичная запись N.
2. Справа дописывается бит чётности количества единиц.
3. Полученное действие повторяется ещё раз.
4. Получается R.
```

Python:

```python
s = bin(N)[2:]

for _ in range(2):
    s += str(s.count("1") % 2)

R = int(s, 2)
```

---

## Алгоритм C

```text
1. Строится двоичная запись N.
2. Если количество единиц чётное, справа дописывается 00.
3. Если количество единиц нечётное, справа дописывается 11.
4. Получается R.
```

---

## Алгоритм D

К двоичной записи числа справа дописывается двухбитная запись остатка:

```text
N mod 4
```

То есть:

```text
остаток 0 → 00
остаток 1 → 01
остаток 2 → 10
остаток 3 → 11
```

---

## Алгоритм E

```text
1. Строится двоичная запись N.
2. Дописывается бит, противоположный последнему.
3. Ещё раз дописывается бит, противоположный новому последнему.
```

---

## Алгоритм F

```text
1. Строится двоичная запись N.
2. Если N чётное, справа повторяются последние два бита записи.
3. Если N нечётное, слева дописывается 1, а справа 0.
```

---

## Алгоритм G

```text
1. Строится двоичная запись N.
2. Считается количество единиц.
3. Берётся остаток этого количества при делении на 4.
4. Его двухбитная запись дописывается справа.
```

Например:

```text
остаток 0 → 00
остаток 1 → 01
остаток 2 → 10
остаток 3 → 11
```

# 14. Типичные ошибки

## Ошибка 1. Оставить `0b`

Нельзя:

```python
s = bin(N)
```

если дальше планируется работать с символами двоичной записи.

Лучше:

```python
s = bin(N)[2:]
```

---

## Ошибка 2. Перевести строку без основания

Нельзя:

```python
int(s)
```

если `s` — двоичная запись.

Нужно:

```python
int(s, 2)
```

---

## Ошибка 3. Проверять чётность строки

Проверяем либо:

```python
N % 2
```

либо последний бит:

```python
s[-1]
```

---

## Ошибка 4. Не пересчитать количество единиц

Если алгоритм два раза дописывает бит по текущей записи, после первого шага строка меняется.

---

## Ошибка 5. Вывести R вместо N

Всегда ещё раз прочитай последнюю строку условия.

```python
    if R > 500:
        answer = min(answer, R)

print(answer)
```

# Как провести занятие за одну пару

```text
0–10 мин   — bin(), int(..., 2), строки
10–25 мин  — дописывание битов и чётность
25–40 мин  — количество единиц и бит чётности
40–55 мин  — минимальный N / максимальный N
55–75 мин  — самостоятельные задачи
75–90 мин  — задания формата ЕГЭ + разбор ошибок
```

---

# Что дать по уровням

## Начинающие

```text
1–20
21–25
```

Главная цель:

```text
понять преобразование N → двоичная запись → R
```

---

## Средние

```text
11–40
```

Главная цель:

```text
научиться быстро писать перебор
```

---

## Сильные

```text
21–50
```

Им полезно часть задач решать:

```text
1. через Python
2. затем попытаться объяснить математически
```

---

# Что ученик обязан вынести

```text
1. bin(N)[2:] — двоичная запись.

2. int(s, 2) — перевод обратно.

3. s.count("1") — число единиц.

4. N % 2 — чётность.

5. Минимальное N:
   перебор по возрастанию + break.

6. Максимальное N:
   сохраняем последнее подходящее.

7. Всегда проверяем:
   что требуется вывести — N или R.
```

Если эти семь вещей понятны, основная масса задания №5 решается короткой программой на Python.
