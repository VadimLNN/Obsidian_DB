# Занятие 11. Исполнитель Черепаха и алгоритмы на плоскости

**ЕГЭ по информатике — задание №6**

Цель занятия: научиться анализировать [[Base/Computer Science/NO theme/Algorithms|алгоритм]] исполнителя **Черепаха**, понимать получающуюся фигуру и считать целочисленные точки:

- внутри фигуры;
- на границе;
- внутри вместе с границей.

Для курса на **60+** задание №6 стоит считать обязательным.

---

# 1. Что проверяется в задании №6

Исполнитель Черепаха двигается по координатной плоскости.

Обычно в начале:

```text
Черепаха находится в точке (0; 0)
голова направлена вверх
хвост опущен
```

То есть начальное направление:

```text
положительное направление оси Y
```

При опущенном хвосте Черепаха оставляет линию.

---

# 2. Основные команды

## Вперёд n

```text
Вперёд 10
```

Черепаха перемещается на `10` единиц в направлении головы.

Если она смотрит вверх:

```text
(0; 0) → (0; 10)
```

---

## Направо m

```text
Направо 90
```

Черепаха поворачивает по часовой стрелке.

Если смотрела:

```text
север
```

после поворота смотрит:

```text
восток
```

---

## Налево m

Поворот против часовой стрелки.

```text
север → запад
```

при:

```text
Налево 90
```

---

# 3. Четыре основных направления

Удобно помнить:

```text
          север
            ↑
            |
запад  ←----+----→ восток
            |
            ↓
            юг
```

Если движение только под углами `90°`, координаты считаются очень просто.

| Направление | Изменение |
|---|---|
| север | `y += n` |
| юг | `y -= n` |
| восток | `x += n` |
| запад | `x -= n` |

# 4. Команда Повтори

Запись:

```text
Повтори 4 [
    Вперёд 10
    Направо 90
]
```

означает:

```text
Вперёд 10
Направо 90
Вперёд 10
Направо 90
Вперёд 10
Направо 90
Вперёд 10
Направо 90
```

Получится квадрат:

```text
10 × 10
```

# 7. Что такое целочисленная точка

Точка является целочисленной, если обе её координаты — целые числа.

Подходят:

```text
(0; 0)
(3; 7)
(-5; 2)
```

Не подходят:

```text
(1.5; 2)
(3; 4.2)
```

---

# 8. Квадрат

Пусть построен квадрат со стороной:

```text
a
```

Например:

```text
a = 6
```

## Точки строго внутри

По каждой координате:

```text
1, 2, 3, 4, 5
```

То есть:

```text
a - 1
```

вариантов.

Поэтому:

```text
I = (a - 1)^2
```

Для стороны `6`:

```text
I = 5² = 25
```

---

# 9. Прямоугольник

Если прямоугольник имеет стороны:

```text
a × b
```

то целочисленных точек **строго внутри**:

```text
I = (a - 1)(b - 1)
```

Например:

```text
8 × 5
```

```text
I = 7 · 4 = 28
```

---

# 10. Точки на границе прямоугольника

Для прямоугольника:

```text
a × b
```

количество целочисленных точек на границе:

```text
B = 2a + 2b
```

Например:

```text
8 × 5
```

```text
B = 16 + 10 = 26
```

---

# 11. Внутри + граница

У прямоугольника:

```text
(a + 1)(b + 1)
```

целочисленных точек внутри и на границе вместе.

Например:

```text
8 × 5
```

```text
9 · 6 = 54
```

---

# 12. Почему положение фигуры обычно не важно

Квадрат:

```text
от (0; 0) до (10; 10)
```

и квадрат:

```text
от (100; 50) до (110; 60)
```

имеют одинаковое количество целочисленных точек.

Если фигуру просто сдвинули на целое число единиц:

```text
ответ не меняется
```

---

# 13. Прямоугольный треугольник

Для простых треугольников можно использовать геометрию.

Пусть вершины:

```text
(0; 0)
(a; 0)
(0; b)
```

Площадь:

```text
S = a · b / 2
```

Но одной площади недостаточно, если нужно количество целочисленных точек.

Здесь удобно использовать **формулу Пика**.

---

# 14. Формула Пика

Для многоугольника с вершинами в целочисленных точках:

```text
S = I + B/2 - 1
```

где:

```text
S — площадь
I — количество целочисленных точек строго внутри
B — количество целочисленных точек на границе
```

Отсюда:

```text
I = S - B/2 + 1
```

---

# 15. Как найти точки на наклонном отрезке

Для отрезка между:

```text
(x1; y1)
(x2; y2)
```

используем:

```text
gcd(|x2 - x1|, |y2 - y1|)
```

При подсчёте всей границы многоугольника:

```text
B = сумма gcd для всех сторон
```

Пример.

Отрезок:

```text
(0; 0) → (8; 6)
```

```text
gcd(8, 6) = 2
```

---

# 16. Пример с треугольником

Вершины:

```text
(0; 0)
(8; 0)
(0; 6)
```

Площадь:

```text
S = 8 · 6 / 2 = 24
```

Граница:

```text
нижняя сторона: gcd(8, 0) = 8
левая сторона:  gcd(0, 6) = 6
диагональ:      gcd(8, 6) = 2
```

```text
B = 8 + 6 + 2 = 16
```

По формуле Пика:

```text
I = 24 - 16/2 + 1
```

```text
I = 17
```

# 18. Python Turtle

Для визуальной проверки можно использовать стандартный модуль `turtle`.

```python
from turtle import *

tracer(0)

left(90)

for _ in range(4):
    forward(100)
    right(90)

update()
done()
```

На реальном ЕГЭ масштаб часто увеличивают:

```python
k = 20
forward(10 * k)
```

чтобы фигура была крупнее.

---

# 19. Сетка в Turtle

Для визуального подсчёта удобно рисовать точки сетки.

Пример:

```python
from turtle import *

tracer(0)

k = 20

# фигура
left(90)

for _ in range(4):
    forward(6 * k)
    right(90)

# точки сетки
penup()

for x in range(-10, 11):
    for y in range(-10, 11):
        goto(x * k, y * k)
        dot(4)

update()
done()
```

Это полезно для проверки, но на простом квадрате быстрее использовать формулу.

# 20. Когда что использовать

## Квадрат / прямоугольник

Используй формулу:

```text
(a - 1)(b - 1)
```

## Простой многоугольник с целыми вершинами

Используй:

```text
формулу Пика
```

## Сложная фигура

Можно:

```text
1. выписать координаты;
2. разбить фигуру на прямоугольники;
3. либо проверить через Turtle.
```

```text

```

```text

```

```text

```

# Python-шаблон для визуальной проверки

```python
from turtle import *

tracer(0)
screensize(3000, 3000)

k = 20

# начальное направление Черепахи в ЕГЭ
left(90)

# пример:
right(90)

for _ in range(4):
    forward(12 * k)
    left(90)

# сетка
penup()

for x in range(-20, 21):
    for y in range(-20, 21):
        goto(x * k, y * k)
        dot(3)

update()
done()
```

Важно:

```text
Turtle здесь нужен прежде всего для визуализации.
```

Если фигура — обычный квадрат или прямоугольник, быстрее решить её формулой.

# Что ученик обязан вынести

```text
1. Черепаха обычно начинает в (0; 0)
   и смотрит вверх.

2. Направо 90:
   север → восток → юг → запад.

3. Повтори k означает буквальное
   повторение всех команд внутри.

4. Для прямоугольника a × b:
   внутри = (a - 1)(b - 1).

5. На границе прямоугольника:
   B = 2a + 2b.

6. Для произвольного многоугольника
   с целочисленными вершинами:
   I = S - B/2 + 1.

7. Повторное прохождение по уже нарисованной линии
   не создаёт новую область.
```

Если это усвоено, большая часть задания №6 становится обычной геометрией, а не задачей про «Черепаху».
