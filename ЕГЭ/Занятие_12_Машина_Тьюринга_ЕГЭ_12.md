# Занятие 12. Машина Тьюринга — новая модель ЕГЭ №12

**ЕГЭ по информатике — задание №12, модель 2026 года**

> Важно: в ЕГЭ-2026 задание №12 изменилось.  
> Теперь в демонстрационной модели используется **исполнитель МТ — машина Тьюринга**.

Цель занятия: научиться читать таблицу команд машины Тьюринга, пошагово выполнять программу и решать обратные задачи по результату её работы.

Для курса на **60+** здесь не нужна глубокая теория вычислимости. Нужно уметь:

```text
читать команду
→ понимать движение головки
→ отслеживать состояние
→ видеть общий эффект алгоритма
→ считать, что изменилось на ленте
```

---

# 1. Как устроена машина Тьюринга

Есть:

```text
1. бесконечная лента;
2. ячейки ленты;
3. символ в каждой ячейке;
4. головка;
5. состояние головки;
6. таблица команд.
```

Лента выглядит примерно так:

```text
... | λ | λ | 1 | 0 | 1 | 1 | λ | λ | ...
                          ▲
                         q0
```

Здесь:

```text
λ — пустой символ
▲ — положение головки
q0 — текущее состояние
```

---

# 2. Алфавит

В каждой ячейке записан ровно один символ.

Например:

```text
λ
0
1
```

или:

```text
λ
X
Z
```

Пустые ячейки обозначим:

```text
λ
```

---

# 3. Состояния

Головка может находиться в состояниях:

```text
q0
q1
q2
...
```

Начальное состояние:

```text
q0
```

Во время работы состояние может изменяться.

---

# 4. Как читать таблицу программы

Пример:

|   | `λ` | `0` | `1` |
|---|---|---|---|
| `q0` | `λ, L, q1` |  |  |
| `q1` | `λ, S, q1` | `1, L, q1` | `0, S, q1` |

Чтобы выбрать команду, смотрим одновременно:

```text
текущее состояние
+
символ под головкой
```

Например:

```text
состояние q1
символ 0
```

значит выполняем:

```text
1, L, q1
```

---

# 5. Формат команды

Команда состоит из трёх частей:

```text
новый_символ, движение, новое_состояние
```

Например:

```text
0, L, q3
```

означает:

```text
1. записать в текущую ячейку 0;
2. сдвинуть головку влево;
3. перейти в состояние q3.
```

---

# 6. Команды движения

## `L`

```text
Left
```

Головка перемещается:

```text
на одну ячейку влево
```

---

## `R`

```text
Right
```

Головка перемещается:

```text
на одну ячейку вправо
```

---

## `N`

```text
No movement
```

Головка:

```text
остаётся в той же ячейке
```

Но программа продолжает работу.

---

## `S`

```text
Stop
```

После записи символа исполнитель:

```text
завершает работу
```

Перемещения после `S` нет.

---

# 7. Порядок действий за один такт

Команда:

```text
1, L, q2
```

выполняется строго так:

```text
1. записать символ 1;
2. сдвинуться влево;
3. перейти в q2.
```

Важно:

```text
сначала запись
потом движение
```

# 8. Первый простой пример

Начальная лента:

```text
... λ λ 0 λ λ ...
        ▲
        q0
```

Команда:

```text
1, R, q1
```

После одного такта:

```text
... λ λ 1 λ λ ...
          ▲
          q1
```

# 9. Пример с отсутствием движения

Команда:

```text
X, N, q2
```

означает:

```text
записать X
не двигаться
перейти в q2
```

Головка остаётся над той же ячейкой, но на следующем такте будет использоваться уже строка:

```text
q2
```

и новый символ:

```text
X
```

# 10. Пример остановки

Команда:

```text
0, S, q1
```

означает:

```text
записать 0
и сразу завершить программу
```

Состояние `q1` в записи команды формально указано, но следующего такта уже не будет.

# 11. Машина A — заменить все Z на X

Используем программу:

|   | `λ` | `Z` |
|---|---|---|
| `q0` | `λ, L, q1` |  |
| `q1` | `λ, S, q1` | `X, L, q1` |

Начально головка стоит:

```text
в первой пустой ячейке справа от блока Z
```

Например:

```text
... λ Z Z Z Z λ ...
              ▲ q0
```

### Что делает программа

Первый шаг:

```text
q0 + λ
→ λ, L, q1
```

Головка попадает на последний `Z`.

Далее:

```text
каждый Z превращается в X
головка идёт влево
```

После последнего `Z` головка встречает:

```text
λ
```

и останавливается.

Результат:

```text
ZZZZ → XXXX
```

# 12. Машина B — пройти справа по нулям

Это особенно важный тип для новой модели №12.

Программа:

|   | `λ` | `0` | `1` |
|---|---|---|---|
| `q0` | `λ, L, q1` |  |  |
| `q1` | `λ, S, q1` | `1, L, q1` | `0, S, q1` |

Головка начинает:

```text
в ближайшей пустой ячейке справа от последовательности
```

Алгоритм:

```text
1. перейти на последний символ;
2. пока встречаются 0:
      заменить 0 → 1
      идти влево;
3. встретив первую 1:
      заменить 1 → 0
      остановиться.
```

Если единиц вообще нет:

```text
все нули заменятся единицами
```

и программа остановится на пустой ячейке слева.

---

# 13. Пример машины B

Начальная последовательность:

```text
10100
```

Справа находятся два нуля.

Работа:

```text
10100
    ↑

10101
   ↑

10111
  ↑
```

Теперь встречена `1`.

Она превращается в:

```text
0
```

Итог:

```text
10011
```

---

# 14. Как меняется количество нулей

Пусть:

```text
z — количество нулей в исходной строке
k — количество нулей в конце строки
```

Если перед этими нулями есть хотя бы одна `1`, то:

```text
k конечных нулей превращаются в единицы
```

То есть нулей становится меньше на:

```text
k
```

Но первая встреченная единица превращается в ноль:

```text
+1 ноль
```

Поэтому:

```text
z_final = z_initial - k + 1
```

---

# 15. Очень важные частные случаи

## Последний символ — `1`

Тогда:

```text
k = 0
```

Сразу:

```text
1 → 0
```

Поэтому количество нулей:

```text
увеличится на 1
```

---

## Вся строка состоит из нулей

Тогда:

```text
все 0 → 1
```

И в результате:

```text
нулей = 0
```

---

# 16. Почему это похоже на двоичное вычитание

Например:

```text
10100₂ = 20
```

После машины B:

```text
10011₂ = 19
```

То есть машина фактически выполняет:

```text
N → N - 1
```

для обычной двоичной записи положительного числа.

Но в ЕГЭ часто не требуется вообще переводить число в десятичную систему.

Выгоднее анализировать:

```text
сколько символов какого типа изменилось
```

# 17. Машина C — прибавление единицы

Программа:

|   | `λ` | `0` | `1` |
|---|---|---|---|
| `q0` | `λ, L, q1` |  |  |
| `q1` | `1, S, q1` | `1, S, q1` | `0, L, q1` |

Алгоритм:

```text
справа идём через единицы
1 → 0

первый 0:
0 → 1
Stop
```

Например:

```text
10111 → 11000
```

Это соответствует:

```text
N → N + 1
```

# 18. Машина D — инверсия всех битов

Программа:

|   | `λ` | `0` | `1` |
|---|---|---|---|
| `q0` | `λ, L, q1` |  |  |
| `q1` | `λ, S, q1` | `1, L, q1` | `0, L, q1` |

Получаем:

```text
0 → 1
1 → 0
```

для всей последовательности.

Например:

```text
010011
```

превращается в:

```text
101100
```

---

# 19. Машина E — стереть всю последовательность

Программа:

|   | `λ` | `0` | `1` |
|---|---|---|---|
| `q0` | `λ, L, q1` |  |  |
| `q1` | `λ, S, q1` | `λ, L, q1` | `λ, L, q1` |

Все встреченные:

```text
0
1
```

заменяются на:

```text
λ
```

То есть последовательность полностью стирается.

# 20. Как решать №12

## Тип 1. Маленькая лента

Выполняем программу вручную:

```text
шаг за шагом
```

Полезно записывать:

```text
лента | позиция | состояние
```

---

## Тип 2. Длинная последовательность

Например:

```text
1000 символов
```

Нельзя симулировать каждый шаг вручную.

Нужно понять:

```text
что делает программа в целом
```

Например:

```text
все конечные нули → единицы
первая единица слева от них → ноль
```

После этого задача становится арифметической.

---

# 21. Минимальный Python-симулятор

Для проверки маленьких примеров можно написать симулятор.

```python
from collections import defaultdict

BLANK = "λ"

tape = defaultdict(lambda: BLANK)

word = "10100"

for i, ch in enumerate(word):
    tape[i] = ch

head = len(word)
state = "q0"
```

Программа машины B:

```python
program = {
    ("q0", "λ"): ("λ", "L", "q1"),
    ("q1", "0"): ("1", "L", "q1"),
    ("q1", "1"): ("0", "S", "q1"),
    ("q1", "λ"): ("λ", "S", "q1"),
}
```

Цикл:

```python
while True:
    symbol = tape[head]
    write, move, state = program[(state, symbol)]

    tape[head] = write

    if move == "S":
        break

    if move == "L":
        head -= 1
    elif move == "R":
        head += 1
```

Но для самого ЕГЭ чаще быстрее понять программу логически.

# 22. Типичные ошибки

## Ошибка 1

Смотреть только на символ, забывая состояние.

Команда определяется парой:

```text
состояние + символ
```

---

## Ошибка 2

Сначала двигать головку, потом записывать.

Правильно:

```text
запись → движение → новое состояние
```

---

## Ошибка 3

Считать `N` остановкой.

```text
N = не двигаться
S = остановиться
```

---

## Ошибка 4

После `S` продолжать программу.

Нельзя.

```text
S → работа завершена
```

---

## Ошибка 5

На строке из 1000 символов выполнять 1000 шагов вручную.

Нужно искать:

```text
общий эффект алгоритма
```

# Универсальная идея для машины B

Если перед конечными нулями есть единица:

```text
z_final = z_initial - k + 1
```

где:

```text
k = количество нулей в конце исходной строки
```

Отсюда:

```text
z_initial = z_final + k - 1
```

Для максимума исходных нулей:

```text
увеличиваем k
```

Для минимума:

```text
берём k = 0
```

Но всегда отдельно проверяем случай:

```text
исходная строка состоит только из нулей
```
