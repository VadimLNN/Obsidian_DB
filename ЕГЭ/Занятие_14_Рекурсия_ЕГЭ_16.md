# Занятие 14. Рекурсия и рекуррентные выражения

**ЕГЭ по информатике — задание №16**

Цель занятия: научиться понимать рекурсивную функцию, вычислять её значения и видеть случаи, когда прямой рекурсивный вызов в Python — плохая идея.

Основные типы №16:

- один предыдущий вызов `F(n - 1)`;
- два предыдущих значения;
- ветвление по чётности;
- рекурсия по цифрам числа;
- рекурсия по двоичной записи;
- большие значения `n`;
- сокращение отношений и разностей;
- распознавание простой закономерности.

---

# 1. Что такое рекурсия

Рекурсия — ситуация, когда функция вызывает саму себя.

Пример:

```python
def F(n):
    if n == 1:
        return 1

    return F(n - 1) + 2
```

При вызове:

```text
F(4)
```

получаем:

```text
F(4)
= F(3) + 2
= F(2) + 2 + 2
= F(1) + 2 + 2 + 2
= 7
```

---

# 2. Базовый случай

У рекурсивной функции обязательно должен быть случай, в котором она перестаёт вызывать себя.

Например:

```python
if n == 1:
    return 1
```

Это:

```text
базовый случай
```

Без него рекурсия не остановится.

---

# 3. Рекурсивный случай

Остальная часть:

```python
return F(n - 1) + 2
```

— рекурсивный случай.

То есть:

```text
F(n) выражается через меньшее значение аргумента
```

---

# 4. Как читать математическую запись

Запись:

```text
F(1) = 1
F(n) = F(n - 1) + 2, при n > 1
```

в Python:

```python
def F(n):
    if n == 1:
        return 1

    return F(n - 1) + 2
```

---

# 5. Пример вычисления вручную

Пусть:

```text
F(1) = 2
F(n) = F(n - 1) + n
```

Найдём:

```text
F(4)
```

Получаем:

```text
F(1) = 2
F(2) = 2 + 2 = 4
F(3) = 4 + 3 = 7
F(4) = 7 + 4 = 11
```

Для небольших `n` такой способ часто быстрее написания программы.

---

# 6. Два предыдущих значения

Например:

```text
F(1) = 1
F(2) = 1
F(n) = F(n - 1) + F(n - 2)
```

Это последовательность Фибоначчи.

```text
F(1) = 1
F(2) = 1
F(3) = 2
F(4) = 3
F(5) = 5
...
```

Python:

```python
def F(n):
    if n == 1:
        return 1

    if n == 2:
        return 1

    return F(n - 1) + F(n - 2)
```

---

# 7. Проблема наивной рекурсии

Функция:

```python
def F(n):
    if n <= 2:
        return 1

    return F(n - 1) + F(n - 2)
```

для:

```text
F(5)
```

нормальна.

Но для:

```text
F(50)
```

будет огромное количество повторных вызовов.

Например:

```text
F(48)
```

вычисляется много раз.

---

# 8. Мемоизация

Можно запоминать уже найденные значения:

```python
from functools import lru_cache

@lru_cache(None)
def F(n):
    if n <= 2:
        return 1

    return F(n - 1) + F(n - 2)
```

Теперь каждый:

```text
F(k)
```

вычисляется один раз.

---

# 9. Но мемоизация решает не всё

Для:

```text
F(100000)
```

рекурсивный вызов:

```text
F(n - 1)
```

может упереться в ограничение глубины рекурсии.

Поэтому для огромных `n` лучше:

```text
1. вывести закономерность;
2. перейти к циклу;
3. сократить выражение.
```

---

# 10. Цикл вместо рекурсии

Пусть:

```text
F(1) = 1
F(n) = F(n - 1) + 2n
```

Можно написать:

```python
f = 1

for n in range(2, 101):
    f += 2 * n

print(f)
```

Для последовательной зависимости это часто лучше прямой рекурсии.

---

# 11. Ветвление

Например:

```text
F(0) = 0

F(n) = F(n / 2), если n чётно

F(n) = 1 + F(n - 1), если n нечётно
```

Python:

```python
def F(n):
    if n == 0:
        return 0

    if n % 2 == 0:
        return F(n // 2)

    return 1 + F(n - 1)
```

---

# 12. Что делает эта функция

Посмотрим:

```text
F(13)
```

Двоичная запись:

```text
13 = 1101₂
```

В ней:

```text
3 единицы
```

И:

```text
F(13) = 3
```

Эта функция фактически считает:

```text
количество единиц в двоичной записи числа
```

Почему?

Если число чётное:

```text
...0₂
```

деление на 2 просто удаляет последний `0`.

Количество единиц не меняется.

Если число нечётное:

```text
...1₂
```

мы прибавляем:

```text
1
```

за последний единичный бит.

---

# 13. Рекурсия по цифрам числа

Очень распространённый тип:

```text
F(0) = 0
F(n) = F(n // 10) + n % 10
```

Что происходит?

```text
n % 10
```

— последняя цифра.

```text
n // 10
```

— число без последней цифры.

Следовательно функция считает:

```text
сумму цифр числа
```

---

# 14. Пример

```text
F(2026)
```

```text
F(2026)
= F(202) + 6
= F(20) + 2 + 6
= F(2) + 0 + 2 + 6
= F(0) + 2 + 0 + 2 + 6
= 10
```

---

# 15. Можно считать не все цифры

Например:

```python
def F(n):
    if n == 0:
        return 0

    digit = n % 10

    if digit % 2 == 0:
        return F(n // 10) + digit

    return F(n // 10)
```

Такая функция считает:

```text
сумму чётных цифр
```

---

# 16. Подсчёт количества цифр

```python
def F(n):
    if n == 0:
        return 0

    return F(n // 10) + 1
```

Для положительного числа функция возвращает:

```text
количество цифр
```

---

# 17. Большие значения и закономерности

Пусть:

```text
F(0) = 0

F(n) = F(n - 1) + 2n - 1, если n нечётно

F(n) = 4F(n / 2), если n чётно
```

Проверим:

```text
F(1) = 1
F(2) = 4
F(3) = 9
F(4) = 16
F(5) = 25
```

Видим:

```text
F(n) = n²
```

Если это доказано или уверенно замечено, задачу:

```text
F(100000)
```

не нужно вычислять рекурсией.

Можно сразу:

```text
100000²
```

---

# 18. Отношения

Пусть:

```text
F(1) = 1
F(n) = n · F(n - 1)
```

Тогда:

```text
F(n) = n!
```

Например:

```text
F(100) / F(98)
```

Не нужно считать `100!`.

```text
F(100) = 100 · 99 · F(98)
```

Следовательно:

```text
F(100) / F(98) = 100 · 99
```

---

# 19. Разности

Если:

```text
F(n) = F(n - 1) + n²
```

то:

```text
F(100) - F(97)
```

равно только:

```text
98² + 99² + 100²
```

Всё предыдущее сокращается.

---

# 20. Взаимная рекурсия

Иногда есть две функции:

```text
F(n)
G(n)
```

Например:

```text
F(1) = 1
G(1) = 2

F(n) = F(n - 1) + G(n - 1)

G(n) = F(n - 1) + 2G(n - 1)
```

Тогда значения считаем парами:

```text
n = 1:
F = 1
G = 2

n = 2:
F = 3
G = 5

n = 3:
F = 8
G = 13
```

---

# 21. Остаток и целая часть

В №16 активно используются:

```text
n % 10
n // 10
n % 2
n // 2
```

Нужно понимать их без раздумий.

Например:

```text
12345 // 10 = 1234
12345 % 10  = 5
```

# 23. Типичные ошибки

## Ошибка 1. Не заметить базовый случай

Например:

```text
F(1) = ...
F(2) = ...
```

а ученик продолжает применять общую формулу к `F(2)`.

---

## Ошибка 2. Использовать `/` вместо `//`

Для целочисленной рекурсии:

```python
n // 2
```

а не:

```python
n / 2
```

---

## Ошибка 3. Забыть `return`

Неправильно:

```python
F(n - 1) + 2
```

Правильно:

```python
return F(n - 1) + 2
```

---

## Ошибка 4. Наивно вызвать `F(100000)`

Для огромных аргументов сначала нужно подумать:

```text
можно ли упростить выражение?
```

---

## Ошибка 5. Не понять смысл рекурсии по цифрам

```text
n // 10
```

обычно означает:

```text
убираем последнюю цифру
```

# Разбор задач 41–50

## 41

Функция прибавляет только:

```text
положительные чётные цифры
```

Чтобы:

```text
F(n) = 0
```

в числе не должно быть цифр:

```text
2, 4, 6, 8
```

Разрешены:

```text
0, 1, 3, 5, 7, 9
```

Диапазон:

```text
1 000 000 ≤ n < 4 000 000
```

Первая цифра может быть:

```text
1 или 3
```

То есть:

```text
2 варианта
```

Для каждой из оставшихся шести цифр:

```text
6 вариантов
```

Получаем:

```text
2 · 6^6
```

```text
= 93312
```

**Ответ: 93312.**

## 45

В десятичной записи:

```text
5 нечётных цифр:
1, 3, 5, 7, 9
```

и:

```text
5 чётных:
0, 2, 4, 6, 8
```

Но первая цифра не может быть `0`.

Удобнее проверить перебором:

```python
count = 0

for n in range(100000, 1000000):
    odd = sum(int(d) % 2 == 1 for d in str(n))

    if odd == 2:
        count += 1

print(count)
```

Получаем:

```text
203125
```

**Ответ: 203125.**

## 46

Нужна минимальная семизначная запись.

Перебор:

```python
def F(n):
    if n == 0:
        return 0

    digit = n % 10

    if digit % 2 == 0:
        return F(n // 10) + digit

    return F(n // 10)

for n in range(1_000_000, 10_000_000):
    if F(n) == 30:
        print(n)
        break
```

Получаем:

```text
1006888
```

Проверка:

```text
1 + 0 + 0 + 6 + 8 + 8 + 8
```

Функция учитывает только чётные цифры:

```text
0 + 0 + 6 + 8 + 8 + 8 = 30
```

**Ответ: 1006888.**

## 47

Для данной функции:

```text
F(n) = n²
```

Поэтому:

```text
a² - b² = 945
```

Разложим:

```text
(a - b)(a + b) = 945
```

Нужно максимизировать:

```text
a - b
```

Подходящая пара множителей:

```text
27 · 35 = 945
```

Тогда:

```text
a - b = 27
a + b = 35
```

Получаем:

```text
a = 31
b = 4
```

**Ответ: 27.**

## 48

```text
F(n) = n!
```

```text
F(2026)
=
2026 · 2025 · 2024 · F(2023)
```

Следовательно:

```text
F(2026) / F(2023)
=
2026 · 2025 · 2024
```

```text
= 8303763600
```

**Ответ: 8303763600.**

# Как провести занятие за одну пару

Пример на 90 минут:

```text
0–10 мин   — что такое рекурсия и базовый случай
10–25 мин  — F(n-1), F(n-2), ручной расчёт
25–40 мин  — рекурсия по цифрам и битам
40–50 мин  — Python + memoization
50–65 мин  — большие n: сокращения и закономерности
65–80 мин  — самостоятельные задачи
80–90 мин  — сложные №16 и разбор
```

# Что ученик обязан вынести

```text
1. У рекурсии есть базовый случай.

2. Сначала всегда проверяем базовый случай,
   потом применяем рекурсивную формулу.

3. n // 10 убирает последнюю цифру.

4. n % 10 получает последнюю цифру.

5. n // 2 и n % 2 часто означают
   работу с двоичной записью.

6. Для двух рекурсивных ветвей полезна memoization.

7. Большое n нельзя автоматически считать
   прямой рекурсией.

8. В выражениях вида:
   F(100) - F(97)
   или
   F(100) / F(97)
   нужно искать сокращение.

9. Некоторые рекуррентные функции
   на самом деле задают очень простые функции:
   сумму цифр, bit_count, n², n! и т.д.
```

Для цели **60+** по №16 ключевой навык — не «уметь писать сложную рекурсию», а **понять, что именно делает данная рекуррентная функция и выбрать самый короткий способ вычисления ответа**.
