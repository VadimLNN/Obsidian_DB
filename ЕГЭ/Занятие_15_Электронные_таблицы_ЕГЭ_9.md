# Занятие 15. Электронные таблицы — основы

**ЕГЭ по информатике — задание №9**

Цель занятия: научиться уверенно работать с электронной таблицей и решать базовые задачи №9:

- понимать адреса ячеек и диапазоны;
- писать простые формулы;
- копировать формулы;
- различать относительные, абсолютные и смешанные ссылки;
- использовать `SUM / СУММ`, `AVERAGE / СРЗНАЧ`, `MIN / МИН`, `MAX / МАКС`;
- применять `COUNTIF / СЧЁТЕСЛИ`, `IF / ЕСЛИ`, `AND / И`, `OR / ИЛИ`;
- сортировать и фильтровать данные;
- проверять условия для каждой строки;
- считать строки, удовлетворяющие нескольким условиям.

> В актуальном №9 очень часто дана большая таблица, где **в каждой строке записано 4–7 чисел**.  
> Нужно проверить условия для каждой строки и посчитать подходящие строки.

---

# 1. Электронная таблица

Таблица состоит из:

```text
столбцов: A, B, C, ...
строк:    1, 2, 3, ...
```

Пересечение столбца и строки — **ячейка**.

Например:

```text
A1
C7
F125
```

---

# 2. Диапазон

Запись:

```text
A2:F2
```

означает все ячейки:

```text
A2, B2, C2, D2, E2, F2
```

Диапазон:

```text
B2:B100
```

— столбец `B` со 2-й по 100-ю строку.

---

# 3. Формула

Формула начинается со знака:

```text
=
```

Например:

```text
=A1+B1
```

или:

```text
=A1*2
```

или:

```text
=(A1+B1)/2
```

---

# 4. Основные арифметические операции

```text
+   сложение
-   вычитание
*   умножение
/   деление
^   степень
```

Пример:

```text
=A2^2
```

означает:

```text
A2²
```

---

# 5. Основные функции

Названия функций зависят от языка интерфейса.

| Назначение | Русское имя | Английское имя |
|---|---|---|
| сумма | `СУММ` | `SUM` |
| среднее | `СРЗНАЧ` | `AVERAGE` |
| минимум | `МИН` | `MIN` |
| максимум | `МАКС` | `MAX` |
| количество чисел | `СЧЁТ` | `COUNT` |
| условный подсчёт | `СЧЁТЕСЛИ` | `COUNTIF` |
| условие | `ЕСЛИ` | `IF` |
| логическое И | `И` | `AND` |
| логическое ИЛИ | `ИЛИ` | `OR` |

В русской локали разделителем аргументов часто является:

```text
;
```

Например:

```text
=СЧЁТЕСЛИ(A2:F2;">10")
```

В другой локали может использоваться запятая.

---

# 6. Сумма

```text
=СУММ(A2:F2)
```

или:

```text
=SUM(A2:F2)
```

суммирует все числа строки.

---

# 7. Среднее арифметическое

```text
=СРЗНАЧ(A2:F2)
```

---

# 8. Минимум и максимум

```text
=МИН(A2:F2)
```

```text
=МАКС(A2:F2)
```

Это одни из самых полезных функций для №9.

---

# 9. СЧЁТЕСЛИ

Например:

```text
=СЧЁТЕСЛИ(A2:F2;">10")
```

считает, сколько чисел в диапазоне больше `10`.

Чтобы узнать, сколько раз число из `A2` встречается в строке:

```text
=СЧЁТЕСЛИ($A2:$F2;A2)
```

Это особенно важно для задач на:

```text
повторяющиеся числа
```

---

# 10. ЕСЛИ

```text
=ЕСЛИ(A2>B2;1;0)
```

Если:

```text
A2 > B2
```

ячейка получит:

```text
1
```

иначе:

```text
0
```

Удобная идея для ЕГЭ:

```text
подходит строка → 1
не подходит     → 0
```

Потом просто:

```text
СУММ
```

по столбцу результатов.

---

# 11. Логическое И

Если должны выполняться **оба условия**:

```text
=И(условие1;условие2)
```

Например:

```text
=И(МАКС(A2:D2)<СУММ(A2:D2)-МАКС(A2:D2);
   МИН(A2:D2)>0)
```

---

# 12. Логическое ИЛИ

Если достаточно хотя бы одного условия:

```text
=ИЛИ(условие1;условие2)
```

---

# 13. Относительная ссылка

Обычная ссылка:

```text
A2
```

— относительная.

Если формулу:

```text
=A2+B2
```

скопировать на одну строку вниз, получится:

```text
=A3+B3
```

Таблица сама изменяет адреса.

---

# 14. Абсолютная ссылка

```text
$A$1
```

не меняется при копировании.

Например:

```text
=A2*$D$1
```

Если скопировать формулу вниз:

```text
A2 → A3 → A4
```

но:

```text
$D$1
```

останется неизменным.

---

# 15. Смешанная ссылка

```text
$A2
```

фиксируется только столбец:

```text
A
```

Строка может меняться.

```text
A$2
```

фиксируется только строка:

```text
2
```

Столбец может меняться.

---

# 16. Зачем это нужно на ЕГЭ

Обычно формулу пишут:

```text
один раз
```

а затем копируют:

```text
на тысячи строк
```

Поэтому важно, чтобы ссылки менялись правильно.

---

# 17. Типичный №9 в 2026 году

Например, в каждой строке находятся:

```text
A B C D
```

Нужно посчитать строки, где одновременно:

```text
1. все числа различны;
2. максимальное число меньше суммы остальных.
```

Вспомогательный столбец можно строить формулой.

Для второго условия:

```text
=МАКС(A2:D2)<СУММ(A2:D2)-МАКС(A2:D2)
```

---

# 18. Как проверить, что все числа различны

Для небольшого количества столбцов можно посчитать частоты.

Например, если данные находятся:

```text
A2:D2
```

в `E2`:

```text
=СЧЁТЕСЛИ($A2:$D2;A2)
```

Копируем вправо до `H2`.

Если все числа различны, получим:

```text
1 1 1 1
```

Если есть пара одинаковых:

```text
2 2 1 1
```

Если одно число повторяется трижды:

```text
3 3 3 1
```

Это очень удобный способ для актуального №9.

---

# 19. Семь чисел в строке

Пусть исходные числа:

```text
A2:G2
```

В `H2` вводим:

```text
=СЧЁТЕСЛИ($A2:$G2;A2)
```

и копируем вправо до:

```text
N2
```

Например, исходная строка:

```text
5 5 5 2 7 9 11
```

частоты будут:

```text
3 3 3 1 1 1 1
```

Значит:

```text
одно число повторяется три раза,
остальные четыре различны
```

---

# 20. Проверка схемы повторений

Если частоты находятся:

```text
H2:N2
```

то условие:

> одно число повторяется три раза, остальные четыре различны

можно проверить:

```text
=И(
  СЧЁТЕСЛИ(H2:N2;3)=3;
  СЧЁТЕСЛИ(H2:N2;1)=4
)
```

Почему тройка встречается:

```text
3 раза
```

Потому что одно и то же повторяющееся число занимает три ячейки, и возле каждой будет написана частота `3`.

---

# 21. Проверка «повторяющееся число не максимум и не минимум»

Если уже известно, что повторяется ровно одно число трижды, достаточно проверить:

```text
максимум встречается один раз
```

и:

```text
минимум встречается один раз
```

Формулы:

```text
=СЧЁТЕСЛИ(A2:G2;МАКС(A2:G2))=1
```

```text
=СЧЁТЕСЛИ(A2:G2;МИН(A2:G2))=1
```

---

# 22. Сортировка и фильтр

## Сортировка

Меняет порядок строк.

Например:

```text
по возрастанию столбца A
```

## Фильтр

Временно скрывает строки, которые не соответствуют условию.

Например:

```text
показать только строки,
где вспомогательный столбец = 1
```

Для №9 фильтр очень удобен после вычисления:

```text
1 — строка подходит
0 — не подходит
```

---

# 23. Универсальная схема решения №9

```text
1. Открыть файл.
2. Посмотреть количество чисел в строке.
3. Перевести каждое условие задания в формулу.
4. Сделать вспомогательные столбцы.
5. Скопировать формулы вниз.
6. Получить для каждой строки 1 или 0.

8. Проверить несколько строк вручную.
```

---

# 24. Когда условие проще считать отдельно

Например:

```text
условие 1 — все числа различны
условие 2 — max < сумма остальных
```

Удобно сделать:

```text
H — первое условие
I — второе условие
J — =И(H2;I2)
```

Это лучше, чем писать одну огромную формулу, которую потом невозможно отлаживать.

# 25. Типичные ошибки

## Ошибка 1. Не зафиксировать диапазон

Написали:

```text
=СЧЁТЕСЛИ(A2:G2;A2)
```

и скопировали вправо.

Диапазон тоже сдвинулся.

Нужно:

```text
=СЧЁТЕСЛИ($A2:$G2;A2)
```

---

## Ошибка 2. Перепутать `И` и `ИЛИ`

```text
оба условия
```

→ `И`

```text
хотя бы одно
```

→ `ИЛИ`

---

## Ошибка 3. Считать количество различных значений вместо количества повторений

Например:

```text
5 5 5 2 7 9 11
```

здесь:

```text
5 различных значений
```

но нас интересует схема:

```text
3 3 3 1 1 1 1
```

---

## Ошибка 4. Сравнить максимум с полной суммой

Условие:

> максимум меньше суммы остальных.

Правильно:

```text
MAX < SUM - MAX
```

---

## Ошибка 5. Перепутать строку таблицы и номер строки

Иногда спрашивается:

```text
количество подходящих строк
```

а иногда:

```text
сумма номеров подходящих строк
```

Это разные ответы.

# Практический шаблон для реального №9

Если исходные числа находятся:

```text
A2:G2
```

## Частоты

В `H2`:

```text
=СЧЁТЕСЛИ($A2:$G2;A2)
```

Копируем вправо:

```text
H2:N2
```

## Сумма

```text
=СУММ(A2:G2)
```

## Минимум

```text
=МИН(A2:G2)
```

## Максимум

```text
=МАКС(A2:G2)
```

## Среднее

```text
=СРЗНАЧ(A2:G2)
```

## Строка подходит / не подходит

```text
=ЕСЛИ(И(условие1;условие2);1;0)
```

После копирования вниз:

```text
=СУММ(столбец_ответов)
```

# Альтернативная проверка через Python

Хотя №9 предназначено для электронной таблицы, сильным ученикам полезно уметь проверить ответ кодом.

Например:

```python
count = 0

for row in rows:
    if len(set(row)) == 4:
        if max(row) < sum(row) - max(row):
            count += 1

print(count)
```

Для повторений:

```python
freq = [row.count(x) for x in row]

if sorted(freq) == [1, 1, 2, 2, 3, 3, 3]:
    ...
```

Но основной навык занятия:

```text
решить задачу именно в электронной таблице
```
