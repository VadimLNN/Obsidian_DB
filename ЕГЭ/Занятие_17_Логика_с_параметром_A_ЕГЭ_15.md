# Занятие 17. Логические выражения с параметром A

**ЕГЭ по информатике — задание №15**

Цель занятия: научиться подбирать параметр `A`, чтобы логическое выражение было **тождественно истинным**, то есть принимало значение `1` при всех допустимых значениях переменной.

Основные модели задания №15:

- логические выражения;
- делимость `ДЕЛ(x, A)`;
- отрезки и множества;
- побитовая конъюнкция `x & A`;
- условия с двумя переменными;
- поиск минимального / максимального `A`.

---

# 1. Что значит «тождественно истинна»

Если сказано:

> формула истинна при любом значении `x`

это значит:

```text
не должно существовать ни одного x,
при котором выражение = 0
```

Практически есть два подхода:

```text
1. найти, когда формула ложна, и запретить этот случай;
2. перебрать A и x программой.
```

Для цели курса **60+** второй способ особенно полезен.

---

# 2. Главное про импликацию

Запись:

```text
P → Q
```

ложна только в одном случае:

```text
P = 1
Q = 0
```

Таблица:

| P | Q | P → Q |
|---:|---:|---:|
| 0 | 0 | 1 |
| 0 | 1 | 1 |
| 1 | 0 | 0 |
| 1 | 1 | 1 |

Полезная замена:

```text
P → Q
```

эквивалентно:

```text
¬P ∨ Q
```

---

# 3. Эквивалентность

```text
P ≡ Q
```

истинна, когда значения одинаковы:

```text
0 ≡ 0 → 1
1 ≡ 1 → 1
```

и ложна, когда различаются.

В Python:

```python
P == Q
```

---

# 4. Логика в Python

```text
¬P      → not P
P ∧ Q   → P and Q
P ∨ Q   → P or Q
P ≡ Q   → P == Q
```

Импликацию лучше оформить отдельной функцией:

```python
def imp(a, b):
    return (not a) or b
```

Тогда:

```text
P → Q
```

пишем:

```python
imp(P, Q)
```

# 7. ДЕЛ(n, m)

В заданиях используется обозначение:

```text
ДЕЛ(n, m)
```

Оно означает:

```text
n делится на m без остатка
```

То есть:

```python
n % m == 0
```

Например:

```text
ДЕЛ(12, 3) = 1
ДЕЛ(12, 5) = 0
```

---

# 8. Типовая задача на делимость

Формула:

```text
ДЕЛ(x, 12) → ДЕЛ(x, A)
```

должна быть истинна при любом натуральном `x`.

Это означает:

```text
каждое число, кратное 12,
должно быть кратно A
```

Достаточно посмотреть на:

```text
x = 12
```

Получаем:

```text
12 должно делиться на A
```

То есть `A` — делитель `12`.

Максимальный:

```text
A = 12
```

---

# 9. Обратная ситуация

```text
ДЕЛ(x, A) → ДЕЛ(x, 15)
```

Каждое кратное `A` должно быть кратно `15`.

Значит:

```text
A должно быть кратно 15
```

Минимальное:

```text
15
```

# 10. НОД и НОК

Для задач №15 полезны:

```text
НОД — наибольший общий делитель
НОК — наименьшее общее кратное
```

Python:

```python
from math import gcd, lcm

print(gcd(12, 18))
print(lcm(12, 18))
```

# 11. Пример с несколькими условиями

Формула:

```text
(ДЕЛ(x, A) ∧ ДЕЛ(x, 8))
→
ДЕЛ(x, 24)
```

Левая часть истинна для чисел, кратных:

```text
НОК(A, 8)
```

Нужно:

```text
НОК(A, 8)
```

делилось на:

```text
24
```

Минимальное подходящее:

```text
A = 3
```

потому что:

```text
НОК(3, 8) = 24
```

# 12. Отрезки

Пусть:

```text
P = [10; 50]
Q = [30; 80]
```

Запись:

```text
x ∈ P
```

означает:

```text
10 ≤ x ≤ 50
```

В Python:

```python
P = 10 <= x <= 50
```

---

# 13. Длина отрезка

Для:

```text
A = [a; b]
```

длина равна:

```text
b - a
```

Не:

```text
b - a + 1
```

Потому что речь идёт о длине отрезка на числовой прямой, а не о количестве целых чисел.

Например:

```text
[30; 50]
```

имеет длину:

```text
20
```

---

# 14. Пересечение отрезков

```text
P = [10; 50]
Q = [30; 80]
```

Пересечение:

```text
P ∩ Q = [30; 50]
```

Длина:

```text
20
```

# 15. Объединение

Если:

```text
P = [10; 20]
Q = [30; 50]
```

и один отрезок `A` должен содержать оба множества, минимально:

```text
A = [10; 50]
```

Длина:

```text
40
```

Даже несмотря на промежуток:

```text
(20; 30)
```

# 16. Типовая задача на отрезки

Формула:

```text
(x ∈ P) → ((x ∈ Q) → (x ∈ A))
```

Раскрываем импликации:

```text
¬P ∨ ¬Q ∨ A
```

Она ложна только когда:

```text
x ∈ P
x ∈ Q
x ∉ A
```

Значит:

```text
P ∩ Q ⊆ A
```

Минимальный `A` должен покрыть пересечение.

---

# 17. Симметрическая разность

Пусть:

```text
¬(x ∈ A)
→
((x ∈ B) ≡ (x ∈ C))
```

Вне `A` принадлежность `B` и `C` должна совпадать.

Следовательно в `A` обязательно должны находиться точки, где:

```text
B и C различаются
```

То есть:

```text
(B \ C) ∪ (C \ B)
```

Это называется:

```text
симметрическая разность
```

# 18. Побитовая конъюнкция

Оператор:

```text
&
```

сравнивает числа побитово.

Пример:

```text
14 = 1110₂
5  = 0101₂
```

```text
14 & 5
=
0100₂
=
4
```

Python:

```python
14 & 5
```

# 19. Что означает x & A = 0

```text
x & A = 0
```

означает:

```text
у x и A нет общих единичных битов
```

А:

```text
x & A ≠ 0
```

означает:

```text
есть хотя бы одна позиция,
в которой и x, и A имеют бит 1
```

---

# 20. Пример

```text
x = 10 = 1010₂
A = 6  = 0110₂
```

```text
x & A
=
0010₂
=
2
```

Следовательно:

```text
x & A ≠ 0
```

# 21. Побитовые задачи проще проверять перебором

Шаблон:

```python
def imp(a, b):
    return (not a) or b

for A in range(0, 256):
    ok = True

    for x in range(0, 512):
        F = imp(
            (x & 13) != 0,
            imp(
                (x & 6) == 0,
                (x & A) != 0
            )
        )

        if not F:
            ok = False
            break

    if ok:
        print(A)
        break
```

# 23. Две переменные

Иногда встречается параметр `A` и переменные:

```text
x
y
```

Например:

```text
(x + 2y < A)
∨
(x > 15)
∨
(y > 8)
```

Чтобы формула была истинна всегда, рассматриваем опасную область:

```text
x ≤ 15
y ≤ 8
```

В ней первое условие обязано быть истинным.

Максимум:

```text
x + 2y
```

равен:

```text
15 + 2·8 = 31
```

Значит минимальное целое:

```text
A = 32
```

# Разбор задач 41–50

## 41

Формула:

```text
P → ((Q ∧ ¬A) → ¬P)
```

Раскрываем импликации:

```text
¬P ∨ ¬Q ∨ A
```

Ложь возникает только при:

```text
x ∈ P
x ∈ Q
x ∉ A
```

Значит:

```text
P ∩ Q ⊆ A
```

Пересечение:

```text
[40; 64]
```

Длина:

```text
64 - 40 = 24
```

**Ответ: 24.**

---

## 42

Формула:

```text
¬A → (B ≡ C)
```

Вне `A` принадлежность отрезкам должна совпадать.

Различаются `B` и `C` на участках:

```text
[22; 32)
(40; 50]
```

Так как `A` должен быть одним отрезком, он обязан покрыть весь промежуток:

```text
[22; 50]
```

Длина:

```text
50 - 22 = 28
```

**Ответ: 28.**

---

## 43

Формула может стать ложной только когда одновременно:

```text
x ∈ B
ДЕЛ(x, 17)
¬ДЕЛ(x, A)
```

В отрезке:

```text
[20; 35]
```

единственное кратное `17`:

```text
34
```

Значит:

```text
34 должно делиться на A
```

Максимальный делитель:

```text
34
```

**Ответ: 34.**

## 45

Формула:

```text
(P ∧ ¬A) → Q
```

может быть ложна, когда:

```text
x ∈ P
x ∉ A
x ∉ Q
```

Следовательно `A` обязан покрывать:

```text
P \ Q
```

```text
P = [12; 48]
Q = [30; 70]
```

Нужный участок:

```text
[12; 30)
```

Минимальная длина:

```text
30 - 12 = 18
```

**Ответ: 18.**

## 46

Формула:

```text
¬ДЕЛ(x, A)
→
(ДЕЛ(x, 28) → ¬ДЕЛ(x, 49))
```

Критические `x` одновременно делятся на:

```text
28
49
```

Минимальное такое число:

```text
НОК(28, 49) = 196
```

Для:

```text
x = 196
```

правая часть ложна, значит левая часть импликации должна быть ложной:

```text
¬ДЕЛ(196, A) = 0
```

то есть:

```text
196 делится на A
```

Максимально:

```text
A = 196
```

**Ответ: 196.**

```python
def imp(a, b):

for A in range(256):

            (x & 13) != 0,

                (x & 6) == 0,
                (x & A) != 0

        )

            ok = False
            break

        break
```

Получаем:

```text
9
```

## 48

Перебор:

```python
def imp(a, b):
    return (not a) or b

for A in range(256):
    if all(
        imp(
            ((x & 35) != 0) or ((x & 22) != 0),
            imp(
                (x & 15) == 0,
                (x & A) != 0
            )
        )
        for x in range(512)
    ):
        print(A)
        break
```

Получаем:

```text
48
```

**Ответ: 48.**

Нужно:

Минимальное целое:

```text
32
```

# Что ученик обязан вынести

```text
1. P → Q ложно только при:
   P = 1, Q = 0.

2. Тождественно истинно означает:
   нет ни одного контрпримера.

3. ДЕЛ(x, A):
   x % A == 0.

4. Для отрезка:
   длина [a; b] = b - a.

5. В задачах с отрезками
   очень полезно искать область,
   где формула становится ложной.

6. x & A — побитовое И,
   а не логическое and.

7. Для побитовых задач
   перебор Python особенно удобен.

8. Всегда читать,
   что требуется:
   min A,
   max A,
   длина A,
   количество элементов A.

9. Перебор — хороший инструмент,
   но ответ желательно понимать логически.
```

Для цели **60+** сначала нужно уверенно освоить **делимость и отрезки**. Побитовые задачи можно дать сильным ученикам как следующий уровень.
