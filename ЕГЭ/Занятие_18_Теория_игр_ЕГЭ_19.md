# Занятие 18. Теория игр — базовый уровень

**ЕГЭ по информатике — задание №19**

Цель занятия: научиться понимать условие логической игры и находить начальные позиции, в которых второй игрок может выиграть **своим первым ходом**.

На этом занятии разбираем именно базовую механику №19.

Задания №20 и №21 — стратегии на 2 хода и дерево игры — будут на следующем занятии.

---

# 1. Как устроены задачи 19–21

Обычно есть:

```text
Петя
Ваня
```

Первым ходит:

```text
Петя
```

Есть одна или две кучи камней.

За один ход разрешено, например:

```text
+1
+4
×2
×3
```

Игра заканчивается, когда достигается условие победы, например:

```text
в куче стало не менее 50 камней
```

или:

```text
суммарно в двух кучах стало не менее 100 камней
```

---

# 2. Кто считается победителем

Побеждает тот игрок, который:

```text
сделал последний ход
```

и впервые получил выигрышную позицию.

Например:

```text
цель: ≥ 50

было: 26
игрок делает ×2
получается: 52
```

Игрок сразу победил.

Следующего хода уже нет.

---

# 3. Главное — читать условие окончания игры

Чаще всего:

```text
не менее K
```

то есть:

```text
>= K
```

Но бывают игры на уменьшение:

```text
не более K
```

Тогда победа достигается при:

```text
<= K
```

Нельзя автоматически использовать `>=`.

---

# 4. Позиция

Для одной кучи позицию можно записать одним числом:

```text
S
```

Например:

```text
S = 20
```

Для двух куч:

```text
(a, b)
```

Например:

```text
(5, 27)
```

---

# 5. Ходы в одной куче

Если разрешено:

```text
+1
×2
```

из позиции:

```text
S
```

можно попасть в:

```text
S + 1
2S
```

Например:

```text
S = 12
```

ходы:

```text
13
24
```

---

# 6. Ходы в двух кучах

Пусть позиция:

```text
(a, b)
```

Разрешено:

```text
+1
×2
```

для любой одной кучи.

Тогда возможны четыре хода:

```text
(a + 1, b)
(a, b + 1)
(2a, b)
(a, 2b)
```

---

# 7. Выигрышная позиция за один ход

Назовём её:

```text
W1
```

Это позиция, из которой **текущий игрок** может закончить игру одним ходом.

Например:

```text
цель ≥ 50
ходы +1, ×2
```

Для:

```text
S = 25
```

можно:

```text
25 × 2 = 50
```

Следовательно:

```text
25 — W1
```

---

# 8. Когда начинается зона W1

Если ход:

```text
×2
```

а цель:

```text
>= 50
```

достаточно:

```text
2S >= 50
```

```text
S >= 25
```

Поэтому позиции:

```text
25...49
```

выигрышны за один ход.

---

# 9. Что означает «Ваня выиграл своим первым ходом»

Ходы идут:

```text
1. Петя
2. Ваня
```

Ваня должен выиграть именно на:

```text
2-м ходе партии
```

То есть Петя сначала делает ход, который **не заканчивает игру**, после чего Ваня получает позицию `W1`.

Схема:

```text
S
│
│ ход Пети
▼
позиция W1
│
│ ход Вани
▼
ПОБЕДА
```

---

# 10. Что значит «неудачный первый ход Пети»

Это ключевая формулировка задания №19.

Например:

> Ваня выиграл своим первым ходом после неудачного первого хода Пети.

Это значит:

```text
существовал хотя бы один ход Пети,
который не закончил игру,
после которого Ваня смог выиграть сразу
```

То есть здесь достаточно:

```text
ХОТЯ БЫ ОДНОГО
```

подходящего хода Пети.

В логике:

```text
exists
```

В Python:

```python
any(...)
```

---

# 11. Важное отличие: «при любом ходе Пети»

Другая формулировка:

> Петя не может выиграть за один ход, но при любом ходе Пети Ваня может выиграть своим первым ходом.

Здесь уже нужно:

```text
КАЖДЫЙ ход Пети
```

проверить.

В Python:

```python
all(...)
```

Это существенно более сильное требование.

---

# 12. Эти две задачи нельзя путать

## Вариант А

```text
после неудачного хода Пети
```

Достаточно:

```text
одного подходящего хода
```

## Вариант Б

```text
при любом ходе Пети
```

Нужно:

```text
чтобы подходили все ходы
```

Ответы в одной и той же игре обычно будут разными.

# 13. Первый ручной пример

Игра:

```text
одна куча
ходы: +1, ×2
цель: >= 50
```

Когда Ваня может выиграть за один ход?

Ему нужна позиция:

```text
>= 25
```

но:

```text
< 50
```

То есть:

```text
25...49
```

Теперь ищем минимальное начальное `S`, из которого Петя может **неудачным** ходом попасть в этот диапазон.

Ходы Пети:

```text
S + 1
2S
```

Самый быстрый способ попасть хотя бы в `25`:

```text
2S >= 25
```

```text
S >= 12.5
```

Минимальное целое:

```text
13
```

При:

```text
S = 13
```

Петя делает:

```text
13 × 2 = 26
```

Ваня:

```text
26 × 2 = 52
```

и выигрывает.

---

# 14. Почему ход Пети должен быть невыигрышным

Если Петя сразу получает:

```text
>= K
```

игра закончилась.

Ваня уже не ходит.

Поэтому при поиске «неудачного хода» обязательно проверяем:

```text
новая позиция Пети < K
```

---

# 15. Python для одной кучи

Игра:

```text
ходы +1 и ×2
цель >= 50
```

```python
K = 50

def moves(s):
    return [s + 1, s * 2]

def win1(s):
    return any(x >= K for x in moves(s))
```

Теперь `win1(s)` означает:

```text
текущий игрок может выиграть одним ходом
```

---

# 16. Задание №19 — «неудачный ход»

```python
for S in range(1, K):
    ok = any(
        x < K and win1(x)
        for x in moves(S)
    )

    if ok:
        print(S)
        break
```

Здесь:

```text
x < K
```

означает:

```text
Петя своим ходом не выиграл
```

а:

```text
win1(x)
```

означает:

```text
Ваня после этого выигрывает одним ходом
```

---

# 17. Вариант «после любого хода»

Если требуется:

```text
Петя не выигрывает за один ход
и
после каждого его хода Ваня выигрывает
```

можно писать:

```python
for S in range(1, K):
    nxt = moves(S)

    if (
        all(x < K for x in nxt)
        and
        all(win1(x) for x in nxt)
    ):
        print(S)
        break
```

```python
    ]
```

# 19. Победа за один ход в двух кучах

```python
K = 59

def win1(a, b):
    return any(
        x + y >= K
        for x, y in moves(a, b)
    )
```

# 20. №19 для двух куч

```python
for S in range(1, 54):

        for x, y in moves(5, S)

        print(S)
        break
```

Сначала нужно понять:

```text
из каких позиций Ваня выигрывает в один ход
```

Например, если разрешено удвоить любую кучу:

```text
(a, b)
```

выигрыш возможен, если:

```text

```

или:

```text
a + 2b >= K
```

# 22. Не всегда выгоднее удваивать большую кучу?

Для получения максимальной суммы за один ход:

```text
да — обычно удвоение большей кучи даёт максимальный прирост
```

Но на экзамене всё равно нужно проверить:

```text
все разрешённые операции
```

Особенно если есть:

```text
+4
×2
```

или нестандартные правила.

# 25. Типичные ошибки

## Ошибка 1

Считать, что «неудачный ход» означает:

```text
любой ход Пети
```

Нет.

Обычно достаточно:

```text
одного неудачного хода
```

если прямо не написано «при любом ходе».

---

## Ошибка 2

Разрешить Ване ход после того, как Петя уже достиг цели.

Такого хода не существует.

---

## Ошибка 3

Забыть ход по первой куче.

Для двух куч нужно проверить операции:

```text
и с первой,
и со второй кучей
```

---

## Ошибка 4

Проверять только умножение.

Иногда победный ход — это:

```text
+1
+3
+4
...
```

---

## Ошибка 5

Использовать `all`, когда нужно `any`.

Фраза:

```text
такая ситуация возможна
```

обычно означает:

```python
any(...)
```

# Универсальный Python — одна куча

## «После неудачного хода»

```python
K = 100

def moves(s):
    return [s + 1, s * 2]

def win1(s):
    return any(x >= K for x in moves(s))

for S in range(1, K):
    if any(
        x < K and win1(x)
        for x in moves(S)
    ):
        print(S)
        break
```

---

# Универсальный Python — две кучи

```python
K = 100

def moves(a, b):
    return [
        (a + 1, b),
        (a, b + 1),
        (a * 2, b),
        (a, b * 2),
    ]

def win1(a, b):
    return any(
        x + y >= K
        for x, y in moves(a, b)
    )

for S in range(1, K):
    if any(
        x + y < K and win1(x, y)
        for x, y in moves(10, S)
    ):
        print(S)
        break
```

---

# Вариант «при любом ходе»

```python
for S in range(1, K):
    nxt = moves(10, S)

    if (
        all(x + y < K for x, y in nxt)
        and
        all(win1(x, y) for x, y in nxt)
    ):
        print(S)
        break
```

