# Занятие 19. Теория игр — выигрышные стратегии

**ЕГЭ по информатике — задания №20 и №21**

Это продолжение занятия №18 по заданию №19.

На прошлом занятии мы разобрали:

```text
W1
выигрыш первым ходом
any / all
неудачный ход Пети
```

Теперь нужно перейти к настоящей **выигрышной стратегии на несколько ходов**.

Цель занятия:

- понимать позиции `W1`, `P1`, `W2`, `P2`;
- отличать «может выиграть» от «гарантированно выиграет»;
- учитывать **все ответы соперника**;
- решать №20;
- решать №21;
- использовать рекурсию и мемоизацию;
- при необходимости строить дерево игры.

# 2. Типичный смысл задания №20

Нужно найти начальные значения `S`, при которых:

```text
1. Петя не может выиграть своим первым ходом;

2. Петя может гарантированно выиграть своим вторым ходом
   независимо от действий Вани.
```

Ключевое слово:

```text
независимо
```

То есть после правильного первого хода Пети:

```text
ВСЕ ответы Вани
```

должны позволять Пете победить следующим ходом.

---

# 3. Типичный смысл задания №21

Нужно найти минимальное `S`, при котором:

```text
Ваня имеет стратегию,
позволяющую выиграть первым или вторым своим ходом
при любой игре Пети,
```

но:

```text
у Вани нет стратегии,
гарантирующей победу первым ходом.
```

То есть:

```text
Петя ходит
↓
Ваня отвечает правильно
↓
если нужно — Петя ходит ещё раз
↓
Ваня выигрывает
```

---

# 4. Почему №20 сложнее №19

В №19 часто достаточно было:

```text
существует неудачный ход Пети
```

То есть:

```python
any(...)
```

В №20 Петя должен иметь **стратегию**.

Он выбирает первый ход так, чтобы:

```text
какой бы ход ни сделал Ваня,
Петя после этого смог закончить игру.
```

Получается:

```text
Петя выбирает → any
Ваня отвечает → all
Петя выигрывает → any
```

---

# 5. Позиция W1

`W` = **Winning**.

`W1` означает:

```text
текущий игрок может выиграть за один свой ход
```

Например:

```text
цель >= 50
ходы +1 и ×2
```

Позиция:

```text
25
```

является `W1`, потому что:

```text
25 × 2 = 50
```

---

# 6. Позиция P1

`P` можно запомнить как:

```text
проигрышная
```

`P1` означает:

```text
текущий игрок не может выиграть сразу,
и после ЛЮБОГО его хода
соперник получает W1.
```

То есть текущий игрок гарантированно проиграет:

```text
на первом ходе соперника
```

---

# 7. Пример P1

Игра:

```text
цель >= 50
ходы +1 и ×2
```

Позиция:

```text
24
```

Ходы:

```text
24 + 1 = 25
24 × 2 = 48
```

Обе позиции:

```text
25
48
```

являются `W1`.

Поэтому:

```text
24 = P1
```

---

# 8. Позиция W2

`W2` означает:

```text
текущий игрок не может гарантированно победить первым ходом,
но может сделать такой ход,
после которого соперник попадёт в P1.
```

То есть:

```text
W2
↓
P1
↓
любой ход соперника
↓
W1
↓
победа
```

Это и есть основная модель:

```text
задания №20
```

---

# 9. Пример W2

Та же игра:

```text
цель >= 50
ходы +1 и ×2
```

Возьмём:

```text
S = 23
```

Петя делает:

```text
23 + 1 = 24
```

А:

```text
24 = P1
```

После любого хода Вани Петя получает `W1`.

Следовательно:

```text
23 = W2
```

---

# 10. Ещё одна W2

```text
S = 12
```

Петя:

```text
12 × 2 = 24
```

Опять получаем:

```text
P1
```

Поэтому:

```text
12 = W2
```

---

# 11. Почему в №20 часто два ответа

Для одной и той же позиции `P1` можно попасть разными способами.

Например:

```text
24
```

можно получить:

```text
23 + 1
```

или:

```text
12 × 2
```

Поэтому в игре:

```text
цель >= 50
ходы +1, ×2
```

две основные позиции `W2`:

```text
12
23
```

---

# 12. Позиция P2

`P2` означает:

```text
текущий игрок проигрывает
не позднее второго хода соперника
при правильной игре соперника.
```

Для задания №21 особенно удобно думать так:

после **любого** хода текущего игрока соперник получает:

```text
W1
или
W2
```

При этом должно существовать хотя бы одно продолжение, где сопернику потребуется именно:

```text
второй ход
```

Иначе это была бы позиция:

```text
P1
```

---

# 13. Пример P2

Для игры:

```text
цель >= 50
ходы +1, ×2
```

позиция:

```text
22
```

Ходы Пети:

```text
22 + 1 = 23
22 × 2 = 44
```

```text
23 = W2
44 = W1
```

То есть:

```text
после любого хода Пети
Ваня получает либо W1, либо W2
```

Следовательно:

```text
22 = P2
```

Ваня гарантированно выигрывает:

```text
первым или вторым своим ходом
```

Но не гарантированно первым, потому что после:

```text
22 → 23
```

он получает `W2`, а не `W1`.

---

# 14. Главное соответствие

Запомнить:

```text
№19 → обычно W1 после плохого хода Пети

№20 → W2

№21 → P2
```

Это не официальные обозначения ФИПИ, а удобная учебная модель.

---

# 15. Схема уровней

```text
TERMINAL
    ↑
    │ победа одним ходом
    │
   W1
    ↑
    │ все ходы ведут в W1
    │
   P1
    ↑
    │ можно сходить в P1
    │
   W2
    ↑
    │ все ходы ведут в W1/W2
    │ и есть ход в W2
    │
   P2
```

# 16. ANY и ALL

Это самое важное место.

## Когда ходит игрок, который строит стратегию

Ему достаточно:

```text
найти хотя бы один хороший ход
```

Используем:

```python
any(...)
```

---

## Когда ходит соперник

Стратегия должна выдержать:

```text
любой его ответ
```

Используем:

```python
all(...)
```

# 17. №20 словами

Петя должен:

```text
выбрать хотя бы один первый ход
```

такой, что:

```text
при любом ответе Вани
```

у Пети есть:

```text
хотя бы один победный ход
```

Схема:

```text

 ↓
all
 ↓
any
```

# 18. №21 словами

Петя может выбирать свои ходы как угодно.

Ваня должен иметь ответ на:

```text

```

Поэтому в анализе появляются несколько чередований:

```text

```

# 19. Универсальная классификация через рекурсию

Для игры:

```text
цель >= K
ходы определены функцией moves
```

можно классифицировать позиции.

Пример для одной кучи:

```python
from functools import lru_cache

K = 50

def moves(s):
    return [s + 1, s * 2]

@lru_cache(None)
def game(s):
    if s >= K:
        return "T"

    r = [game(x) for x in moves(s)]

    if "T" in r:
        return "W1"

    if all(x == "W1" for x in r):
        return "P1"

    if "P1" in r:
        return "W2"

    if all(x in ("W1", "W2") for x in r):
        return "P2"

    return "дальше"
```

# 22. Более универсальная числовая классификация

Можно не использовать строки.

```python
from functools import lru_cache

@lru_cache(None)
def game(s):
    if s >= K:
        return 0

    r = [game(x) for x in moves(s)]

    bad = [x for x in r if x <= 0]

    if bad:
        return 1 - max(bad)

    return -max(r)
```

Интерпретация:

```text
 1  → W1
-1  → P1
 2  → W2
-2  → P2
 3  → W3
-3  → P3
...
```

Это уже полноценная универсальная модель игры.

Например:


```text

```

То есть:

```text
W2
```

# 24. Почему отрицательное — проигрыш

Например:

```text
game(s) = -2
```

означает:

```text
при правильной игре соперника
текущий игрок проиграет
не позднее второго хода соперника
```

Это:

```text
P2
```

# 25. Две кучи

Для:

```text
(a, b)
```

и ходов:

```text
+1
×2
```

функция:

```python
def moves(a, b):
    return [
        (a + 1, b),
        (a, b + 1),
        (a * 2, b),
        (a, b * 2),
    ]
```

Победа:

```python
def terminal(a, b):
    return a + b >= K
```

---

# 26. Классификация двух куч

```python
from functools import lru_cache

@lru_cache(None)
def game(a, b):
    if a + b >= K:
        return 0

    r = [
        game(x, y)
        for x, y in moves(a, b)
    ]

    bad = [x for x in r if x <= 0]

    if bad:
        return 1 - max(bad)

    return -max(r)
```

# 29. Дерево игры

Для небольших задач полезно строить дерево.

Пример:

```text
             23
            /  \
          24    46
         / \
       25   48
       |     |
     победа победа
```

Но дерево должно показывать:

```text
все возможные ответы проигрывающего игрока
```

и только те ходы выигрывающего, которые соответствуют его стратегии.

---

# 30. Ошибка: показать только удобный ход Вани

Если Петя сделал ход в `P1`, Ваня может иметь несколько ответов.

Для доказательства стратегии Пети нужно проверить:

```text
ВСЕ возможные ходы Вани
```

Иначе стратегия не доказана.

---

# 31. Ошибка: использовать any вместо all

В №20:

```text
Петя делает хороший первый ход
```

После него нельзя проверять:

```python
any(ответы_Вани)
```

Нужно:

```python
all(ответы_Вани)
```

Потому что Ваня будет мешать Пете.

---

# 32. Ошибка: считать, что соперник помогает

В задачах на стратегию предполагается:

```text
оба игрока играют оптимально
```

Проигрывающий игрок не обязан делать удобные ходы.

Он выбирает:

```text
самый неприятный для соперника вариант
```

---

# 33. Ошибка: не исключить W1 в №20

Условие №20 обычно отдельно говорит:

```text
Петя не может выиграть своим первым ходом
```

Поэтому позиции `W1`:

```text
не подходят
```

Нужна именно:

```text
W2
```

---

# 34. Ошибка: забыть второе условие №21

В №21 недостаточно показать:

```text
Ваня выигрывает первым или вторым ходом
```

Нужно ещё:

```text
Ваня НЕ имеет гарантированной стратегии
выиграть первым ходом
```

Иначе это позиция:

```text
P1
```

а не:

```text
P2
```

# 35. Минимальный набор, который надо запомнить

# Подробный разбор №41–50

# 41

Игра:

```text
(5, S)
цель >= 59
+1 или ×2
```

Проверяем позиции с помощью классификации.

```python
from functools import lru_cache

K = 59

def moves(a, b):
    return [
        (a + 1, b),
        (a, b + 1),
        (a * 2, b),
        (a, b * 2),
    ]

@lru_cache(None)
def game(a, b):
    if a + b >= K:
        return 0

    r = [game(x, y) for x, y in moves(a, b)]

    nonpos = [v for v in r if v <= 0]

    if nonpos:
        return 1 - max(nonpos)

    return -max(r)

for S in range(1, K - 5):
    if game(5, S) == 2:
        print(S)
```

Первые два значения:

```text
24
26
```

Они соответствуют:

```text
W2
```

**Ответ: 24 26.**

# Универсальный код для одной кучи

```python
from functools import lru_cache

K = 70

def moves(s):
    return [
        s + 3,
        s * 2,
    ]

@lru_cache(None)
def game(s):
    if s >= K:
        return 0

    r = [game(x) for x in moves(s)]

    nonpos = [
        x for x in r
        if x <= 0
    ]

    if nonpos:
        return 1 - max(nonpos)

    return -max(r)
```

# Как читать результат

```text
game(S) == 1
→ W1

game(S) == -1
→ P1

game(S) == 2
→ W2
→ №20

game(S) == -2
→ P2
→ №21
```

# Почему этот способ удобнее функции по номеру хода

Часто встречается код вида:

```python
f(s, m)
```

где нужно помнить:

```text
чётный ли номер хода;
кто сейчас ходит;
на каком ходе должна закончиться игра.
```

Он рабочий, но новичкам легко ошибиться.

Модель:

```text
W1 / P1 / W2 / P2
```

явно описывает смысл позиции.

Поэтому для обучения она обычно понятнее.

# Что ученик обязан вынести

```text
1. W1:
   текущий игрок выигрывает первым ходом.

2. P1:
   после любого хода соперник получает W1.

3. W2:
   можно сходить в P1.
   Это основная модель №20.

4. P2:
   после любого хода соперник получает W1 или W2,
   но не всегда W1.
   Это основная модель №21.

5. На своём выборе:
   any.

6. На выборе противника:
   all.

7. Выигрышная стратегия обязана учитывать
   все возможные ответы соперника.

8. В №20 нельзя брать W1:
   Петя не должен выигрывать сразу.

9. В №21 нельзя брать P1:
   Ваня не должен иметь гарантированную победу
   уже первым ходом.

10. Для сложных игр удобно использовать
    рекурсию + @lru_cache.
```

После занятия №19 блок `19–21` должен восприниматься как одна система:

```text
№19 — понять механику одного хода
№20 — найти W2
№21 — найти P2
```
