# Занятие 1. Системы счисления

## Тема

**Системы счисления. Кодирование чисел в разных системах счисления.**

Курс направлен на подготовку к ЕГЭ по информатике.  
Первый тематический блок рабочей программы посвящён системам счисления.

---

# 1. Цели занятия

К концу занятия ученик должен:

- понимать, что такое система счисления;
- знать, что такое основание системы счисления;
- различать позиционные и непозиционные системы счисления;
- понимать запись чисел в системах с основаниями `2`, `8`, `10`, `16`;
- переводить числа из системы с основанием `P` в десятичную;
- переводить целые десятичные числа в систему с основанием `P`;
- понимать связь между двоичной, восьмеричной и шестнадцатеричной системами;
- уметь применять эти знания при решении задач формата ЕГЭ.

# 4. Что такое система счисления

**Система счисления** — способ записи чисел с помощью определённого набора символов и правил.

Например:

```text
125₁₀
101101₂
75₈
2D₁₆
```

Нижний индекс показывает основание системы счисления.

---

# 5. Основание системы счисления

**Основание системы счисления** — количество различных цифр, которые используются для записи числа.

## Основные системы

| Система | Основание | Используемые символы |
|---|---:|---|
| Двоичная | 2 | `0, 1` |
| Восьмеричная | 8 | `0 ... 7` |
| Десятичная | 10 | `0 ... 9` |
| Шестнадцатеричная | 16 | `0 ... 9, A, B, C, D, E, F` |

Для шестнадцатеричной системы:

```text
A = 10
B = 11
C = 12
D = 13
E = 14
F = 15
```

---

# 6. Позиционные системы счисления

В позиционной системе значение цифры зависит от её позиции в числе.

Например:

```text
352₁₀
```

можно представить как:

```text
3 × 10² + 5 × 10¹ + 2 × 10⁰
```

То есть:

```text
300 + 50 + 2 = 352
```

Общий принцип:

```text
aₙaₙ₋₁...a₁a₀
```

равен:

```text
aₙ × Pⁿ + aₙ₋₁ × Pⁿ⁻¹ + ... + a₁ × P¹ + a₀ × P⁰
```

где `P` — основание системы счисления.
`n` - разрядность
`a` - символ/цифра

---

# 7. Перевод из системы с основанием P в десятичную

## Алгоритм

Чтобы перевести число в десятичную систему:

1. пронумеровать разряды справа налево, начиная с `0`;
2. каждую цифру умножить на основание системы в степени, соответствующей разряду;
3. сложить полученные значения.

---

## Пример 1

Перевести:

```text
1011₂
```

в десятичную систему.

```text
1011₂ =
1 × 2³ +
0 × 2² +
1 × 2¹ +
1 × 2⁰
```

```text
= 8 + 0 + 2 + 1
= 11
```

Ответ:

```text
1011₂ = 11₁₀
```

---

## Пример 2

Перевести:

```text
347₈
```

в десятичную систему.

```text
347₈ =
3 × 8² +
4 × 8¹ +
7 × 8⁰
```

```text
= 3 × 64 + 4 × 8 + 7
= 192 + 32 + 7
= 231
```

Ответ:

```text
347₈ = 231₁₀
```

---

## Пример 3

Перевести:

```text
2D₁₆
```

в десятичную систему.

Так как:

```text
D = 13
```

получаем:

```text
2D₁₆ =
2 × 16¹ +
13 × 16⁰
```

```text
= 32 + 13
= 45
```

Ответ:

```text
2D₁₆ = 45₁₀
```

---

# 8. Перевод из десятичной системы в систему с основанием P

Для перевода целого десятичного числа используется **метод последовательного деления**.

## Алгоритм

1. Делим число на основание новой системы.
2. Записываем остаток.
3. Полученное частное снова делим на основание.
4. Продолжаем, пока частное не станет равно `0`.
5. Остатки записываем **снизу вверх**.

---

## Пример

Перевести:

```text
13₁₀
```

в двоичную систему.

```text
13 / 2 = 6, остаток 1
 6 / 2 = 3, остаток 0
 3 / 2 = 1, остаток 1
 1 / 2 = 0, остаток 1
```

Читаем остатки снизу вверх:

```text
1101₂
```

Ответ:

```text
13₁₀ = 1101₂
```

# 9. Связь двоичной, восьмеричной и шестнадцатеричной систем

## Двоичная ↔ восьмеричная

Одна восьмеричная цифра соответствует **трём двоичным разрядам**.

```text
000 = 0
001 = 1
010 = 2
011 = 3
100 = 4
101 = 5
110 = 6
111 = 7
```

Пример:

```text
101110₂
```

Разбиваем справа налево по три цифры:

```text
101 110
```

```text
101₂ = 5
110₂ = 6
```

Получаем:

```text
101110₂ = 56₈
```

---

## Двоичная ↔ шестнадцатеричная

Одна шестнадцатеричная цифра соответствует **четырём двоичным разрядам**.

Пример:

```text
10101111₂
```

Разбиваем по четыре цифры:

```text
1010 1111
```

```text
1010₂ = A₁₆
1111₂ = F₁₆
```

Ответ:

```text
10101111₂ = AF₁₆
```

# 13. Типичные ошибки

## Ошибка 1. Неправильная нумерация степеней

Правильно:

```text
1011₂

степени:
3 2 1 0
```

Нумерация начинается **справа с нуля**.

---

## Ошибка 2. Использование недопустимых цифр

Например:

```text
128₈
```

— некорректная запись, потому что в восьмеричной системе допустимы только цифры:

```text
0–7
```

---

## Ошибка 3. Остатки читают сверху вниз

При переводе из десятичной системы остатки после последовательного деления необходимо читать:

```text
снизу вверх
```

---

## Ошибка 4. Забывают значения A–F

```text
A = 10
B = 11
C = 12
D = 13
E = 14
F = 15
```


```text

```

через степени основания.

Перевод:

```text
10 → P
```

через последовательное деление.

Быстрые переводы:

```text

2 ↔ 16 — группы по 4 бита
```
