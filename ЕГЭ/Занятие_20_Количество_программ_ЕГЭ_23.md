# Занятие 20. Исполнитель «Вычислитель» — количество программ

**ЕГЭ по информатике — задание №23**

Цель занятия: научиться считать количество программ исполнителя, которые переводят одно число в другое, в том числе при ограничениях на траекторию.

В актуальном формате встречаются:

- обычные команды `+1`, `+2`, `×2`, `×3`;
- обязательные числа в траектории;
- запрещённые числа;
- несколько обязательных точек;
- движение в сторону уменьшения;
- целая часть от деления;
- округление;
- перестановка цифр;
- замена цифр;
- возведение в квадрат;
- условно доступные команды.

Главный инструмент:

```text
рекурсия + динамическое программирование
```

---

# 1. Что такое программа исполнителя

Пусть у исполнителя есть команды:

```text
A. Прибавить 1
B. Умножить на 2
```

Исходное число:

```text
3
```

Нужно получить:

```text
8
```

Одна программа:

```text
AAB
```

Траектория:

```text
3 → 4 → 5 → 10
```

Такая программа **не подходит**, потому что закончилась не на `8`.

Другая программа:

```text
BAA
```

```text
3 → 6 → 7 → 8
```

подходит.

---

# 2. Траектория вычислений

Траектория — последовательность результатов выполнения команд.

Например:

```text
начало: 4

A: +1
B: ×2
```

Программа:

```text
ABA
```

даёт:

```text
4 → 5 → 10 → 11
```

Траектория:

```text
5, 10, 11
```

В условии могут потребовать:

```text
траектория содержит 10
```

или:

```text
траектория не содержит 10
```

---

# 3. Главная идея подсчёта

Пусть нужно посчитать число программ:

```text
из x в y
```

Если из `x` можно сделать:

```text
x + 1
x * 2
```

то:

```text
F(x, y)
=
F(x + 1, y)
+
F(2x, y)
```

Потому что каждая программа начинается либо:

```text
с первой команды
```

либо:

```text
со второй
```

---

# 4. Базовые случаи

Для возрастающего исполнителя:

```python
def f(x, y):
    if x > y:
        return 0

    if x == y:
        return 1

    return f(x + 1, y) + f(x * 2, y)
```

Почему:

```text
x > y → попасть назад нельзя → 0 программ
```

```text
x == y → пустое продолжение → 1 способ
```

---

# 5. Почему при x == y возвращаем 1

Пусть мы уже пришли в конечное число.

Например:

```text
F(10, 10)
```

Это означает:

```text
существует ровно один способ закончить программу:
ничего больше не делать
```

Поэтому:

```text
1
```

Если поставить:

```text
0
```

все пути обнулятся.

---

# 6. Три команды

Например:

```text
+1
+2
×3
```

Тогда:

```python
def f(x, y):
    if x > y:
        return 0

    if x == y:
        return 1

    return (
        f(x + 1, y)
        + f(x + 2, y)
        + f(x * 3, y)
    )
```

---

# 7. Обязательная точка

Требуется:

```text
из 2 получить 20
траектория обязана содержать 10
```

Любую такую программу можно разрезать:

```text
2 → 10 → 20
```

Поэтому:

```text
F(2, 10) · F(10, 20)
```

Почему умножение?

Первая часть выбирается:

```text
F(2, 10)
```

способами.

Для каждого такого способа вторую часть можно выбрать:

```text
F(10, 20)
```

способами.

---

# 8. Несколько обязательных точек

Если траектория должна содержать:

```text
10
12
```

и исполнитель всё время увеличивает число:

```text
4 → 10 → 12 → 20
```

Ответ:

```text
F(4, 10)
·
F(10, 12)
·
F(12, 20)
```

---

# 9. Порядок обязательных точек

Если команды только увеличивают число:

```text
+1
+3
×2
```

и старт:

```text
2
```

финиш:

```text
30
```

то траектория не может пройти:

```text
20
```

а потом:

```text
10
```

Поэтому обязательные точки автоматически располагаются по возрастанию.

Для уменьшающего исполнителя — по убыванию.

---

# 10. Запрещённая точка

Пусть нельзя проходить через:

```text
14
```

Самый удобный способ:

```python
def f(x, y):
    if x == 14:
        return 0

    if x > y:
        return 0

    if x == y:
        return 1

    return (
        f(x + 1, y)
        + f(x * 2, y)
    )
```

Как только попали в запрещённое число:

```text
этот путь уничтожается
```

---

# 11. Несколько запрещённых чисел

```python
BAD = {14, 18, 25}

def f(x, y):
    if x in BAD:
        return 0

    if x > y:
        return 0

    if x == y:
        return 1

    return ...
```

---

# 12. Обязательная и запрещённая точки одновременно

Например:

```text
из 1 в 21
обязательно пройти 10
не проходить 18
```

Можно считать:

```text
F(1, 10)
·
F(10, 21)
```

при этом функция `F` должна возвращать `0`, если встретила:

```text
18
```

---

# 13. Мемоизация

Рекурсивная функция много раз вычисляет одни и те же значения.

Например:

```text
F(10, 30)
```

может вызываться десятки раз.

Используем:

```python
from functools import lru_cache

@lru_cache(None)
def f(x, y):
    ...
```

Теперь уже вычисленный результат сохраняется.

---

# 14. Более удобная форма

Если конечное число не меняется:

```python
from functools import lru_cache

TARGET = 30

@lru_cache(None)
def f(x):
    if x > TARGET:
        return 0

    if x == TARGET:
        return 1

    return f(x + 1) + f(x * 2)
```

# 15. Табличное динамическое программирование

[[ЕГЭ/Занятие_14_Рекурсия_ЕГЭ_16|Рекурсия]] — не единственный способ.

Пусть команды:

```text
+1
+2
```

Нужно:

```text
из 1 в 5
```

Количество способов попасть:

```text
в 1 → 1
в 2 → 1
в 3 → 2
в 4 → 3
в 5 → 5
```

Потому что:

```text
ways[n]
=
ways[n - 1]
+
ways[n - 2]
```

Ответ:

```text
5
```

---

# 16. Когда таблица удобнее рекурсии

Табличный метод полезен, когда:

- команды простые;
- числа небольшие;
- нужно объяснить решение без кода;
- требуется увидеть количество путей к каждому числу.

Python-рекурсия удобнее, если команды:

- условные;
- делят число;
- меняют цифры;
- имеют много ограничений.

# 17. Уменьшающий исполнитель

В 2026 году встречаются задачи вида:

```text
A. Вычесть 1
B. Найти целую часть от деления на 2
```

Например:

```text
40 → 6
```

Тогда направление проверки меняется.

```python
def f(x, y):
    if x < y:
        return 0

    if x == y:
        return 1

    return f(x - 1, y) + f(x // 2, y)
```

# 19. Деление с округлением вверх

Может быть команда:

```text
подели на 2,
результат округли вверх
```

В Python:

```python
from math import ceil

ceil(x / 2)
```

Но для положительных целых можно и без `math`:

```python
(x + 1) // 2
```

# 20. Условная команда

Например:

> поменять местами цифры десятков и единиц можно только тогда, когда цифра десятков меньше цифры единиц.

Для числа:

```text
123
```

десятки:

```python
(123 // 10) % 10
```

единицы:

```python
123 % 10
```

# 21. Перестановка двух младших цифр

```python
def swap_last(n):
    tens = (n // 10) % 10
    ones = n % 10

    return (
        n
        - tens * 10
        - ones
        + ones * 10
        + tens
    )
```

Например:

```text
123 → 132
```

---

# 22. Проверка применимости команды

```python
tens = (n // 10) % 10
ones = n % 10

if tens < ones:
    # команду можно выполнить
```

В рекурсии:

```python
result = f(n + 1)

if tens < ones:
    result += f(swap_last(n))

return result
```

```python
int(str(n).replace("1", "3"))
```


# 24. Возведение в квадрат

Команда:

```text
x → x²
```

пишется:

```python
f(x ** 2)
```

Обязательно должна оставаться проверка:

```text
если x > target → 0
```

иначе числа быстро улетают далеко за цель.

---

# 25. Важная ловушка: разные команды могут дать одинаковое число

Пусть:

```text
x = 1
```

команды:

```text
+1
×2
```

Обе дают:

```text
2
```

Но программы разные:

```text
A
B
```

Поэтому в рекурсии нужно считать:

```python
f(x + 1) + f(x * 2)
```

даже если при конкретном `x` аргументы совпали.

Мы считаем:

```text
программы
```

а не:

```text
различные траектории
```

---

# 26. Универсальная схема

Для возрастающего исполнителя:

```python
from functools import lru_cache

TARGET = ...

BAD = {...}

@lru_cache(None)
def f(x):
    if x in BAD:
        return 0

    if x > TARGET:
        return 0

    if x == TARGET:
        return 1

    return (
        f(...)
        + f(...)
        + ...
    )
```

---

# 27. Универсальная схема для уменьшения

```python
@lru_cache(None)
def f(x):
    if x in BAD:
        return 0

    if x < TARGET:
        return 0

    if x == TARGET:
        return 1

    return (
        f(...)
        + f(...)
    )
```

# 28. Что делать перед написанием кода

Всегда сначала определить:

```text
1. числа растут или уменьшаются?
2. где условие остановки?
3. какие команды допустимы?
4. есть ли обязательные точки?
5. есть ли запрещённые точки?
6. могут ли команды возвращать то же число?
```

Последний пункт важен: если команда не изменяет число, можно случайно получить бесконечную рекурсию.

# 29. Частые ошибки

## Ошибка 1

Поставить:

```python
if x == target:
    return 0
```

Правильно:

```python
return 1
```

---

## Ошибка 2

Для уменьшающего исполнителя использовать:

```python
if x > target:
    return 0
```

Нужно наоборот:

```python
if x < target:
    return 0
```

---

## Ошибка 3

Обязательную точку учитывать сложением.

Правильно:

```text
через точку → произведение участков
```

---

## Ошибка 4

Несколько обязательных точек сложить:

```text
F(a, b) + F(b, c)
```

Нужно:

```text
F(a, b) · F(b, c)
```

---

## Ошибка 5

Забыть запрещённую точку после обязательной.

Запрет действует:

```text
на всю траекторию
```

---

## Ошибка 6

При условной команде выполнять её всегда.

Сначала:

```text
проверить условие применимости
```

# Подробный разбор задач 41–50

## 41

```text
2 → 39
+1, ×2, ×3
не проходить 14
```

```python
from functools import lru_cache

@lru_cache(None)
def f(x):
    if x == 14:
        return 0

    if x > 39:
        return 0

    if x == 39:
        return 1

    return (
        f(x + 1)
        + f(x * 2)
        + f(x * 3)
    )

print(f(2))
```

Получаем:

```text
188
```

**Ответ: 188.**

## 42

Нужно правильно реализовать условную перестановку.

```python
from functools import lru_cache

def swap_last(n):
    t = (n // 10) % 10
    u = n % 10

    return (
        n
        - t * 10
        - u
        + u * 10
        + t
    )

@lru_cache(None)
def f(x):
    if x > 154:
        return 0

    if x == 154:
        return 1

    result = f(x + 1)

    t = (x // 10) % 10
    u = x % 10

    if t < u:
        result += f(swap_last(x))

    return result

print(f(110))
```

Получаем:

```text
34
```

**Ответ: 34.**

## 44

Обязательные точки расположены:

```text
4 → 7 → 18 → 41
```

Поэтому:

```text
F(4, 7)
·
F(7, 18)
·
F(18, 41)
```

```python
from functools import lru_cache

def count(start, target):
    @lru_cache(None)
    def f(x):
        if x > target:
            return 0

        if x == target:
            return 1

        return (
            f(x + 3)
            + f(x + 4)
            + f(x ** 2)
        )

    return f(start)

print(
    count(4, 7)
    * count(7, 18)
    * count(18, 41)
)
```

Получаем:

```text
81
```

**Ответ: 81.**

# Что ученик обязан вынести

```text
1. F(x) — количество программ из x в цель.

2. Количество программ =
   сумма вариантов после каждой допустимой команды.

3. Если дошли до цели:
   return 1.

4. Если перескочили цель:
   return 0.

5. Запрещённое число:
   return 0.

6. Обязательная точка:
   произведение количества программ
   на участках траектории.

7. Несколько обязательных точек:
   разбиваем путь на несколько участков.

8. Для уменьшающего исполнителя
   меняется условие пересечения цели.

9. Условную команду можно добавлять
   в сумму только после проверки условия.

10. @lru_cache(None)
    убирает повторные вычисления.
```

Для цели **60+** №23 — выгодное задание: базовый вариант решается короткой рекурсией, а большая часть усложнений сводится к нескольким понятным изменениям этой же функции.
