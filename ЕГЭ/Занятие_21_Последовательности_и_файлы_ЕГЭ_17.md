# Занятие 21. Последовательности и обработка файлов

**ЕГЭ по информатике — задание №17**

Цель занятия: научиться писать короткую программу, которая читает числовую последовательность из файла, перебирает соседние пары или тройки и выводит два требуемых значения.

В актуальном формате №17 обычно нужно:

```text
1. прочитать файл;
2. найти характеристику всей последовательности;
3. перебрать соседние пары или тройки;
4. проверить несколько условий;
5. посчитать подходящие фрагменты;
6. найти максимум или минимум;
7. вывести два числа.
```

В демоверсии ЕГЭ-2026 используется именно такая схема:

```text
найти минимальный двузначный элемент последовательности;
рассматривать соседние пары;
в паре ровно один элемент должен быть двузначным;
сумма пары должна быть кратна найденному минимуму;
вывести количество пар и максимальную сумму.
```

---

# 1. Чтение файла

Если в файле каждое число записано с новой строки:

```python
a = [int(x) for x in open("17.txt")]
```

Более универсально:

```python
a = list(map(int, open("17.txt").read().split()))
```

Второй вариант работает и тогда, когда числа разделены:

```text
пробелами
переносами строк
табуляцией
```

---

# 2. Проверка чтения

Сразу после чтения полезно проверить:

```python
print(len(a))
print(a[:10])
```

Так можно быстро заметить:

```text
не тот файл;
пустой файл;
ошибку в пути.
```

---

# 3. Соседние пары

Пусть:

```python
a = [10, 20, 30, 40]
```

Соседние пары:

```text
(10, 20)
(20, 30)
(30, 40)
```

Их:

```text
n - 1
```

Удобный Python:

```python
for x, y in zip(a, a[1:]):
    ...
```

---

# 4. Соседние тройки

```python
for x, y, z in zip(a, a[1:], a[2:]):
    ...
```

Для последовательности из `n` элементов троек:

```text
n - 2
```

---

# 5. Можно использовать индексы

Пары:

```python
for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]
```

Тройки:

```python
for i in range(len(a) - 2):
    x = a[i]
    y = a[i + 1]
    z = a[i + 2]
```

Оба способа правильные.

Для №17 `zip` обычно короче.

# 6. Двузначное число

Если последовательность содержит только натуральные числа:

```python
10 <= x <= 99
```

Если возможны отрицательные:

```python
10 <= abs(x) <= 99
```

Например:

```text
34   → двузначное
-34  → тоже двузначное
7    → нет
105  → нет
```

---

# 7. Трёхзначное число

Для последовательности целых чисел:

```python
100 <= abs(x) <= 999
```

---

# 8. Ровно один элемент удовлетворяет условию

Например:

> ровно один элемент пары является двузначным.

Можно написать:

```python
(
    (10 <= abs(x) <= 99)
    +
    (10 <= abs(y) <= 99)
    == 1
)
```

Почему это работает?

В Python:

```text
True  = 1
False = 0
```

Поэтому:

```text
True + False = 1
```

---

# 9. Хотя бы один

```python
cond(x) or cond(y)
```

Например:

```python
x % 7 == 0 or y % 7 == 0
```

---

# 10. Оба

```python
cond(x) and cond(y)
```

Например:

```python
x % 3 == 0 and y % 3 == 0
```

---

# 11. Не более двух из трёх

Например:

```python
sum(
    100 <= abs(x) <= 999
    for x in triple
) <= 2
```

Полный пример:

```python
for triple in zip(a, a[1:], a[2:]):
    if sum(100 <= abs(x) <= 999 for x in triple) <= 2:
        ...
```

---

# 12. Найти глобальный параметр до цикла

Очень часто условие пары зависит от всей последовательности.

Например:

```text
минимальный двузначный элемент
```

Нужно сначала:

```python
m = min(
    x for x in a
    if 10 <= abs(x) <= 99
)
```

И только потом:

```python
for x, y in zip(a, a[1:]):
    ...
```

---

# 13. Максимальный трёхзначный элемент

```python
m = max(
    x for x in a
    if 100 <= abs(x) <= 999
)
```

Но внимательно читать условие.

Если сказано:

```text
максимальный положительный трёхзначный
```

лучше:

```python
m = max(
    x for x in a
    if 100 <= x <= 999
)
```

---

# 14. Минимальный положительный трёхзначный

```python
m = min(
    x for x in a
    if 100 <= x <= 999
)
```

Не использовать здесь:

```python
abs(x)
```

если в условии явно требуется:

```text
положительный элемент
```

# 15. Последняя цифра

Для положительного числа:

```python
x % 10
```

Если возможны отрицательные и требуется последняя цифра записи:

```python
abs(x) % 10
```

# 16. Предпоследняя цифра

```python
(abs(x) // 10) % 10
```

Например:

```text
347
```

```text
последняя      = 7
предпоследняя  = 4
```

---

# 17. Последние две цифры одинаковые

```python
abs(x) % 10 == (abs(x) // 10) % 10
```

Например:

```text
233  → да
-177 → да
420  → нет
```

```text
сумма пары кратна m

```

# 20. Счётчик

```python
count = 0
```

# 21. Максимум

Если все рассматриваемые значения гарантированно положительные:

```python
mx = 0
```

Но если могут быть отрицательные суммы, безопаснее:

```python
mx = -10**30
```

или:

```python
mx = None
```

---

# 22. Максимум через None

```python
mx = None

for x, y in ...:
    if условие:
        value = x + y
        count += 1

        if mx is None or value > mx:
            mx = value
```

Такой код корректен даже для:

```text
отрицательных значений
```

---

# 23. Типовой шаблон №17

```python
a = list(map(int, open("17.txt").read().split()))

m = min(
    x for x in a
    if 10 <= x <= 99
)

count = 0
mx = -10**30

for x, y in zip(a, a[1:]):
    two_digit = (
        (10 <= x <= 99)
        +
        (10 <= y <= 99)
        == 1
    )

    if two_digit and (x + y) % m == 0:
        count += 1
        mx = max(mx, x + y)

print(count, mx)
```

---

# 24. Лучше разбивать длинное условие

Плохо:

```python
if ((10 <= abs(x) <= 99) + (10 <= abs(y) <= 99) == 1) and (x+y)%m==0 and x*y>0:
```

Читаемее:

```python
one_two_digit = (
    (10 <= abs(x) <= 99)
    +
    (10 <= abs(y) <= 99)
    == 1
)

sum_divisible = (x + y) % m == 0
same_sign = x * y > 0

if one_two_digit and sum_divisible and same_sign:
    ...
```

На экзамене это уменьшает количество ошибок.

---

# 25. Сначала параметр, потом пары

Типичная ошибка:

```python
for x, y in pairs:
    m = min(...)
```

Это бессмысленно пересчитывает один и тот же минимум много раз.

Правильно:

```text
1. m = ...
2. цикл по парам
```

---

# 26. Частые ошибки

## Ошибка 1

Перебирать все пары элементов:

```text
(a[0], a[5])
(a[2], a[10])
...
```

Когда в условии сказано:

```text
два идущих подряд элемента
```

---

## Ошибка 2

Для отрицательного числа проверять:

```python
10 <= x <= 99
```

если условие говорит о количестве цифр записи числа.

Нужно:

```python
10 <= abs(x) <= 99
```

---

## Ошибка 3

Перепутать:

```text
ровно один
```

и:

```text
хотя бы один
```

---

## Ошибка 4

Взять минимум из всей последовательности вместо:

```text
минимального элемента,
удовлетворяющего дополнительному условию
```

---

## Ошибка 5

Инициализировать максимум нулём при отрицательных возможных результатах.

---

## Ошибка 6

Вывести только:

```text
count
```

когда в ответе нужны:

```text
два числа
```

# Подробный разбор задач 41–50

## 41

Минимальный двузначный элемент последовательности `A`:

```text
11
```

Код:

```python
a = [
    12,105,34,7,210,55,1000,18,82,5,
    140,63,420,27,99,100,44,6,330,71,
    16,800,25,50,3,120,88,14,700,31,
    9,240,66,11,500,42,20,360,77,4
]

m = min(x for x in a if 10 <= x <= 99)

count = 0
mx = -10**30

for x, y in zip(a, a[1:]):
    one_two = (
        (10 <= x <= 99)
        +
        (10 <= y <= 99)
        == 1
    )

    if one_two and (x + y) % m == 0:
        count += 1
        mx = max(mx, x + y)

print(count, mx)
```

Получаем:

```text
1 825
```

**Ответ: 1 825.**

## 43

Минимальный положительный трёхзначный элемент `A`:

```text
100
```

Для каждой соседней тройки:

```python
m = min(x for x in a if 100 <= x <= 999)

count = 0
mx = -10**30

for t in zip(a, a[1:], a[2:]):
    two_digit_count = sum(
        10 <= x <= 99
        for x in t
    )

    if (
        two_digit_count <= 2
        and sum(t) >= m
    ):
        count += 1
        mx = max(mx, sum(t))

print(count, mx)
```

Результат:

```text
37 1265
```

**Ответ: 37 1265.**

## 44



```python
m = min(x for x in b if 100 <= x <= 999)
```

## 49

Максимальный положительный трёхзначный элемент:

```text
999
```

```python
M = max(x for x in b if 100 <= x <= 999)

count = 0
mx = -1

for x, y in zip(b, b[1:]):
    one_two = (
        (10 <= abs(x) <= 99)
        +
        (10 <= abs(y) <= 99)
        == 1
    )

    q = x*x + y*y

    if one_two and q <= M*M:
        count += 1
        mx = max(mx, q)

print(count, mx)
```

Получаем:

```text
22 641764
```

**Ответ: 22 641764.**

## 50

Сначала ищем элементы, у которых две последние цифры одинаковы:

```python
same_last_two = [
    x for x in b
    if abs(x) % 10 == (abs(x) // 10) % 10
]
```

Минимальный:

```text
M = -300
```

Следовательно:

```text
M² = 90000
```

Проверка совпадения цифр:

```python
def last(x):
    return abs(x) % 10

def tens(x):
    return (abs(x) // 10) % 10
```

Полный перебор:

```python
M = min(
    x for x in b
    if last(x) == tens(x)
)

count = 0
mx = -1

for x, y in zip(b, b[1:]):
    digits = (
        last(x) == tens(y)
        or
        last(y) == tens(x)
    )

    one_div7 = (
        (x % 7 == 0)
        +
        (y % 7 == 0)
        == 1
    )

    q = x*x + y*y

    if (
        digits
        and one_div7
        and q <= M*M
    ):
        count += 1
        mx = max(mx, q)

print(count, mx)
```

Результат:

```text
1 2493
```

**Ответ: 1 2493.**

# Быстрая самопроверка

Перед запуском проверить:

```text
1. Пары или тройки?

2. Они обязательно соседние?

3. Натуральные числа или целые?

4. Для количества цифр нужен abs()?

5. Ровно один / хотя бы один / оба?

6. Какой глобальный min/max нужен?

7. Что требуется оптимизировать:
   сумму,
   произведение,
   сумму квадратов?

8. Нужен максимум или минимум?

9. В ответе одно число или два?

10. Не был ли максимум ошибочно инициализирован нулём?
```

# Что ученик обязан вынести

```text
1. Чтение:
   a = list(map(int, open("17.txt").read().split()))

2. Пары:
   zip(a, a[1:]).

3. Тройки:
   zip(a, a[1:], a[2:]).

4. Для отрицательных чисел
   количество цифр проверяем через abs().

5. Ровно один:
   cond(x) + cond(y) == 1.

6. Глобальный min/max
   вычисляем до цикла по парам.

7. Счётчик:
   count += 1.

8. Максимум:
   mx = max(mx, value).

9. Условие лучше разбивать
   на несколько понятных переменных.

10. В №17 обычно требуется вывести
    два значения.
```

Для цели **60+** №17 — одно из самых выгодных программных заданий: после освоения одного универсального шаблона большинство вариантов отличаются только условиями внутри `if`.
