# Занятие 23. Большое повторение ядра ЕГЭ

Это занятие не вводит новую тему.

Цель — проверить, умеет ли ученик:

```text
сам распознать тип задачи;
вспомнить нужную формулу или шаблон;
решить задачу без подсказки по теме.
```

На предыдущих занятиях уже разобраны:

- системы счисления;
- кодирование информации;
- звук и изображения;
- условие Фано;
- комбинаторика;
- графы;
- таблицы истинности;
- базы данных;
- поиск в тексте;
- простой алгоритм;
- Черепаха;
- Машина Тьюринга;
- IP-адреса;
- рекурсия;
- электронные таблицы;
- динамическое программирование в таблицах;
- логика с параметром `A`;
- теория игр №19–21;
- количество программ №23;
- последовательности и файлы №17;
- параллельные процессы №22.

---

# Как проводить занятие

Лучше не говорить ученикам заранее:

```text
«сейчас задача на IP»
```

или:

```text
«сейчас будет рекурсия»
```

Они должны сначала сами определить:

```text
какой это тип задания
```

и только после этого решать.

## 50

Опасная область возникает, когда:

```text
x > 15
```

ложно и:

```text
y > 8
```

ложно.

То есть:

```text
x <= 15
y <= 8
```

В этой области должно всегда выполняться:

```text
x + 2y < A
```

Максимальное:

```text
15 + 2 · 8 = 31
```

Значит:

```text
31 < A
```

Минимальное целое:

```text
32
```

**Ответ: 32.**

# Как оценить результат

Для задач:

```text
1–40
```

можно считать:

```text
32–40 правильных
→ ядро усвоено хорошо

24–31
→ есть отдельные пробелы

16–23
→ нужно повторять несколько крупных блоков

0–15
→ пока рано переходить к полноценному варианту
```

Для мини-диагностики:

```text
9–10 / 10
→ отлично

7–8 / 10
→ нормально

5–6 / 10
→ посмотреть ошибки

0–4 / 10
→ нужна точечная отработка тем
```

---

# Как разбирать ошибки

После проверки не нужно просто повторно решать всё занятие.

Лучше создать таблицу:

| Ошибка | Тема | Причина |
|---|---|---|
| №19 | IP | забыл размер блока |
| №25 | игры | перепутал W1/W2 |
| №27 | №23 | неверный базовый случай |
| №40 | процессы | перепутал границы времени |

После этого на занятии №24 можно дать полноценный диагностический вариант и уже по реальным ошибкам определить слабые темы.
