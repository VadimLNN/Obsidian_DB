Это занятие строится **по результатам диагностики занятия №24**.

Здесь нет смысла заставлять весь класс решать один и тот же набор задач.

Цель:

```text
слабые ученики → закрывают конкретные пробелы;
средние → закрепляют нестабильные номера;
сильные → начинают задание №24.
```

---

# 1. Как распределить учеников

После диагностического занятия у каждого ученика должна быть карта ошибок.

Например:

```text
№13 — ошибка
№17 — ошибка
№20 — ошибка
```

Тогда ученик не решает весь лист подряд.

Он получает:

```text
задачи соответствующих блоков
+
короткий повтор теории
+
повторную проверку в конце.
```

---

# 2. Рекомендуемая схема пары

```text
0–10 мин   — раздать индивидуальные маршруты

10–55 мин  — точечная отработка слабых номеров

55–70 мин  — повторная мини-проверка

70–90 мин:
    слабые/средние → продолжают ядро
    сильные → знакомятся с №24
```

# 8. Не более K символов

Например:

> максимальная подстрока, содержащая не более двух `A`.

Используем:

```text
скользящее окно
```

```python
left = 0
count_a = 0
best = 0

for right in range(len(s)):
    if s[right] == "A":
        count_a += 1

    while count_a > 2:
        if s[left] == "A":
            count_a -= 1

        left += 1

    best = max(
        best,
        right - left + 1
    )

print(best)
```

---

# 9. Почему скользящее окно удобно

Мы поддерживаем текущий отрезок:

```text
[left ... right]
```

Если условие нарушено:

```text
двигаем left
```

пока окно снова не станет допустимым.

Каждый символ проходит через границы окна максимум несколько раз.

Сложность:

```text
O(n)
```



```python
pos = [

```

```text

```

