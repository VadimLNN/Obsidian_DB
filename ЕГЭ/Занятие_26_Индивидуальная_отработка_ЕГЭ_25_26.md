# 4. Делители за O(sqrt(n))

Если:

```text
d | n
```

то одновременно:

```text
n // d
```

тоже делитель.

Поэтому достаточно проверить:

```text
d <= sqrt(n)
```

```python
def divisors(n):
    d = set()

    for x in range(1, int(n**0.5) + 1):
        if n % x == 0:
            d.add(x)
            d.add(n // x)

    return sorted(d)
```

---

# 5. Проверка простоты

```python
def is_prime(n):
    if n < 2:
        return False

    for d in range(2, int(n**0.5) + 1):
        if n % d == 0:
            return False

    return True
```

# 6. Разложение на простые множители

```python
def factorize(n):
    factors = []

    d = 2

    while d * d <= n:
        while n % d == 0:
            factors.append(d)
            n //= d

        d += 1

    if n > 1:
        factors.append(n)

    return factors
```

Например:

```text
60 = 2 · 2 · 3 · 5
```

Функция вернёт:

```python
[2, 2, 3, 5]
```

# 7. Важно: «ровно два простых множителя»

Фраза:

```text
ровно два простых множителя,
не обязательно различных
```

означает:

```text
p · q
```

где возможен случай:

```text
p = q
```

Например:

```text
49 = 7 · 7
```

подходит.

Проверка:

```python
f = factorize(n)

if len(f) == 2:
    ...
```

---

# 8. Различные простые множители

Если требуется:

```text
ровно три различных простых множителя
```

проверяем:

```python
len(set(factorize(n))) == 3
```

Но также нужно учитывать формулировку:

```text
ровно три простых множителя
```

и:

```text
ровно три различных простых множителя
```

Это не одно и то же.

# 11. Зачем здесь сортировка

Типичная задача:

```text
есть ограниченный объём;
есть много объектов разного размера;
нужно разместить максимальное количество.
```

Чтобы максимизировать количество, обычно сначала берём:

```text
самые маленькие объекты
```

То есть:

```python
data.sort()
```

---

# 12. Файлы на диск

```python
files.sort()

total = 0
count = 0

for x in files:
    if total + x <= S:
        total += x
        count += 1
    else:
        break
```

Так получаем максимальное количество файлов.

# 14. Вложенные коробки

Если следующая коробка должна быть меньше предыдущей хотя бы на:

```text
D
```

то после сортировки по убыванию:

```python
boxes.sort(reverse=True)

last = boxes[0]
count = 1

for x in boxes[1:]:
    if last - x >= D:
        count += 1
        last = x
```

# 16. Рейтинг — модель 2026

Для каждого продукта даны два числа:

```text
срок хранения
срок годности после вскрытия
```

Все `2N` значений сортируются.

Если первым встречается:

```text
срок хранения
```

продукт ставится:

```text
на первое свободное место с начала рейтинга
```

Если первым встречается:

```text
срок после вскрытия
```

продукт ставится:

```text
на первое свободное место с конца
```

После размещения продукта его второе число:

```text
игнорируется
```

# 17. Моделирование рейтинга

```python
events = []

for i, (a, b) in enumerate(products, 1):
    events.append((a, i, "left"))
    events.append((b, i, "right"))

events.sort()
```

Далее:

```python
left = 1
right = n
placed = {}
last = None

for value, product, side in events:

    if product in placed:
        continue

    if side == "left":
        placed[product] = left
        left += 1
    else:
        placed[product] = right
        right -= 1

    last = product
```

## 27

Ищем числа больше `1000`.

```python
def factorize(n):
    f = []
    d = 2

    while d * d <= n:
        while n % d == 0:
            f.append(d)
            n //= d

        d += 1

    if n > 1:
        f.append(n)

    return f

cnt = 0
n = 1001

while cnt < 5:
    f = factorize(n)

    if (
        len(f) == 2
        and all("1" in str(p) for p in f)
    ):
        print(n, max(f))
        cnt += 1

    n += 1
```
