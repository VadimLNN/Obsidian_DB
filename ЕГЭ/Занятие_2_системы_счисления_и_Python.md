# Занятие 2. Системы счисления + минимальный Python для ЕГЭ

# 1. Повторение: что такое основание системы счисления

Основание системы счисления обозначим `P`.

В системе с основанием `P` допустимы цифры:

```text
0, 1, 2, ..., P - 1
```

Примеры:

| Система           | Основание | Допустимые цифры            |
| ----------------- | --------: | --------------------------- |
| двоичная          |         2 | `0, 1`                      |
| восьмеричная      |         8 | `0 ... 7`                   |
| десятичная        |        10 | `0 ... 9`                   |
| шестнадцатеричная |        16 | `0 ... 9, A, B, C, D, E, F` |

Для шестнадцатеричной системы:

```text
A = 10
B = 11
C = 12
D = 13
E = 14
F = 15
```

# 2. Перевод из любой системы в десятичную

Число

```text
aₙaₙ₋₁...a₁a₀
```

в системе с основанием `P` раскрывается по степеням основания:

```text
aₙ·Pⁿ + aₙ₋₁·Pⁿ⁻¹ + ... + a₁·P¹ + a₀·P⁰
```

![Позиционная запись числа](assets/01_позиционная_запись.png)

## Алгоритм

1. Нумеруем разряды **справа налево**, начиная с `0`.
2. Каждую цифру умножаем на `P` в степени её разряда.
3. Складываем результаты.

## Пример 1

Перевести:

```text
1011₂ → ?₁₀
```

Раскладываем:

```text
1011₂ =
1·2³ + 0·2² + 1·2¹ + 1·2⁰
```

```text
= 8 + 0 + 2 + 1
= 11
```

Ответ:

```text
1011₂ = 11₁₀
```

## Пример 2

```text
347₈ → ?₁₀
```

```text
347₈ =
3·8² + 4·8¹ + 7·8⁰
```

```text
= 3·64 + 4·8 + 7
= 192 + 32 + 7
= 231
```

Ответ:

```text
347₈ = 231₁₀
```

## Пример 3

```text
2D₁₆ → ?₁₀
```

Так как:

```text
D = 13
```

получаем:

```text
2D₁₆ =
2·16¹ + 13·16⁰
= 32 + 13
= 45
```

Ответ:

```text
2D₁₆ = 45₁₀
```

# 3. Перевод из десятичной системы в любую другую

Для целых чисел используется **последовательное деление на основание новой системы**.

## Алгоритм

1. Делим число на `P`.
2. Записываем остаток.
3. Частное снова делим на `P`.
4. Продолжаем до тех пор, пока частное не станет равно `0`.
5. Остатки читаем **снизу вверх**.

![Перевод из десятичной системы](assets/02_из_10_в_P.svg)

## Пример

Перевести:

```text
45₁₀ → ?₂
```

```text
45 / 2 = 22, остаток 1
22 / 2 = 11, остаток 0
11 / 2 =  5, остаток 1
 5 / 2 =  2, остаток 1
 2 / 2 =  1, остаток 0
 1 / 2 =  0, остаток 1
```

Читаем остатки снизу вверх:

```text
101101
```

Ответ:

```text
45₁₀ = 101101₂
```

# 4. Быстрые переводы между 2, 8 и 16

Здесь не обязательно каждый раз переходить через десятичную систему.

![Быстрые переводы 2, 8 и 16](assets/03_переводы_2_8_16.svg)

---

## 4.1. Двоичная ↔ восьмеричная

Поскольку:

```text
8 = 2³
```

одна восьмеричная цифра соответствует **трём двоичным разрядам**.

|   8 |   2 |
| --: | --: |
|   0 | 000 |
|   1 | 001 |
|   2 | 010 |
|   3 | 011 |
|   4 | 100 |
|   5 | 101 |
|   6 | 110 |
|   7 | 111 |

### Из двоичной в восьмеричную

```text
101110₂
```

Разбиваем справа налево по 3:

```text
101 110
```

```text
101₂ = 5
110₂ = 6
```

Ответ:

```text
101110₂ = 56₈
```

### Из восьмеричной в двоичную

```text
73₈
```

Каждую цифру заменяем тремя битами:

```text
7 → 111
3 → 011
```

Ответ:

```text
73₈ = 111011₂
```

---

## 4.2. Двоичная ↔ шестнадцатеричная

Поскольку:

```text
16 = 2⁴
```

одна шестнадцатеричная цифра соответствует **четырём двоичным разрядам**.

|  16 |    2 |  16 |    2 |
| --: | ---: | --: | ---: |
|   0 | 0000 |   8 | 1000 |
|   1 | 0001 |   9 | 1001 |
|   2 | 0010 |   A | 1010 |
|   3 | 0011 |   B | 1011 |
|   4 | 0100 |   C | 1100 |
|   5 | 0101 |   D | 1101 |
|   6 | 0110 |   E | 1110 |
|   7 | 0111 |   F | 1111 |

### Из двоичной в шестнадцатеричную

```text
10101111₂
```

Разбиваем по 4:

```text
1010 1111
```

```text
1010 → A
1111 → F
```

Ответ:

```text
10101111₂ = AF₁₆
```

### Из шестнадцатеричной в двоичную

```text
5A₁₆
```

```text
5 → 0101
A → 1010
```

Ответ:

```text
5A₁₆ = 01011010₂
```

---

## 4.3. Восьмеричная ↔ шестнадцатеричная

Самый удобный путь:

```text
8 → 2 → 16
```

или:

```text
16 → 2 → 8
```

Пример:

```text
157₈ → ?₁₆
```

Сначала в двоичную:

```text
1 → 001
5 → 101
7 → 111
```

```text
157₈ = 001101111₂
```

Убираем незначащие нули слева и группируем по 4:

```text
0110 1111
```

```text
0110 → 6
1111 → F
```

Ответ:

```text
157₈ = 6F₁₆
```

# 12. Неизвестная цифра x

Пусть дано:

```text
12x5₁₃ + 3x7₁₃
```

Нужно найти `x`, при котором сумма делится на `12`.

Запись:

```text
12x5₁₃
```

раскрывается так:

```text
1·13³ + 2·13² + x·13 + 5
```

Второе число:

```text
3x7₁₃ =
3·13² + x·13 + 7
```

Перебор:

```python
for x in range(13):
    a = 1 * 13**3 + 2 * 13**2 + x * 13 + 5
    b = 3 * 13**2 + x * 13 + 7

    if (a + b) % 12 == 0:
        print(x, (a + b) // 12)
```

# 13. Дополнительно: перевод из десятичной в произвольную систему через Python

`bin()`, `oct()` и `hex()` работают только для `2`, `8`, `16`.

Для других оснований можно использовать свой небольшой алгоритм:

```python
def to_base(n, base):
    digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"

    if n == 0:
        return "0"

    result = ""

    while n > 0:
        result = digits[n % base] + result
        n //= base

    return result
```

Пример:

```python
print(to_base(125, 5))
```

Ответ:

```text
1000
```

Эту функцию **не обязательно учить наизусть**. Главное — понимать принцип последовательного деления.

```text
45–90 мин  — практика
```

После общей части:

### Начинающие

Идут по заданиям уровня 1.

С ними можно отдельно повторить:

```text
P → 10
10 → P
2 ↔ 8
2 ↔ 16
```

### Продвинутые

Сразу переходят к уровню 2 и работают самостоятельно на компьютерах.

Если задача решена вручную — хорошо.

Если вычисления становятся громоздкими — использовать Python.

Главная цель — не просто получить ответ, а понимать:

1. **что именно вычисляется**;
2. **в какой системе находится число**;
3. **почему используется конкретный алгоритм или код**.
