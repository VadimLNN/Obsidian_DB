# 4. Бит и байт

**Бит** — минимальная единица количества информации.

Один бит может принимать два значения:

```text
0
1
```

**Байт** состоит из восьми бит:

```text
1 байт = 8 бит
```

Это нужно запомнить.

---

# 5. Единицы измерения информации

В задачах используем:

```text
1 байт = 8 бит
1 Кбайт = 1024 байта = 2¹⁰ байт
1 Мбайт = 1024 Кбайта = 2¹⁰ Кбайт
1 Гбайт = 1024 Мбайта = 2¹⁰ Мбайт
```

Цепочка:

```text
бит → байт → Кбайт → Мбайт → Гбайт
```

При движении вправо:

```text
бит → байт      / 8
байт → Кбайт    / 1024
Кбайт → Мбайт   / 1024
Мбайт → Гбайт   / 1024
```

При движении влево — умножаем.

# 7. Мощность алфавита

**Мощность алфавита** — количество различных символов, которые могут использоваться.

Например:

```text
цифры 0–9 → 10 символов
латинские заглавные A–Z → 26 символов
```

Если разрешены 26 букв и 10 цифр:

```text
N = 26 + 10 = 36
```

---

# 8. Сколько бит нужно на один символ

Если на один символ выделяется `i` бит, можно закодировать:

```text
2^i
```

различных вариантов.

Нужно найти минимальное `i`, для которого:

```text
2^i ≥ N
```

где:

```text
N — мощность алфавита
i — количество бит на один символ
```

---

# 9. Пример: 32 символа

```text
N = 32
```

```text
2⁵ = 32
```

Значит:

```text
i = 5 бит
```

---

# 10. Пример: 36 символов

```text
N = 36
```

Проверяем:

```text
2⁵ = 32  — не хватает
2⁶ = 64  — хватает
```

Ответ:

```text
6 бит на символ
```

---

# 11. Важное правило

Если количество символов не является степенью двойки, берём **следующее достаточное количество бит**.

Например:

```text
N = 33
```

```text
2⁵ = 32  — мало
2⁶ = 64  — достаточно
```

Ответ:

```text
6 бит
```

---

# 12. Информационный объём сообщения

Главная формула:

```text
I = K · i
```

где:

```text
I — информационный объём
K — количество символов
i — количество бит на символ
```

---

# 13. Пример

Сообщение содержит:

```text
120 символов
```

Каждый символ кодируется:

```text
8 бит
```

Тогда:

```text
I = 120 · 8 = 960 бит
```

В байтах:

```text
960 / 8 = 120 байт
```

---

# 14. Алфавит + объём сообщения

Текст содержит:

```text
200 символов
```

Алфавит содержит:

```text
64 символа
```

Сначала определяем количество бит:

```text
64 = 2⁶
```

```text
i = 6
```

Теперь объём:

```text
I = 200 · 6 = 1200 бит
```

```text
1200 / 8 = 150 байт
```

Ответ:

```text
150 байт
```

# 15. Задачи на идентификаторы

Типовая ситуация:

> Каждому пользователю выдаётся идентификатор длиной `K` символов. Используется алфавит из `N` символов. Каждый символ кодируется одинаковым минимально возможным количеством бит.

Алгоритм:

```text
1. Найти N.
2. Найти минимальное i: 2^i ≥ N.
3. Найти K · i бит.
4. Если память выделяется целыми байтами — округлить вверх.
5. Если идентификаторов много — умножить на их количество.
```

---

# 16. Округление вверх

Если один идентификатор занимает:

```text
42 бита
```

то:

```text
42 / 8 = 5.25 байта
```

Но память выделяется целыми байтами.

Нужно:

```text
6 байт
```

То есть округляем **вверх**.

---

# 17. Пример задачи на идентификатор

Идентификатор содержит:

```text
15 символов
```

Используются:

```text
26 букв
10 цифр
```

Всего:

```text
N = 36
```

На символ:

```text
2⁵ = 32  — мало
2⁶ = 64  — хватает
```

```text
i = 6
```

На весь идентификатор:

```text
15 · 6 = 90 бит
```

```text
90 / 8 = 11.25 байта
```

Следовательно:

```text
12 байт
```

# 19. Поиск минимального количества бит

```python
N = 36

i = 0

while 2 ** i < N:
    i += 1

print(i)
```

Ответ:

```text
6
```

---

# 20. Округление вверх в Python

```python
from math import ceil

bits = 90
bytes_count = ceil(bits / 8)

print(bytes_count)
```

Результат:

```text
12
```

---

# 21. Полная задача через Python

```python
from math import ceil

alphabet = 36
length = 15
count = 1000

i = 0

while 2 ** i < alphabet:
    i += 1

bits_per_id = length * i
bytes_per_id = ceil(bits_per_id / 8)
total = bytes_per_id * count

print(total)
```

- работу вперёд.
