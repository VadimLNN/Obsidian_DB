# Занятие 4. Кодирование звуковой информации

## Тема

**Кодирование звуковой информации. Частота дискретизации, глубина кодирования, число каналов, объём аудиофайла, сжатие и передача.**

В актуальном ЕГЭ по информатике задачи на объём звуковой информации относятся к **заданию 7**.

---

# 1. Что нужно знать

При оцифровке звук измеряется через небольшие промежутки времени.

Основные параметры цифровой звукозаписи:

- **частота дискретизации** `f`;
- **глубина кодирования** `b`;
- **количество каналов** `c`;
- **продолжительность записи** `t`.

---

# 2. Частота дискретизации

Частота дискретизации показывает, **сколько измерений сигнала выполняется за одну секунду**.

Например:

```text
32 кГц = 32 000 измерений в секунду
48 кГц = 48 000 измерений в секунду
96 кГц = 96 000 измерений в секунду
```

Важно:

```text
1 кГц = 1000 Гц
```

---

# 3. Глубина кодирования

Глубина кодирования показывает, сколько бит используется для хранения одного измерения.

Например:

```text
8 бит
16 бит
24 бита
32 бита
```

Чем больше глубина кодирования, тем больше информации хранится о каждом измерении.

---

# 4. Количество каналов

Часто встречаются:

```text
моно    = 1 канал
стерео  = 2 канала
квадро  = 4 канала
```

Если остальные параметры одинаковы:

```text
стерео занимает в 2 раза больше памяти, чем моно
квадро занимает в 4 раза больше памяти, чем моно
```

---

# 5. Главная формула

Информационный объём несжатой звукозаписи:

```text
I = f · b · c · t
```

где:

```text
I — объём в битах
f — частота дискретизации в Гц
b — глубина кодирования в битах
c — количество каналов
t — время в секундах
```

---

# 6. Перевод единиц

```text
1 байт = 8 бит

1 Кбайт = 1024 байта

1 Мбайт = 1024 Кбайта
```

Поэтому после нахождения объёма в битах:

```text
биты / 8        → байты

байты / 1024    → Кбайты

Кбайты / 1024   → Мбайты
```

---

# 7. Пример

Производится монофоническая запись:

```text
частота: 32 кГц
глубина: 16 бит
время: 10 секунд
```

Переводим частоту:

```text
32 кГц = 32 000 Гц
```

Находим объём:

```text
I = 32 000 · 16 · 1 · 10
```

```text
I = 5 120 000 бит
```

В байтах:

```text
5 120 000 / 8 = 640 000 байт
```

В Кбайтах:

```text
640 000 / 1024 = 625 Кбайт
```

**Ответ: 625 Кбайт.**

---

# 8. Обратные задачи

Из формулы

```text
I = f · b · c · t
```

можно выразить любой параметр.

Например, время:

```text
t = I / (f · b · c)
```

Глубина:

```text
b = I / (f · c · t)
```

Частота:

```text
f = I / (b · c · t)
```

---

# 9. Во сколько раз изменится объём

Если продолжительность записи не меняется:

```text
I ∝ f · b · c
```

Например:

- частота увеличилась в 2 раза;
- глубина увеличилась с 16 до 24 бит, то есть в `24 / 16 = 1.5` раза;
- моно заменили на стерео, то есть число каналов увеличилось в 2 раза.

Тогда объём увеличится:

```text
2 · 1.5 · 2 = 6 раз
```

---

# 10. Сжатие

Если сказано:

> объём сократился на 80%

то осталось:

```text
100% - 80% = 20%
```

То есть:

```text
Iсжат = I · 0.2
```

Важно не перепутать:

```text
сжали НА 80% → осталось 20%

сжали ДО 80% → осталось 80%
```

В ЕГЭ обычно формулировка явно говорит, на сколько процентов сокращён объём.

---

# 11. Передача файла

Для передачи:

```text
t = I / v
```

где:

```text
I — размер передаваемого файла
v — скорость передачи
t — время
```

Если:

```text
I — в Кбайтах
v — в Кбайт/с
```

то время сразу получится в секундах.

---

# 12. Непрерывная передача аудиопотока

Если звук передаётся сразу во время записи, поток данных после сжатия не должен превышать пропускную способность канала.

Несжатый поток:

```text
V = f · b · c
```

в бит/с.

После сжатия на `p%`:

```text
Vсжат = f · b · c · (1 - p/100)
```

Для непрерывной передачи должно выполняться:

```text
Vсжат ≤ пропускная способность канала
```

---

# 13. Минимум для Python

Для большинства задач Python не обязателен, но им удобно проверять вычисления.

```python
f = 48000
b = 24
channels = 2
time = 30

bits = f * b * channels * time
bytes_count = bits / 8
kb = bytes_count / 1024

print(kb)
```

Для сжатия на 80%:

```python
compressed = kb * 0.2
```

Для передачи:

```python
speed = 50  # Кбайт/с

transfer_time = compressed / speed

print(transfer_time)
```



```text

```


# 21. Решения задач 41–50

## 41

Сравниваем только параметры, потому что продолжительность одинакова.

Исходный объём пропорционален:

```text
48 · 16 · 1
```

Новый до сжатия:

```text
96 · 24 · 2
```

Но после сжатия остаётся `25%`:

```text
96 · 24 · 2 · 0.25
```

Отношение:

```text
(96 · 24 · 2 · 0.25) / (48 · 16 · 1)
= 1.5
```

**Ответ: итоговый файл в 1.5 раза больше.**

---

## 42

После уменьшения на `70%` осталось `30%`.

Исходный объём:

```text
3375 / 0.3 = 11250 Кбайт
```

Скорость накопления несжатых данных:

```text
48 000 · 24 · 2 / 8 / 1024
= 281.25 Кбайт/с
```

Время:

```text
11250 / 281.25 = 40 секунд
```

**Ответ: 40 секунд.**

## 43

За время передачи было отправлено:



Несжатый поток:

```text
64 000 · 32 · 2 / 8 / 1024
= 500 Кбайт/с
```

Продолжительность:

```text
16000 / 500 = 32 секунды
```

**Ответ: 32 секунды.**

## 44

**Ответ: 32 бита.**

# 22. Как провести занятие с группой разного уровня

Примерный план:

```text
0–10 мин   — повторение битов, байтов, Кбайтов
10–25 мин  — что такое частота, глубина, каналы
25–40 мин  — формула I = f·b·c·t
40–50 мин  — одна задача на сжатие и передачу
50–90 мин  — самостоятельная работа по уровням
```

## Начинающие

Дать:

```text
1–10
```

После этого:

```text
11–20
```

С ними отдельно проговаривать каждый шаг:

```text
кГц → Гц
минуты → секунды
биты → байты
байты → Кбайты
```

## Сильные

После общего объяснения можно сразу дать:

```text
21–40
```

Если быстро справляются:

```text
41–50
```

# 23. Что ученик должен вынести с занятия

Главное:

```text
I = f · b · c · t
```

и понимание каждого множителя.

Также:

```text
моно = 1
стерео = 2
квадро = 4
```

```text
1 кГц = 1000 Гц
```

```text
1 байт = 8 бит
1 Кбайт = 1024 байта
```

И при сжатии:

```text
уменьшили на 80% → осталось 20%
```

Для передачи:

```text
время = размер / скорость
```
