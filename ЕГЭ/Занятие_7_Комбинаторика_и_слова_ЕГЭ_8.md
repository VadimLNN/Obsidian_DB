# 1. Что такое «слово» в задании №8

В задачах ЕГЭ слово — это просто последовательность символов.

Например:

```text
ААБВ
КККА
АРТА
```

Слово **не обязано иметь смысл** в русском языке.

Если сказано:

> составляются пятибуквенные слова из букв А, Б, В

то допустимы:

```text
ААААА
ААААБ
ААААВ
...
ВВВВВ
```

если в условии нет дополнительных ограничений.

---

# 2. Главное правило комбинаторики

Если на каждую позицию можно поставить `N` символов, а длина слова равна `K`, то:

```text
Количество слов = N^K
```

Например:

```text
алфавит: А, Б, В, Г
длина: 5
```

На каждое место:

```text
4 варианта
```

Поэтому:

```text
4^5 = 1024
```

---

# 3. Правило произведения

Если для разных позиций количество вариантов различается, количества вариантов **перемножаются**.

Например:

Слово длины 5 составляется из:

```text
А, Б, В, Г
```

Первый символ должен быть:

```text
А или Б
```

То есть:

```text
2 варианта
```

Остальные четыре позиции:

```text
4 варианта каждая
```

Ответ:

```text
2 · 4^4 = 512
```

---

# 4. Если буквы нельзя повторять

Если нужно составить слово длины `K` из `N` различных символов и каждый можно использовать не более одного раза:

```text
N · (N - 1) · (N - 2) · ...
```

Например:

```text
5 букв
использовать все 5 ровно по одному разу
```

Получаем:

```text
5! = 120
```

где:

```text
5! = 5 · 4 · 3 · 2 · 1
```

# 5. Ровно одна нужная буква

Пусть слово длины 5 строится из:

```text
А, Б, В, Г
```

и буква `А` должна встретиться **ровно один раз**.

Сначала выбираем место для `А`:

```text
5 вариантов
```

Остальные четыре позиции:

```text
Б, В или Г
```

то есть:

```text
3^4
```

Ответ:

```text
5 · 3^4 = 405
```

# 6. Хотя бы одна буква

Часто проще считать через противоположное событие.

Нужно найти количество пятибуквенных слов из:

```text
А, Б, В, Г
```

в которых есть **хотя бы одна А**.

Всего слов:

```text
4^5
```

Без буквы `А`:

```text
3^5
```

Поэтому:

```text
4^5 - 3^5
```

```text
= 781
```

Главная идея:

```text
хотя бы один
=
все
-
ни одного
```

# 7. Запрет двух одинаковых символов подряд

Например:

> сколько шестибуквенных слов из А, Б, В, Г не содержат `АА`?

Здесь простой формулой считать уже неудобно.

Для ЕГЭ разумно использовать Python.

```python
from itertools import product

count = 0

for x in product("АБВГ", repeat=6):
    word = "".join(x)

    if "АА" not in word:
        count += 1

print(count)
```

Это один из самых полезных инструментов для №8.

```python

for x in product("АБВ", repeat=4):
```

Это именно тот перебор, который нужен в большинстве задач №8.

# 9. Подсчёт слов с условием

Пример:

> Сколько пятибуквенных слов из А, Б, В, Г содержат ровно две буквы А?

```python
from itertools import product

count = 0

for x in product("АБВГ", repeat=5):
    word = "".join(x)

    if word.count("А") == 2:
        count += 1

print(count)
```

# 10. Несколько условий

Например:

- слово длины 6;
- алфавит `АБВГД`;
- ровно две `А`;
- `АА` запрещено;
- слово не начинается с `Д`.

```python
from itertools import product

count = 0

for x in product("АБВГД", repeat=6):
    word = "".join(x)

    if (
        word.count("А") == 2
        and "АА" not in word
        and not word.startswith("Д")
    ):
        count += 1

print(count)
```

Условия удобно записывать через:

```python
and
or
not
```

# 11. Гласные и согласные

```python
vowels = "АЕИОУЭЮЯ"
```

Например:

```python
if word[0] in vowels:
    ...
```

или:

```python
if word[0] not in vowels:
    ...
```

Посчитать количество гласных:

```python
sum(ch in vowels for ch in word)
```

Например:

```python
if sum(ch in vowels for ch in word) == 2:
    ...
```

# 12. Лексикографический порядок

Это один из главных типов современного №8.

Пусть используются буквы:

```text
А, К, Р, У
```

в таком порядке.

Все четырёхбуквенные слова будут идти так:

```text
1. АААА
2. АААК
3. АААР
4. АААУ
5. ААКА
6. ААКК
...
```

Это очень похоже на счёт в системе счисления.

---

# 13. Связь с системами счисления

Для алфавита:

```text
А, К, Р, У
```

можно заменить буквы цифрами:

```text
А → 0
К → 1
Р → 2
У → 3
```

Тогда:

```text
АААА → 0000₄
АААК → 0001₄
АААР → 0002₄
АААУ → 0003₄
ААКА → 0010₄
```

То есть список слов фактически совпадает со счётом:

```text
0000
0001
0002
0003
0010
...
```

в системе с основанием `4`.

---

# 14. Почему нужно прибавлять 1

Первое слово:

```text
АААА
```

соответствует:

```text
0000₄ = 0
```

Но номер слова:

```text
1
```

Поэтому:

```text
номер = значение + 1
```

Это очень важная деталь.

---

# 15. Найти номер слова

Пусть порядок букв:

```text
А, К, Р, У
```

Нужно найти номер:

```text
УКАРА
```

Заменяем:

```text
У → 3
К → 1
А → 0
Р → 2
А → 0
```

Получаем:

```text
31020₄
```

Переводим в десятичную:

```text
3·4^4 + 1·4^3 + 0·4^2 + 2·4 + 0
```

и прибавляем:

```text
1
```

# 16. Найти слово по номеру

Если нужно найти слово №250:

```text
1. Вычитаем 1.
2. Полученное число переводим в систему с основанием N.
3. Дополняем слева нулями до нужной длины.
4. Цифры заменяем буквами.
```

Например, алфавит:

```text
А, М, Р, Т
```

Значит:

```text
основание = 4
```

Для позиции:

```text
250
```

работаем с:

```text
249
```

# 17. Лексикографический порядок через Python

Python может сразу генерировать слова в нужном порядке.

Главное — записать символы **в правильном порядке**.

```python
from itertools import product

alphabet = "АКРУ"

for number, x in enumerate(product(alphabet, repeat=5), start=1):
    word = "".join(x)

    print(number, word)
```

---

# 18. Главное предупреждение

Если в условии буквы перечислены так:

```text
П, А, Р, У, С
```

это **не значит**, что порядок:

```text
П А Р У С
```

Если сказано:

> слова записаны в алфавитном порядке

нужно сначала расположить буквы:

```text
А, П, Р, С, У
```

И в Python использовать именно:

```python
alphabet = "АПРСУ"
```

# 19. Номер слова + дополнительное условие

Современный №8 часто выглядит примерно так:

> Все слова записаны по порядку. Найдите последнее слово с чётным номером, которое:
>
> - не начинается с определённых букв;
> - содержит ровно две нужные буквы.

Самый надёжный подход:

```python
from itertools import product

alphabet = "АКОРСТ"

for number, x in enumerate(product(alphabet, repeat=5), start=1):
    word = "".join(x)

    if (
        number % 2 == 0
        and word[0] not in "АСТ"
        and word.count("О") == 2
    ):
        print(number, word)
```

Если требуется **последнее** слово, программа выведет несколько строк — нужен последний номер.

Или можно сохранять:

```python
answer = 0

for number, x in enumerate(..., start=1):
    ...
    if условие:
        answer = number

print(answer)
```

```python
word.count("А") == 2
```

### Не менее двух А

```python
word.count("А") >= 2
```

### Не более двух А

```python
word.count("А") <= 2
```

```python
"А" not in word
```

```python
word.startswith("А")
```

```python
word[0] == "А"
```

```python
word[0] not in "АБВ"
```

```python
word.endswith("А")
```


# 26. Типичные ошибки

## Ошибка 1. Неправильный порядок букв

Было:

```text
П, А, Р, У, С
```

А для алфавитного списка нужно:

```text
А, П, Р, С, У
```

---

## Ошибка 2. Забыть `+1`

Системы счисления начинаются с:

```text
0
```

а список слов:

```text
1
```

Поэтому:

```text
номер = значение + 1
```

---

## Ошибка 3. Перепутать `ровно` и `не менее`

```python
== 2
```

не то же самое, что:

```python
>= 2
```

---

## Ошибка 4. Перебирать перестановки вместо слов с повторениями

Для обычного №8:

```python
product(...)
```

Если символы могут повторяться.

`permutations()` нужен только когда повторение запрещено.

---

## Ошибка 5. Забыть запрет ведущего нуля в задаче про числа

Если задача говорит о **числах**, первая цифра не может быть `0`.

Если задача говорит о **словах или кодах**, первый символ может быть любым, если условие не запрещает.

## 44

Полный перебор всех чисел:

```text
7^10
```

слишком велик.

Поэтому сначала считаем **схемы расположения** чётных и нечётных цифр.

Обозначим:

```text
Н — нечётная цифра
Ч — чётная цифра
```

Нужно:

```text
10 позиций
ровно 3 Н
НН запрещено
```

Подходящих схем:

```text
с Н на первой позиции — 21
с Ч на первой позиции — 35
```

В семеричной системе:

```text
нечётные цифры: 1, 3, 5        → 3 варианта
чётные цифры: 0, 2, 4, 6       → 4 варианта
```

Если первая цифра чётная, ноль использовать нельзя:

```text
2, 4, 6 → 3 варианта
```

Поэтому:

```text
21 · 3^3 · 4^7
+
35 · 3 · 3^3 · 4^6
```

Получаем:

```text
20901888
```

**Ответ: 20901888.**
