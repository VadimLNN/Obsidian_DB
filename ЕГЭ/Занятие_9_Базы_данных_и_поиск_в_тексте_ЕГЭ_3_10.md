# Занятие 9. Базы данных и поиск информации в тексте

**ЕГЭ по информатике — задания №3 и №10**

Цель занятия: научиться уверенно брать два задания, которые для курса на **60+** относятся к приоритетным:

- **№3** — поиск информации в реляционной многотабличной базе данных;
- **№10** — поиск информации средствами текстового редактора.

В реальном ЕГЭ оба задания выполняются на компьютере с использованием приложенных файлов.

---

# Часть I. Базы данных — ЕГЭ №3

# 1. Что такое база данных

База данных — организованный набор связанных данных.

Пример:

```text
Товары
Магазины
Операции
```

Вместо одной огромной таблицы информация обычно разделена на несколько связанных таблиц.

---

# 2. Основные понятия

## Таблица

Например:

| Код | Товар | Цена |
|---|---|---:|
| P01 | Молоко | 89 |
| P02 | Хлеб | 55 |

## Запись

Одна строка таблицы:

```text
P01 | Молоко | 89
```

## Поле

Один столбец:

```text
Код
Товар
Цена
```

---

# 3. Первичный ключ

**Первичный ключ** однозначно определяет запись.

Например:

```text
P01
P02
P03
```

Код товара удобнее использовать для связи таблиц, чем длинное название товара.

---

# 4. Связи между таблицами

Например:

```text
Товары.Код
      │
      └──────────────→ Операции.КодТовара

Магазины.Код
      │
      └──────────────→ Операции.КодМагазина
```

В таблице операций может не быть названия:

```text
Молоко
```

Там будет:

```text
P01
```

Поэтому нужно сначала найти код товара в справочнике.

---

# 5. Типичная структура задания №3

Обычно есть несколько листов или таблиц:

```text
Товар
Магазин
Движение товара
```

Вопрос может быть таким:

> Сколько единиц товара X было продано в магазинах определённого района?

Тогда нужно связать сразу несколько таблиц:

```text
название товара
→ код товара
→ район
→ коды магазинов района
→ операции продажи
→ сумма количества
```

---

# 6. Главный алгоритм №3

## Шаг 1. Понять, что спрашивают

Например:

```text
товар: молоко
район: Центральный
операция: продажа
нужна: сумма количества
```

## Шаг 2. Найти код товара

```text
Молоко → P01
```

## Шаг 3. Найти нужные магазины

```text
Центральный район
→ S01, S03
```

## Шаг 4. В таблице операций оставить строки

```text
товар = P01
магазин = S01 или S03
операция = Продажа
```

## Шаг 5. Выполнить итоговое действие

Чаще всего:

```text
SUM(Количество)
```

Иногда:

```text
Количество · Цена
```

если спрашивают стоимость.

---

# 7. Поступление и продажа — не одно и то же

В таблице могут находиться операции:

```text
Поступление
Продажа
```

Если спрашивают:

> сколько продано

нельзя учитывать поступления.

Если спрашивают изменение остатка:

```text
изменение = поступление - продажа
```

---

# 8. Сумма количества и сумма стоимости

Это две разные задачи.

### Количество

```text
18 + 12 + 15 = 45 единиц
```

### Стоимость

Если цена товара:

```text
89 руб.
```

то:

```text
18·89 + 12·89 + 15·89
```

---

# 9. Фильтры

Удобно последовательно фильтровать таблицу:

```text
1. операция
2. товар
3. магазин / район
4. дата
```

И только потом считать сумму.

В Excel / LibreOffice Calc полезны:

```text
автофильтр
сортировка
SUM
SUMIF / SUMIFS — необязательно, но удобно
```

Для №3 необязательно знать SQL.

## Ловушка 2

Район часто находится только в таблице:

```text

```

## Ловушка 3

Перепутать:

```text

```


## Ловушка 5

Не включить крайние даты интервала.

Если:

```text

```

```text

04.09
05.09
```

# Часть II. Поиск информации в тексте — ЕГЭ №10

# 11. Что реально проверяет №10

В задании нужно открыть приложенный текстовый документ и найти:

```text
слово
словосочетание
сочетание букв
```

иногда только в определённых:

```text
главах
частях
разделах
```

Главная сложность №10 — **правильно прочитать условие поиска**.

---

# 12. Поиск точного слова и сочетания букв — разные вещи

Допустим, ищем:

```text
мир
```

### Точное слово

Нужно найти:

```text
мир
```

но не:

```text
мировой
мирный
```

### Сочетание букв

Тогда подходят:

```text
мир
мировой
мирный
```

и даже слово:

```text
программирование
```

если внутри него действительно встречается последовательность `мир`.

На экзамене нужно буквально выполнять формулировку задания.

---

# 13. «В составе других слов, но не как отдельное слово»

Это типичная формулировка.

Пусть требуется сочетание:

```text
рук
```

Подойдут:

```text
рука
руки
рукопись
рукодельный
```

Не подойдёт отдельное слово:

```text
рук
```

---

# 14. Регистр

Условие может просить:

```text
то или То
```

Это значит:

```text
регистр первой буквы не важен
```

При использовании поиска удобно отключить:

```text
Учитывать регистр / Match case
```

Но всегда сверяйся с условием.

---

# 15. Дефис

Сложное слово:

```text
кто-то
```

в задачах ФИПИ может считаться одним словом с дефисом.

Если ищется сочетание:

```text
то
```

оно встречается в:

```text
кто-то
```

дважды.

Поэтому поиск по тексту надёжнее ручного чтения.

---

# 16. Выбирать только нужные главы

Если условие говорит:

```text
главы II, III и IV
```

не нужно искать по всему произведению.

Рабочий способ:

```text
1. выделить нужные главы;
2. скопировать во временный документ;
3. выполнять поиск только там.
```

Так меньше шансов включить лишние совпадения.

---

# 17. Практический алгоритм №10

```text
1. Прочитать, что именно нужно искать.
2. Определить нужные главы.
3. Открыть поиск Ctrl+F.
4. Настроить регистр.
5. Найти все совпадения.
6. Проверить границы слова.
7. Исключить совпадения, запрещённые условием.
8. Записать только число.
```

---

# 18. Почему нельзя просто доверять числу «Найдено: N»

Если требуется:

> сочетание `мир` в составе других слов, но не как отдельное слово

поиск покажет и:

```text
мир
```

и:

```text
мировой
```

и:

```text
мирный
```

Нужно исключить отдельные слова `мир`.

# 19. Учебный текст для задач 26–50

Все дальнейшие задачи выполняются по этому тексту.

## Глава I

Информатика изучает данные и способы их обработки. База данных хранит связанные записи. Код программы задаёт алгоритм, а кодирование превращает сообщение в последовательность символов. Мир цифровых технологий меняется быстро. Программист работает с программой и проверяет её результат. Рукописный конспект иногда помогает лучше запомнить материал. Кто-то открыл файл, но то решение оказалось неверным.

## Глава II

Вторая глава посвящена сетям. Компьютер подключён к локальной сети, сетевой адрес помогает найти узел. Россия развивает цифровые сервисы, а российские разработчики создают новые системы. База данных может находиться на сервере. Код доступа нельзя хранить открыто. Обработка данных требует точности. Рука робота движется по программе. Потом кто-то исправил ошибку.

## Глава III

Текстовый редактор помогает искать слова и сочетания букв. Поиск слова мир не должен находить слово мировой, если требуется только отдельное слово. Информационный поиск бывает простым и сложным. Кодекс отличается от слова код, хотя сочетание код в нём есть. База данных снова упоминается как пример. Руки оператора лежали на клавиатуре, а рукопись лежала рядом. То был учебный пример, зато кто-то понял условие.

## Глава IV

Электронная таблица содержит строки и столбцы. Данные можно сортировать, фильтровать и суммировать. Программа обработки вычисляет результат. Российский рынок программного обеспечения растёт. Россия упоминается отдельно. Мирный режим работы сервера важен, но слово мир здесь является частью другого слова. Кодирование изображений использует глубину цвета. Рукодельный пример оказался забавным. Кто-то снова написал то.

## Глава V

Перед экзаменом полезно повторить основные темы. База данных, кодирование, программирование и информационный поиск встречаются в разных заданиях. Программист должен внимательно читать условие. Данные из нескольких таблиц связываются по ключу. Мир задач становится понятнее после практики. Россия и российские города могут встречаться в учебных текстах. Рукописный ответ здесь не нужен. Кто-то знает, что то слово иногда требуется исключить из поиска.

# Что ученик обязан вынести

## №3

```text
1. Таблицы связаны ключами.
2. Сначала найти нужные коды.
3. Потом фильтровать операции.
4. Не путать поступление и продажу.
5. Не путать количество и стоимость.
```

## №10

```text
1. Точное слово ≠ сочетание букв.
2. Всегда учитывать нужный диапазон глав.

5. Внимательно читать:
   «в составе других слов»,
   «но не как отдельное слово».
```

Для цели **60+** оба задания стоит считать обязательными.
